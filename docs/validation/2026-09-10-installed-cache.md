# 安装缓存启动并发优化

本轮基于 270b8aa 及工作区已有的文件 I/O 修复，仅修改 InstalledAppsCache 与对应测试。未覆盖或回退上一轮改动。

## 问题与改动

- 原实现安排扫描即写入 lastRefreshAt，isWarmed 在结果尚未发布时返回 true；后加入的 warmUp 调用方得不到完成通知，可能错过自动发现档案的启用集重放。
- warmUp 的检查与刷新分别加锁；maxAge=0 不检查在途状态，允许多个扫描同时运行并交错发布结果。
- 新实现将冷态、缓存年龄和在途判断合并在同一临界区。在途请求共享完成回调；仅扫描完成时更新时间戳。同步 refresh 遇到在途扫描时等待其结果。
- 已热且无在途扫描时，warmUp 继续跳过且不回调，保留既有契约。异步扫描之外的磁盘操作不占缓存锁，读取缓存不会等待整个扫描。
- 删除旧测试里未使用、跨后台队列修改的 scans 计数，避免测试自身引入数据竞争。
