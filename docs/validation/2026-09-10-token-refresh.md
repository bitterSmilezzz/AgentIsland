# Token 刷新与详情解析优化

本轮继续检查高频 Token 路径，新增两个回归场景：

- 数据库每分钟轮询但统计值没有变化时，旧实现仍调用 `onRefresh`，引擎会重复采样、重算卡片布局。现在比较刷新前后的用量快照与汇总，只有真实变化（包括 24h 窗口过期）才通知 UI。
- SQLite 对 REAL 聚合可能返回 `301.0`，详情页原本使用 `Int("301.0")`，失败后静默显示 0。模型与会话查询统一使用数值解析，汇总、模型、会话三处口径一致。

验证结果：99/99 测试通过，`--selftest` 通过，`git diff --check` 通过。新增测试覆盖无变化轮询、成本变化、窗口过期和 REAL Token 详情。

未做真实数据库性能基准；聚合查询仍按现有只读连接和刷新节奏执行。
