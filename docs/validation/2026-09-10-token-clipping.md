# 关闭消息后 Token 条截断

用户截图表明：右侧贴边卡片底部文字进入了造型的透明倒角区。此前按矩形窗口边界检查的布局测试无法检出。

原因：SideNotchShape 在右侧停靠时将正文上下边界内缩 10pt，而 cardShell 与窗口高度计算未为这部分留白。事件移除、窗口缩短后，文字虽然仍在矩形窗口内，却已超出正文造型。

修复：卡片外壳增加安全留白；高度计算与列表剩余空间同步包含留白；顶部停靠时也避开左右倒角；Token 条固定理想纵向高度，保留完整文字。

验证：新增 scripts/test-token-layout.py，使用实际 SwiftUI 视图与假数据模拟八条 Agent 记录、显示消息、关闭消息。测量 Token 条实际位置，检查正文下沿是否在 CGPath 内。

- 修复前失败：正文下沿 445.5pt，造型正文边界 444pt（窗口 454pt）。
- 修复后通过：Token 条保持 27pt 高，正文位于造型内。
- 核心测试 97/97；应用 --selftest 通过；git diff --check 通过。

运行布局测试前执行 swift build；然后运行 python3 scripts/test-token-layout.py。此测试需要 macOS 图形会话，编译临时测试程序，不读取用户会话日志。
