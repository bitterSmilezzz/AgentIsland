# 异常弹窗去重验证

## 问题

同一 Agent 持续处于 Token 高速增长或高 CPU 状态时，活动引擎会在每个确认周期再次生成同类告警。用户关闭消息后，新的告警事件又会触发 Agent Island 弹出，看起来像窗口“莫名其妙一直弹”。

## 修复

- Token 激增在同一段连续异常期间只生成一次事件。
- Token 速率回落到阈值以下后，清除告警锁，下一轮异常仍可提醒。
- 高 CPU 死循环告警在同一段持续高负载期间只生成一次事件。
- Agent 离线、终止或清理异常时同步清理告警锁，避免旧状态污染下一次运行。

## 验证

`AgentIslandTestsRunner`：100 个用例通过；新增用例覆盖“关闭 Token 激增消息后继续增长不重复弹窗，以及恢复后新一轮异常仍可告警”。`AgentIsland --selftest` 全部通过。
