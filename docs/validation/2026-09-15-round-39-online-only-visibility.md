# R39 验证记录：仅显示在线 Agent（v0.0.56）

日期：2026-09-15 · 执行：主 agent
触发：用户要求离线 Agent 不显示，待机与运行中的 Agent 显示。

## 变更

- `visibleSnapshots` 从“在线或 24h 内有活动”收紧为 `processRunning == true`。
- 主列表、菜单摘要、窗口高度和活动环继续共用同一可见集合，避免内容与窗口几何口径漂移。
- 待机、工作中、待确认、已完成都属于在线状态，继续显示；离线 Agent 的历史活动和 Token 只保留在底层快照/统计中，不再进入主界面。
- 设置页仍展示全部档案，便于重新启用或管理未运行的 Agent。

## 回归

- 离线但近期活跃：隐藏。
- 离线且有 24h Token：隐藏，且不进入顶部活动环。
- 在线待机：显示。
- 在线工作：显示。
- 可见集与活动环仍是总快照的严格子集。
