# R41 验证记录：Token 时间分析（v0.0.58）

日期：2026-09-15 · 执行：主 agent
目标：增加完整的按时间 Token 可视化，但不提高主卡默认信息密度。

## 设计结果

- 主卡底部仍为单行 24h / 累计汇总，仅增加轻量箭头和点击入口。
- 下钻页采用“范围选择 → 核心指标 → 趋势 → 来源构成 → 口径说明”的渐进层级。
- 24h 固定 24 个小时桶、7 天固定 28 个 6 小时桶、30 天固定 30 个日桶，避免窄面板过密。
- 当前范围与上一等长周期分开统计；来源占比可继续跳 Agent 模型/会话详情。
- 数据库继续只读，时间线仅在打开页面和切换范围时后台查询，不加入常驻轮询负担。

## 数据验证

- 纯聚合测试覆盖当前周期左边界、上一周期、未来记录排除、过旧记录排除、来源排序和成本。
- 空时间线覆盖三种范围的固定桶数。
- 双 SQLite fixture 验证 DimAgent + OpenCode 合并后桶合计、范围合计和来源合计一致。
- 自建 runner：**217 通过 / 0 失败**。

## 构建与实机

- Release v0.0.58 打包完成，ad-hoc 签名成功。
- 330pt 真实卡片中主列表仍为单行汇总；点击进入分析页后，三档范围选择、三项指标、趋势图、来源条和口径说明均未横向溢出。
- 使用本机真实 151.80M 累计数据验证：24h 显示 3.67M 与小时趋势，7 天显示 31.14M，30 天显示 151.80M；三档切换后数据、轴标签、峰值和环比均同步更新。
- Accessibility 树暴露完整数值（如 `3,673,097`）、范围选择状态、趋势摘要和来源占比，不依赖图形/颜色才能理解。
- 汇总条真实 SwiftUI 几何门禁：有/无事件横幅两种布局下均位于 notch 内，PASS。
