# 02 · UI、组件与导航动效

## 1. 当前接缝

`views.js` 同时管理页面 HTML、绑定与切换；`main.js` 保存运行状态与采样更新；`island-navigation.js` 管理持久表面的动画；`navigation.js` 与原生窗口交接。工作台已有保持导航/顶栏的更新方式。先维护现有行为，再抽出边界；本阶段不用框架迁移掩盖状态问题。

## 2. 前端文件职责（拟增量拆分）

| 文件 | 职责 |
| --- | --- |
| `js/ui/components.js` | 行、动作按钮、状态标签、空/错状态的共享渲染；不读取业务状态 |
| `js/ui/page-host.js` | 页面 mount/update/dispose、焦点、滚动、请求有效性 |
| `js/ui/drafts.js` | 按 page/object 保存编辑草稿，接现有 set_workbench_draft 租约 |
| `js/ui/motion.js` | 时长、缓动、reduced-motion 与动画取消封装 |
| `js/pages/tasks.js`、`window-layouts.js`、`connections.js` | 新页面渲染与事件绑定，不重复实现业务规则 |
| `css/tokens.css`、各壳 CSS | 语义 token、形态隔离与布局 |

先抽新页面与共用组件，旧页面按实际修改逐步拆分；不一次移动所有函数。全局状态只有一份，草稿不得成为第二份已保存业务数据。

## 3. 页面生命周期

`PageContext` 目标字段：`page_id/object_id/request_seq/disposables/draft_key/focus_origin`。mount 获取快照与绑定；update 只修补变动区域；dispose 取消动画、解除监听、清计时器与订阅；异步响应比较 request_seq 和当前 page_id。不能在每次采样重新绑定整页监听。

编辑字段一旦 dirty，采样只能更新旁边的状态与冲突提示。写入成功才清 dirty；失败保留文字和焦点。点当前页是 no-op。离开页保留草稿；若当前窗口即将按闲置回收，继续使用既有草稿租约。未保存内容不能因隐藏/唤回丢失。

## 4. 界面实现

三壳仍使用 `shell-island/sidebar/workbench` 作用域。主导航目标以整体方案为准，只在模块具备读写/错误/空态后添加。报告入口归入用量页，同时给旧入口兼容导航；不能直接删掉导出能力。

组件先规范：`AgentRow`（身份、状态、用量、独立来源动作）、`AttentionRow`（对象、具体行动、来源）、`SectionHeader`、`FieldGroup`、`InlineResult`、`EmptyState`、`CapabilityHint`。图标 SVG viewBox/描边统一；Agent 官方图标不混用动作图标。

目标 token：spacing 4/8/12/16/24/32；正文 13–14px；小控件圆角约8px、区域12px、表面18px；控件点击区28–32px。色彩先复用当前 surface/text/accent，再去除重复硬编码与主题冲突；不宣称一次 token 替换已经完成视觉验收。

工作台检查900/1180px及实际最小窗口，侧栏检查配置宽度范围，岛检查330px目标内容与原生实际宽度。长工具名、中文两行、英文协议、100%以上CPU、缺数据都要有稳定布局。

## 5. 导航与几何状态机

目标状态：`idle → preparing → reserving → animating → settling → idle`。每次导航生成 transition ID；新的导航从当前可见几何开始，旧回调失效。异步用量请求和viewport确认都携带自己的请求身份。

1. 捕获旧内容、焦点来源与当前视觉尺寸，复制层 inert + aria-hidden，不参与输入。
2. 渲染/测量目标，提交原生可用包络需求；测量值与贴边锚点归一处计算。
3. 确认匹配的 viewport 后开始表面过渡，内容只淡变，文字不缩放。
4. 进入与返回从当前视觉状态接续，不能重置到上一个动画的起点。
5. 落定后移除副本、解除临时尺寸并处理当前采样高度；过期 settle 回调无效果。

保留既有 `island-navigation.js` 作为单一过渡实现，先修验证失败的接缝，不再增加第二套窗口尺寸监听。原生仅留包络，Web只处理视觉表面；主线程几何提交不持业务锁。

工作台导航/顶栏保持静止，正文初始离场100ms、入场200–240ms，位移至多4–6px。岛初始进入280–340ms、返回220–280ms只作为校准候选；现有值调整前先记录原生现状。周期采样不播放导航，数字直接更新；reduced-motion 取消位移/缩放和无意义等待。

## 6. 验收与失败定位

测试进入 Agent 用量/设置后返回，返回后再采样、报告延迟、连续A→B→返回、动画半途中逆向、四边贴边。记录原生框、Web表面框、transition ID与确认时间（不含个人内容）；检查结束后的额外几何提交是否有必要，尺寸落位是否二次反弹。仅检查最终截图不足以过关。

验证焦点回到触发项、Esc/Enter/空格、页面无旧副本、采样不覆盖输入、重复点击不丢草稿、监听不累计。截图只用模拟内容；原生用户桌面验证遵守现有隔离要求。回归入口沿用 test-island-return/click/motion 与 test-functional-ui，新增用例针对已复现缺陷，不镜像实现。

## A2 增量实现记录

当前接入使用顶层js/page-host.js，与现有资产/JS守护的目录扫描一致；暂不迁入嵌套ui/目录。PageCache在当前WebView中保留已知页面DOM，不将草稿序列化或持久化；DraftGuard保留隐藏页控件的租约。读取以pageRequest身份检查连接状态与请求顺序；未完成注水的页面恢复时重新读取。已恢复的档位状态保留原快照，写入仍按后端revision复核，用户可刷新重读，不将缓存显示宣称实时配置。

此步未完成整体组件/token拆分或所有页面的资源抽象；按新页面需求继续增量整理。模拟浏览器检查不替代原生隔离UI验收。


## 工作台快捷导航

顶栏“前往”与 Meta/Control+K 打开同一原生 HTML dialog。只搜索固定功能页及功能别名，不检索会话正文；结果有界滚动，方向键循环、回车打开，Escape 取消并返回触发焦点。当前页只关闭弹窗，不重建内容；目标复用现有导航、DOM 草稿和滚动保留。配置、MCP、Skills、提示词、Claude 方案采集、窗口布局确认及其他已打开的 dialog 显示时不叠加导航弹窗。焦点已在预览内时保留原选择；从顶栏返回时聚焦预览容器，不默认选中写入按钮。配置及提示词的焦点循环区分容器入口与已有控件：Tab 从首项进入，Shift+Tab 从末尾“取消”进入，之后按方向循环，不把反向进入误算为倒数第二项。隐藏或折叠的预览不阻塞导航。120ms 进场、减少动态关闭动效；注册一次键盘监听，后续页面更新复用控制器，不增加轮询。不是执行命令、全局数据搜索或来源工具跳转。

`node scripts/test-quick-navigation.mjs` 覆盖纯数据搜索、标签转义及各类预览的焦点保护。受控浏览器核对草稿往返、同页、空结果、方向键、焦点与确认保护；配置和提示词预览另核对顶栏返回后 Shift+Tab、回车取消且无写入，以及循环后明确确认仍可达。实际 Codex 和 Claude 预览控制器在浅/深色、880×560 与1120×760、普通/减少动态模式下核对快捷键、顶栏入口、取消及明确确认后跳转，IPC 为受控夹具。原生 WebView 键盘、品质与资源仍按整体门禁验收。

v0.0.304 的隔离非 demo WebView 专项见 `.build/vm/confirmation-native-0426c1a3477340d7a6bb424b6d32884a/keyboard-receipt.json`：真实键盘、顶栏入口、反向 Tab 取消及明确确认按实际文件哈希和备份数量核对，12项状态比较通过；确认后正常进入设置。原生快捷键实际验证为 Control+K，RFB 的 Super/Meta 按键未证明 macOS Command 映射，不能计作原生 Command+K 通过；浏览器 Meta/Control 分支另有受控验证。Tips 抢占客体前台、误点到其他页面和内容相同未生成预览的尝试均排除。557次环境观测解锁、最大间隔2.059秒；测试目标、lease、awake退出及锁释放已独立核实，宿主无测试窗口及激活操作。专项只证明本次焦点与写入边界，不替代完整动效、资源或跨平台品质验收。


### 用量页报告入口与异步状态

工作台报告归入用量页的按需展开区域，一级导航移除独立报告项；概览、快捷导航和旧report路由均打开同一用量页并展开/聚焦格式按钮。普通进入用量页不生成报告，明确Export等原生intent保持原Markdown生成行为。旧CLI/后端report_text及独立pageReport导出符号保留。

报告控制器保存最近成功正文和格式，生成/复制反馈独立。请求代次覆盖同格式重复请求；剪贴板完成不得覆盖之后生成的反馈，复制只取成功正文。生成失败保留旧正文和成功格式，空结果停用复制；异步结果可结算离屏缓存，返回保持展开与结果。正文可聚焦滚动和手动选中；复制失败不混入错误文字。快捷导航跨页面后不恢复弹窗调用者焦点，目标自行接收；取消/同页选择仍恢复调用者。UI与存量用量口径独立，不将报告归位算资源或原生动效验收。


### 用量趋势范围

### 任务一级入口与分类切换

工作台一级导航只显示“任务”，页内使用“任务看板 / 待办事项”两个按钮。todo/tasks 路由及各自 DOM 缓存保留，旧快速搜索待办和概览待办仍可达；不合并两类存储，不把勾选待办等同任务批准。父导航和页标题均显示任务；分类按钮通过 aria-current 表明当前视图，切换后焦点保留在目标分类。

两分类使用相同标题和说明，切换时只过渡内容区；工作台正文入场从0.55透明度立即开始，220ms到完整可见，离场仍100ms。快速逆向取消旧动画、移除惰性遮层并清理根节点内全部旧过渡宿主，避免整页/内容区过渡交替时留下裁切样式；减少动态继续禁用过渡。周期刷新不播放切页动画。

合成浏览器880×560连续四次往返核对任务及待办各自草稿，过渡结束无遗留离场层，并逐张查看截图。原生 UI smoke 增加分类与待办草稿、快捷导航 Escape 的合成事件检查；后者不替代真实键盘行为或原生逐帧品质验证。Todo CRUD 沿用既有命令，本轮浏览器夹具不证明持久化。

### 窗口排列的紧凑工作区

最小880×560桌面窗口内，标题/工具栏/规则与控件留白收敛，画布高度随视口有界调整，选窗、预览与主要动作保持集中。候选窗口列表独立滚动且可键盘聚焦，长工具名称允许换行，会话标题省略；保存规则与历史仍按需展开。目标屏幕示意同时适配画布宽高并保持原比例，负坐标按原数据计算，不改后端几何或原生窗口放置。

应用/撤销后聚焦当前结果中的冲突确认、撤销动作或结果区，并最小滚动到对应反馈；异步完成不抢根节点之外的焦点。动态结果替换后不回落到屏幕外的读取按钮。受控浏览器检查浅色880×560、深色1120×760、32窗/长中文、纵向屏幕、减少动态、部分失败/冲突撤销、分类往返草稿与延迟结果焦点；这不证明真实工具AX、多屏或原生品质全部完成。

共享sr-only辅助类用于任务、窗口规则和工作空间工具选择，视觉裁切而保留关联label/legend的无障碍名称，不使用display:none；紧凑布局不能以删除辅助名称换取空间。
