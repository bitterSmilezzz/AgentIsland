# 13 · Claude 方案只读采集

## 当前状态与目标

目标是让缺少正文的“确认方案”能够查看对应方案。普通 transcript 的明确 plan 字段仍使用既有按需只读路径；hook 注入正文是独立 opt-in 能力，不将 planFilePath 当读取授权。长期来源与人工关口边界见 [ADR 0030](../../adr/0030-claude-attention-artifacts.md)。

当前已接入正式应用的显式采集生命周期、六个工作台命令，以及“扩展配置”中的折叠入口。默认不启动服务；配置预览、确认和采集启动分别执行。正常启动只恢复明确启用且配置版本仍匹配的服务；demo、后台测试及 UI smoke 不启动接收。引擎关联与正文读取使用同一短期缓存，任务文件仍仅存不可逆引用。已具私有 socket 实际投递→Runtime→正式关联覆盖→任务同步→正式读取的受控组合回归，停用后旧引用不可读且关口保持。

受控回归已覆盖配置、内核接收、生命周期与来源关联；受控页面验证主题、窄窗口、键盘、单次确认与不确定反馈。已在独立目录中运行官方 Claude Code 2.1.291，观察到真实 hook 字段与主消息对应关系，并通过两项显式客户端回归；模型响应来自本机受控端点，未接入真实账号或日常会话。正式应用接收与真实客户端的连续操作、隔离原生验收仍需补齐，不能把模块与页面回归当作完整交付。

## 接收契约

仅接受 PreToolUse / ExitPlanMode，输入最多512 KiB，所有层级重复 JSON 键拒绝。session_id 和主消息 uuid 使用非空规范 UUID，tool_use_id 有界且无控制字符，plan 为非空字符串且最多64 KiB。planFilePath、cwd 及其他无关字段不作为文件读取权限；tool_input 中除注入的 plan/planFilePath 外的内容必须与 transcript 原输入对应。

显式私密标志或已识别凭据拒绝正文缓存；同一已捕获调用后来收到私密正文时旧正文同时作废。凭据形态检测并不保证识别任意敏感文本。Payload、缓存和正文不提供 Debug/Serialize，错误只返回固定类别，不输出输入、路径或正文。

来源只允许接收生命周期提供的可信根，最多2个；目标必须是根内深度不超过5的同会话 UUID.jsonl。Unix逐级使用父描述符 openat/O_NOFOLLOW，核对常规文件、所有者、可写权限、创建身份及目录链；具名路径在校验后仍须指向打开的对象。目录换名后即使硬链接旧文件到新目录，也不复用旧正文。读取验证不改文件、不写用户配置。此关联证明本机来源身份，不证明可编辑的本机记录一定由 Claude 生成；来源鉴权仍由接收通道负责。

## 版本与生命周期

缓存默认关闭，只有配置安装读回与接收服务核对完成后才能启用。启停/配置失效/应用退出清空；正文只在进程内保留，最多32项/2 MiB，每项最多可读15分钟，从首次收到时计时。校验层在投递/关联/读取时清除过期项；macOS接收模块已具每30秒定时清理，单工作线程空闲时用系统poll等待100毫秒，无请求也清理。正式生命周期已接线；接收线程每秒复核配置与显式启动绑定，并在完整帧入缓存前再复核。失效由线程自行停用、清缓存及关闭自有端点，不依赖界面或引擎轮询。文件系统延迟不作绝对时限保证。重复投递不续期、不挤到队尾；容量不足移出最早项。正文或原输入冲突清除该调用正文并保留拒绝状态至原期限，避免旧引用展示不确定内容。

采集不能单独制造任务或“需留意”。语义探针先选中实际未收口主关口，再以会话、目录/文件身份、调用、原输入及主消息版本绑定正文。首次绑定后，同ID的变化消息不能迁移正文；子会话、缺消息身份、已带明确正文的事件不能接管缓存。引用组合路径指纹、目录/文件创建身份、消息/调用版本及正文摘要，不包含可逆原文。读取只接受已绑定精确版本，不通过读取动作绑定新事件；过期、冲突、停止或来源变化时回到来源工具，不用最近方案替代。

## 接收服务与配置安装的实施约束

接收模块已使用macOS私有Unix socket，目录0700、套接字0600，双方getpeereid核对同一有效UID。根/端点所有者、权限、对象类型、设备/inode/创建身份核对；活动或陌生端点不替换，只有确认连接被拒绝的同一自有陈旧socket才移除。停止清正文并通过原目录描述符移除自有socket；根换名/替换时停止，不删除新命名空间对象。该边界限制本机用户，不宣称签名级Claude作者鉴权，也不承诺跨进程命名空间事务。

隐藏入口--claude-plan-hook在设置/引擎/日志/UI初始化前处理，只接受独立参数；有界stdin最多512KiB/2秒，发送与确认另有2秒总期限。只向运行中的私有端点发送，不自动启动应用、不创建缺失端点、不访问网络、不输出决策JSON。单帧长度+正文+写方向EOF，服务端单次交换750毫秒总I/O期限；溢出、截断、额外帧、慢读写、非目标事件及私密正文拒绝。CLI仅成功确认返回0，其他结果返回1和固定“采集未确认”提示，不声称正文一定没收到，不使用退出2或updatedInput。stdout始终为空。语义依据[官方hook退出规则](https://code.claude.com/docs/en/hooks#exit-code-output)，真实客户端仍单独验收。

本机内核回归覆盖收发→生产Store精确正文、重复监听、陈旧/陌生对象、权限/类型、异常帧、滞留和逐字节输入、异常ACK、根替换前/中途、定时清理与停止。状态只含运行/成功确认次数/拒绝次数/最近确认时间；重复投递算一次确认，不宣称唯一计划数。没有在本机另建用户验证跨UID客户端，当前证明是实际内核同UID读取、权限与固定比较分支，完整隔离验收仍保留。

macOS语义探针已计算可信来源/主消息/工具版本，独立于临时正文与缓存启停；元数据齐备但来源身份无法核实时不生成任务来源事件。晚到正文只补到同收据对应的当前开放观测关口，等待步骤共用运行时还要核对该运行的最新收据；不新增运行/关口，不接到旧步骤、人工已处理或已完成事项，不替换已有精确正文引用。过期/停用/移出/重建任务Store的受控回归保持事件指纹与原关口；不同正文版本不读取为旧引用，同ID不同主消息及物理来源替换具有不同版本。缺少hook必要消息身份的旧方言保留既有路径；正式缓存生命周期已接入，仍须完成真实应用/客户端验收，当前受控接口不能冒充原生通过。

仅支持明确默认用户级 Claude 配置目标。启用前展示自有 hook 条目与修改范围；预览绑定配置版本，执行前复核，保留可恢复旧版本，发布后读回，再启用接收。未知内容保留，重复键或含凭据配置拒绝备份/修改，符合项目不存凭据约定。配置凭据检查必须结合字段语义：认证/密钥字段与未知环境变量的非空明文值不能只靠正文形态检测放行；无法核实为普通值或环境/钥匙串引用时拒绝写入。安装器不得额外落盘保存原配置中的凭据。移除只删除已核实的自有条目；外部修改或不完整结果要求重新读取，不自动重试。未启用不采集，配置失效停止并清缓存。

内部配置模块的受控边界：settings.json最多256KiB，所有层级重复键拒绝；只支持默认用户目录，不读凭据文件。预览5分钟内单次确认，目录链/文件创建身份与元数据/配置与所有权内容/当前应用二进制元数据参与版本复核，相同字节的替换也使旧预览失效。配置与所有权发布分别核对，不声称跨进程两文件事务；修改后的异常返回“结果未完整核实”，不允许原确认重复执行。源与应用数据目录逐级描述符读取，未知配置保留。

自有条目须有独立所有权记录且准确匹配唯一ExitPlanMode命令；手工同名或重复条目不接管。应用路径变化后可明确预览更新自有命令或移除旧命令。记录同样严格解析，旧配置与所有权重新检查，原先不存在的配置还原为不存在。最多20份备份，容量满时拒绝新增备份而不自动淘汰旧记录；已具指定记录预览/取消/单次确认移入废纸篓，清理不另建备份，配置与其他记录保持原样。记录、目录链及废纸篓的预览身份变化拒绝，移动后异常明确未完整核实；含认证值的当前配置仍可清理既有安全备份，当前值不会写入清理记录。状态observe读取不消费预览，主动重新读取inspect才取消旧确认。清理预览和配置漂移停用已接线。非空认证字段和所有未知env明文均拒绝备份/写入，已有合法引用仅原样保留，不宣称Claude会解析任意引用语法；目前认证辅助命令等未核实字段也可能保守拒绝。工作台已提供上述入口；这不等于真实客户端验收。

临时正文返回原缓存剩余有效时间，不从读取时重新计时。查看区扣除请求耗时，到期清空 DOM 正文；暂停或配置确认操作触发即时失效提示，来源/服务外部变化通过仅在临时查看期间的五秒复核提示。页面离开后清除正文；后台页不作持续文件读取。文件系统延迟与浏览器调度不保证绝对响应时限。

工作台入口放在扩展/来源能力区域，默认折叠；状态、启停、配置预览与失败重试集中在当前操作区。取消不修改配置，Escape 返回入口焦点；执行不确定时阻止重复确认。仍复用任务正文只读查看区，不添加批准按钮。浅深主题、窄窗口、减少动态与键盘流程必须通过受控页面检查后，才进入真实客户端与原生验收。

## 退出条件

1. 协议与缓存：有界、重复键、来源替换、同ID变更、私密冲突、过期/容量/停用及实际探针/持久引用回归。已具受控证据。
2. 接收通道：macOS模块与内核文件/连接回归已实施；正式应用启停/配置漂移接线已实施并具无消费者轮询停用回归，状态连续性已具生产语义路径与受控文件回归，跨UID原生证据未取得。
3. 配置与 UI：内部配置模块已具版本复核、预览/取消/安装/移除/还原与受控文件回归；指定备份废纸篓清理及非破坏预览的状态读取已具内部回归；正式命令、服务生命周期、容量界面已接线；受控页面已检查深浅主题、360px 无横向溢出、Escape 返回配置按钮、双击仅一次执行、不确定结果禁用修改及记录展开状态保持。真实客户端与原生证据仍缺。
4. 实际 Claude 客户端：官方2.1.291的独立目录测试已验证真实注入字段、主消息身份、精确 transcript 正文读取及权限宿主拒绝后关口收口；该版本会持久化注入正文，临时覆盖层明确不接管。真实账号/日常会话以及正式应用接收的连续操作尚未验证。
5. 原生 macOS 隔离验收与完整交付门禁。仍遵循07，不用模拟结果替代。


## 可重复的客户端取证

仅用于macOS受控测试，不读取日常配置。官方npm包固定为2.1.291，独立安装在忽略目录，禁用安装脚本；测试脚本在运行前核对平台签名与版本。配置目录独立、进程环境白名单、restricted模式、模型只指向本机mock；权限宿主只返回deny，不返回allow、updatedInput或批准结果。脚本保存的原始输入/输出仅在`.scratch/`，不提交。

```sh
npm install --prefix .scratch/claude-real-client/runtime --ignore-scripts --no-audit --no-fund @anthropic-ai/claude-code@2.1.291
python3 scripts/test-claude-plan-client.py
cargo test --locked --manifest-path app/src-tauri/Cargo.toml real_client_ -- --ignored
```

脚本不自动下载或更新客户端，也不构成OS级网络隔离；本机mock验证客户端处理路径，不能证明真实服务或原生UI通过。已观察到该版本的原始tool输入含plan及planFilePath，优先走既有transcript精确读取，hook覆盖层只服务缺正文的方言。官方来源：[安装](https://code.claude.com/docs/en/setup#install-with-npm)、[人工交互工具](https://code.claude.com/docs/en/hooks#tools-that-require-user-interaction)、[配置目录与网关变量](https://code.claude.com/docs/en/env-vars)。
