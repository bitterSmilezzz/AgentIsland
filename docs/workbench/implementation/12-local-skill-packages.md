# 12 · 本地 Skills 安装与恢复

需求 D2 / M3，沿用内建管理方向，核心口径见 ADR 0036。依赖 02、05；同步与跨工具治理的完整目标保留，不将本地安装范围冒充全部完成。

## 流程与界面

工作台 → 模型与连接 → 扩展 → 本机 Skills → 安装与恢复，默认折叠。原生选择含 SKILL.md 的本地目录，取消无写入；完整扫描后显示安装/更新对象、目标文件数、体积与新增/变化/移除差异。前 100 项是显示上限，实际发布完整树。确认期间保护其他配置操作，键盘可查看差异、正反向 Tab、Esc 取消并回发起按钮。

安装/恢复完成后读回并刷新安装记录、失效旧 Skills 启停快照。已有记录刷新失败保留，但禁用旧恢复操作；能力读取失败可重试。选择/预览晚到缓存页时结算，返回重新建立确认保护。五分钟安装预览到期明确取消重选；后端再次检查来源、目标指纹和时间，UI 禁用不替代冲突检查。

恢复记录跨应用重启，恢复前另读文件差异。首次安装恢复移回本次包，同名更新恢复旧包，本次版本仍保留；文件后来改变则拒绝覆盖。无自动脚本执行、无配置启用切换。安装成功与客户端发现分开，需在实际目标客户端核对。

## 技术契约

`skill_files` 负责有界描述符读取、暂存校验与平台发布；`skills_package` 负责版本、短期预览、不可变收据与恢复事实；`skills_picker` 主线程原生选择；后台工作使用独立 managed Store/锁。命令：capability / choose / inventory / sync_preview / edit_read / edit_preview / edit_close / apply / cancel / recoveries / restore_preview / restore / trash_preview / trash，以 `skills_package_` 为前缀。choose 不返回来源路径，目标由元数据名称与固定用户目录派生。

当前 adapter 使用 serde-saphyr 1.3.0 有界解析 YAML name/description，支持多行块、单双引号、转义、注释、别名和合并键；名称为 1–64 小写字母/数字/单连字符，说明须为非空字符串。元数据限 64 KiB、单文档、深度 16，事件/节点和展开预算见 ADR；重复键、无效类型和不支持标签明确拒绝，错误不输出正文。BOM/CRLF 可读，正文及元数据原始字节不重写。同名目录必须核实其元数据名称与目标一致。仅 .DS_Store 作为系统元数据忽略，其他隐藏文件/链接/特殊文件与已识别私有文本拒绝。限额、私有权限与事务位置见 ADR，不作为 CPU/内存预算通过证据。

依据：[官方技能结构与用户级目录](https://learn.chatgpt.com/docs/build-skills)规定 SKILL.md、名称/说明及可选脚本/资源，用户目录为 `.agents/skills`；Darwin SDK `sys/stdio.h` 核对 SWAP=2、EXCL=4 和 renameatx_np 签名。其他客户端发现、格式全覆盖及其他平台仍需独立证据。

## 安装记录清理

每条自有记录提供“移入废纸篓”，首先展示记录及保留包的文件数量、体积与移出路径；确认才移动，不删除已安装目录，不改启停配置。五分钟预览有独立短期计划，可取消，执行前校验整条内容指纹和目录身份。完整包保留在废纸篓，可手动取回；应用内这条恢复不再提供，转移不声称释放磁盘。失败仍保留原件，执行后读回失败明确“已移动”，关闭预览提示刷新核对。无隐藏路径/正文回显。

部分/坏收据记录可单独核实安全结构后移出；额外内容、链接或不可读记录保留，拒绝自动强制清理。废纸篓不可用/跨卷不回退复制删除。100 条安装容量满额可逐项清理；清单完整读取上限512，默认显示最近5条，旧记录通过折叠历史仍可访问，行索引不因折叠改变。清理成功/失败使旧动作快照失效；刷新失败保留清单并禁用动作，取消回发起按钮，缓存晚到预览返回后重新保护确认。

真实沙箱新增5项覆盖完整目录移动、目标/配置不变、取消/期限/漂移/同内容inode替换、废纸篓链接失败与重试、未完成记录释放100项容量、101项可继续清理、身份/结构限制、最大512节点包更新保留514节点记录完整移出。受控生产模块验证取消零移动、错误后旧动作禁用、成功、执行后错误文案、满额安装禁用和清理后恢复、缓存/读取失败、历史对象与焦点；明暗/窄宽截图仅证明组件，不证明原生客户端及整体品质验收。


## 用户级跨工具同步

目标选择为 Codex / Claude Code；原生选择与同步均使用所选目标。默认折叠“同步已有技能”，展开才手动读取固定用户目录，选择另一工具的目录候选后展示“同步/同步更新”、实际目标与完整差异，确认后整包复制。来源和目标相同禁用；来源无效/链接不可预览。目录候选不声称合法技能或客户端已加载。工具专属语法不转换，标准包要求显式 name/description；项目、插件与托管目录不写入。

目录清单失败保留旧项并禁用；一组读取失败保留该组未核实条目，另一组新读取条目仍可预览。来源代次、目录身份或元数据变化要求刷新；确认固定目标，执行后旧安装/来源快照失效。返回缓存页恢复确认保护，执行后错误关闭提示核对状态。记录标明实际目标，旧记录缺目标兼容 Codex，恢复版本包括目标；宽屏同行、窄屏分行，避免目标状态挤压断字。协议与限额见 ADR 0036。

新增5项真实文件测试覆盖双向复制/来源不变/目标独立恢复、相同目标无变化/更新差异与资源保留、旧收据兼容/目标篡改拒绝、代次/来源漂移/父目录链接替换、只读清单/保留命名空间/200项限额。生产 JS + 假 IPC 验证目标切换、取消零写入、失败刷新/部分失败留清单、缓存晚到、发布后错误和重试；明暗620/1100宽组件截图人工核对。原生选择器、客户端发现和整套品质仍需隔离环境验收。


## 正文编辑

已有技能清单增加“编辑正文”，目标为该行原工具，与同步目标选择独立。按需读取纯文本 Markdown；原元数据、资源与脚本保留，不展示 parser 诊断/路径。原始文字通过 textarea.value / pre.textContent 显示，HTML 字符不会执行。草稿变更才开放“预览保存”，CRLF 输入按 textarea 原生换行归一后记录初始值，避免未编辑即显示脏草稿。用户明确“放弃草稿”才清空；关闭应用前需自行保留未保存内容。

预览显示实际目标、文件变化与折叠新旧正文，隐藏编辑框与记录，减少重复内容；取消/Esc恢复草稿、记录及编辑框焦点。缓存页保留编辑 DOM 与内存草稿，晚到读取返回后保护其他配置操作。保存后读回刷新记录和来源，清除草稿；错误保留草稿，执行后错误关闭不能声称文件未改，禁止再次提交该预览。读取30分钟/预览5分钟到期提示保留草稿重读；后台校验不依赖UI禁用。

新增5项真实文件回归覆盖两个目标的正文更新/元数据BOM与CRLF保持/资源与执行位/重启恢复、取消/无变化/读与预览期限/资源漂移、同内容目录替换与链接、凭据/UTF8字节与整文件大小/16项票据/收据不含正文、空正文与无尾部换行元数据边界。生产JS + 假IPC在独立内置浏览器验证未修改禁用、取消保留草稿/焦点、纯文本显示、成功刷新、冲突保留草稿、发布后错误/关闭口径/重复确认禁用、缓存晚到。人工核对浅色620x820编辑与深色1100x820确认截图，未作为原生客户端或全Mac品质通过证据。

目标与记录根目录在发布前后重新沿固定用户路径核对设备/inode，避免外部重命名替换后只在旧描述符读回并误报当前目录成功。恢复/废纸篓转移同样复核，发布后漂移明确已执行并要求核对；30项真实Skills包回归通过。客户端发现与隔离原生目录选择验收仍待完成。

## 真实 Codex 用户级发现验收

生产 `Store` 在临时用户目录安装/更新/恢复完整包，生产 `skills_config` 预览/写入启停，再由真实 Codex CLI app-server 的 `initialize → initialized → skills/list(forceReload=true)` 读取该目录。验收覆盖安装前无项、安装后名称/说明/USER 范围/精确文件身份、停用、包含多行说明与 YAML 别名的更新、跨 Store 重启后的旧包恢复、重新启用及撤销首次安装后无项。保留包/恢复记录不被当成已安装技能。当前证据版本为 codex-cli 0.160.0（macOS）；不能推广为所有版本/工具/元数据语法都兼容。

进程只继承临时用户配置路径和基本环境；macOS OS 策略拒绝网络和实际用户主目录读取，写入仅限临时树，启动前实际验证 socket 拒绝。只发送初始化/发现协议，不调用认证、thread/turn 或配置写协议；脚本输出仅验证结论，原始响应与日志不保存，子进程限时关闭、临时树自动删除。此处是文件与网络隔离测试，不声称已使用隔离 OS 用户会话或通过原生 UI 门禁。

显式运行，常规 Rust 回归不会自动启动第三方客户端：

```sh
AGENTISLAND_CODEX_CLIENT=/绝对路径/codex cargo test --locked --manifest-path app/src-tauri/Cargo.toml real_codex_client_discovers_production_install_update_toggle_and_restore -- --ignored --nocapture
```

环境值只选择测试二进制，不修改实际用户 HOME/CODEX_HOME 或配置。测试脚本 [check-codex-skill-discovery.py](../../../scripts/check-codex-skill-discovery.py) 仅接受仓外临时测试根与显式标记。发现/元数据解析和启停读入不等于模型已注入/执行正文；当前 GUI 自动刷新仍独立保留，Claude Code 对应验证见下节。[官方协议](https://learn.chatgpt.com/docs/app-server)、[官方用户级目录](https://learn.chatgpt.com/docs/build-skills)。

## 真实 Claude Code 用户技能发现与正文加载

生产 Store 在临时用户目录执行 Claude 目标的安装、同名更新、跨 Store 重启恢复旧包和撤销首次安装；真实官方 Claude Code 2.1.291 分别以新会话读取默认用户目录。验收核对初始化的 slash 命令名称、绑定用户技能目录及发送给模型的当前正文标记；更新/恢复时旧正文标记必须缺席，删除安装后不再发现。包内资源脚本不会执行。此结果只覆盖固定版本与标准 fixture，未推广为所有元数据、插件/项目作用域或 GUI 即时刷新。

模型端点为一次性 loopback 模拟服务，不使用真实账号。子进程只继承临时 HOME 与必要环境，系统策略拒绝真实用户 HOME 内容读取（明确选择的独立客户端二进制除外）、其他网络及临时树外写入；启动前实际验证目录列举与其他端口被拒绝。工具列表为空、MCP 配置严格为空，禁用技能 shell 注入和会话持久化；验证器不保存原始请求/响应，客户端临时文件随 Rust 沙箱清理，子进程和本机服务限时回收。使用 user 设置源才能检查默认用户技能；restricted 模式的 builtin 清单不能抵扣该证据。依据[官方技能作用域](https://code.claude.com/docs/en/skills)与[CLI 参数](https://code.claude.com/docs/en/cli-reference)。

显式 opt-in 运行，普通回归不自动启动第三方客户端：

```sh
AGENTISLAND_CLAUDE_CLIENT=/绝对路径/claude cargo test --locked --manifest-path app/src-tauri/Cargo.toml real_claude_client_loads_production_install_update_and_restore -- --ignored --nocapture
```

[check-claude-skill-discovery.py](../../../scripts/check-claude-skill-discovery.py) 只接受仓外系统临时目录与显式标记。首轮模拟端点按完整 URL 匹配而拒绝客户端查询参数，失败记录保留；改为核对规范化路径后通过，并再次核对禁用会话持久化的完整五阶段。不会用静态文件成功或模型回答代替实际发送正文证据；不抵扣真实服务或原生 UI/资源门禁。

## 编辑与来源状态交互

安装能力读取期间展开来源，显示等待；能力返回后读取已展开区域，不要求重新折叠。来源手动读取也登记读取状态，操作完成后统一核对来源。平台明确不支持与尚未读取能力分开；失败保留清单并禁用旧动作，重试恢复。

编辑/编辑预览期间隐藏安装工具栏、来源与历史背景，关闭恢复原有折叠状态和列表。进入编辑及取消预览后只滚动内部区域，使当前编辑区完整可见并聚焦正文，不改变原生窗口几何；读取结束不抢走用户已自行移动的焦点。安装记录满额在编辑区直接说明关闭/清理路径，禁用保存。

写入尝试后结果未核实，确认按钮禁用、取消入口改为关闭预览；保留正文供选择复制，编辑器只读，禁止重新预览重复保存。关闭后进入刷新安装记录，来源也明确待刷新；重新核对后才从具体来源重新读取。普通未执行编辑关闭回到原来源按钮。受控生产 JS/CSS 证明提前展开、失败重试、取消/Escape、焦点、满额、待核对只读和620px/1100px明暗主题，未替代原生 WebView/目录选择/整体动效与资源验收。
