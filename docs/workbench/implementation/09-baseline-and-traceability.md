每个相关批次开始时记录当前功能入口和受控数据baseline，勿将真实用户会话截图或凭据作为夹具。表中证据是需要获得的结果，不是本轮已经运行的测试。

资源baseline至少记录：构建版本、机器/系统/WebView、监控工具与数量、窗口形态、采样间隔、静默或运行场景、持续时间、CPU/RSS/唤醒/读取量。比较时保持同场景，区分热身与稳态；发现增长记录峰值和是否回落，不只报一次RSS。帧检查记录掉帧/额外几何提交与具体路径，不能仅凭“感觉丝滑”判定通过。

数据baseline记录旧todos/settings/profile受控样本、schema与兼容需求；故障注入包含权限拒绝、磁盘写失败和损坏文件。备份保留完整性，文档/导出/日志仍用脱敏字段；不能为扫描通过删坏用户原件。
