# 本机工具预算

此模块推进 NEW-06 的内建用量治理与 KEEP-03 的预算能力。入口位于工作台用量分析，默认折叠；灵动岛沿用简洁提醒与工具跳转。

## 口径与来源

度量与工具卡片同源：已采样的 `token_usage.tokens24h`，滚动24小时净消耗，缓存读取不重复计入。未取得快照或监控关闭时用量为未知，不能显示0或生成越线提醒；真实零记录显示0。页面只读取引擎已有快照，手动刷新不触发额外日志全量扫描或网络请求，展示快照不代表实时服务账单。

按工具设置预算，不按当前档位推断历史接口。现有账本缺少可信接口身份，因此接口预算、账户余额、云端账单与路由执行仍待独立实现及验收。预算只提醒，不阻断请求或关闭进程；整体预算与工具预算是独立作用域，可以分别提醒。

## 后端契约

`Settings.tool_token_budgets` 持久化工具ID与整数上限；0删除，最大1e9，归一化保留有界合法ID、最多128项。旧设置缺省为空。`tool_budget_list` 返回工具名称、上限、可选用量、来源与阈值状态及提醒开关；不包含文件内容或凭据。

`tool_budget_set(agent_id, budget, expected_budget)` 只修改一个工具，验证工具身份、区间和当前上限；引擎锁覆盖比较、原子设置写入与内存发布。失败不更新内存，其他设置保持；常规设置patch不能绕过逐项比较覆盖整张预算表。此保护针对应用内窗口，并非跨进程文件事务锁。

提醒沿用预算开关与通知策略。每工具独立80%预警、100%超额、低于75%重新武装；没有数据或关闭提醒时不消费跨级也不重新武装，恢复后按已有级别继续。修改预算复位所选状态机，删除预算清理记忆。提醒以工具ID归属，内容标明本机滚动口径；汇总预算不能精确绑定某一条会话。

## 交互与生命周期

展开才读取；切工具保留各自草稿，刷新保留未保存输入及其原始比较值。冲突后须核对当前预算，取消草稿才采用新值，避免静默覆盖。保存中禁止再次写入或切换编辑工具；切页允许，后台完成继续更新被缓存的原页面。读取失败保留已有列表，写入失败或回执丢失保留草稿。

首次展开优先选择需留意的预算，其次已设预算与已有消耗的工具。保存禁用输入后，在当前页面仍展开且用户未移走焦点时恢复输入焦点，便于失败后用Enter重试；后台缓存页不抢焦点。

控制器为全部工具草稿及进行中的请求维护工作台生命周期标记，不把工具选择视作未保存设置，也不因当前工具无草稿而丢弃其他工具输入。原生表单提供标签、状态播报、焦点样式、Enter提交与Tab顺序，窄窗动作换行；局部动效遵循减少动态设置。

## 验收

后端覆盖未知/零/停用、阈值滞回、两工具隔离、关闭提醒、预算变更/移除、持久化、同项冲突、失败零发布及容量上限。控制器覆盖独立草稿、保留旧比较值、明确取消、失败/丢失回执、进行中的写入互斥；页面以实际生产模块和受控IPC夹具验证主题、键盘、缓存切页和重试。正式包隔离原生流程与全量回归独立记录于本轮审查，浏览器夹具不等于原生验收。此模块不证明整体macOS计划或资源预算已完成。
