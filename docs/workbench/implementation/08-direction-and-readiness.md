## 2. macOS范围冻结与变化流程

macOS本轮范围为整体方案M0–M4和07的A–E：现有体验收敛、共享UI/契约、本地任务、三种窗口布局、内建档位/模型/接口治理、任务关口与快照流程，可选只读连接作为辅助。范围不包括完整团队编排、云同步、远程执行、全工具配置写入、供应商账单全覆盖或所有应用精确定位。

来源能力验收分三种：已核实协议的工具验证正确会话；仅应用入口验证正确工具且提示限制；无入口明确不可用。不能为了“macOS做完”无限追逐所有工具协议。

对外服务适配按实际证据交付：有已验证API和权限的模块完成对应只读流程；未验证项不得显示为已连接。接口不具备证据时记录技术缺口及降级入口，不能将全部网关能力列成Mac首版承诺，也不能将仅打开控制台称为服务接入完成。

需求变化记录：具体场景 → 与当前范围的差异 → 数据/性能/权限/交付影响 → 建议批次。涉及改变产品角色、自动执行/批准、新增云端数据流、平台顺序或扩大Mac退出条件的变化，必须取得用户明确决定后更新规格；普通布局、代码组织、参数校准和错误文案在已授权范围内自行处理。待定项必须有降级方式，不能靠猜测消掉。

## 3. 四种状态必须分开

1. **通知已读/关闭**：只移除横幅或推进通知队列，不解决来源任务。
2. **本地标记已处理**：只关闭本地人工关口，保留手动处理说明；来源状态尚未证明改变。
3. **来源已回答/批准/验收**：有匹配任务、run、artifact版本的可信事件才更新来源记录。
4. **执行结束/失败/被中断**：是运行状态，不等于人工验收或满意度。

状态视图优先级：open人工关口 → 需处理；失败 → 需处理且标执行失败；running → 执行中；其他终态 → 已结束。ready有待验收关口时仍在需处理，没有可信验收关口时写结果就绪，不能擅自生成批准请求。

手动新建Agent任务无run时仍可归档/恢复；归档是本地组织动作，不向工具取消执行。来源running的任务归档也不能伪装执行已停止。归档记录保留历史，物理删除/长期保留策略在存储规格中单独定案。

## 4. 可信来源和导入边界

可观测字段分级：纯进程证据仅支持在线/资源；语义会话支持状态/来源；明确关联的生命周期事件才支持任务run更新；文档/问题版本事件才支持细分人工关口。只有文字“完成”“确认”不能建立精确task/artifact关系。

收集标题与摘要不意味着可原样永久保存会话全文：任务标题由用户输入，自动来源只提取必要字段，凭据/密钥内容不持久化、不进入日志或导出。无法可靠提取安全摘要时保存类型与来源引用，显示时按需读取；导出采用字段白名单，禁止直接序列化原始source或响应。

来源字段不足时保留现有通知；不把任意外部notify升级成可信批准事件。手动关联与系统观测来源分别标识。工具升级导致字段失效时能力降级并给原因，不抓最近记录代替。

## 5. 开始实现前的工程门槛

| 检查 | 必须得到什么 | 不满足时能否继续 |
| --- | --- | --- |
| 工作区基线 | 当前branch、最高tag、版本漂移、累积改动范围、相关测试结果有记录 | 只做独立诊断，不重置已有工作 |
| 功能保留表 | 当前能力→页面/命令→对应验收场景可追溯 | 不开始移动/删除入口 |
| 首批复现 | A1具体路径、原生几何/采样时间、成功信号 | 可做取证，不能宣称动画问题已解决 |
| 数据写入 | 旧数据兼容、单写方、revision、坏文件/磁盘满行为 | 不接真实写入 |
| 来源与平台 | 能力表、身份字段、降级规则 | 支持未验证展示，不执行猜测动作 |
| 服务API | 版本、授权能力、受控响应夹具 | 可做通用页面，不开启未知服务调用 |
| AX原生探针 | 权限、身份、坐标、可写属性验证 | 可做纯布局/fake测试，不移动真实工具窗口 |
| 发布环境 | 真实隔离UI会话/VM、release与ui-smoke调用衔接 | 可以开发与受控验证，不能宣布发布完成 |

本轮源码核实：release.sh直接调用 `scripts/ui-smoke.sh`，而ui-smoke.sh要求 `--isolated-session`。修复必须同时确认真实隔离环境和调用方式，不能只自动补旗标骗过检查。它是已知交付阻塞，不是用户尚未批准普通开发。

## 6. 技术参数在哪一批锁定

- A1：原生/表面几何协调与证据格式；初始动效时长可调整，但必须验证中间帧。
- A2：页面生命周期、草稿保存键、共享组件/token；避免把transport拆成只有透传而没有契约价值的多层包装。
- B1/B2：实体ID生成、来源字段白名单、revision作用域、去重收据、任务文件损坏策略、摘要上限与容量指标。单写方成立再接真实数据。
- C1：AX能力、显示器坐标和窗口身份，不提前将窗口标题当稳定ID。
- D2：内建工具适配的配置格式、作用范围、协议、差异/备份与冲突契约；逐工具验证。可选外部服务另行核实版本、响应、凭据引用与权限，不抵扣内建功能验收。
- E：资源实测预算、支持Mac环境与发布出口；数值须来自基线与场景，不为显得完整捏造MB/FPS承诺。

这些属于技术验证和规格补全，不需要用户逐项决定库名、字段长度或函数组织。越过已定产品边界时才提出具体选择。
