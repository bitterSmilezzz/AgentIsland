# 18 · 受管理运行的项目授权与执行者身份

日期：2026-11-07。领域决定见 [ADR 0043](../../adr/0043-managed-run-project-authorization.md)；策略版本锚见 [ADR 0044](../../adr/0044-managed-run-policy-anchor.md)；自有历史数据策略见 [ADR 0041](../../adr/0041-managed-history-data-policy.md)。本文记录授权判据、策略存储、显式用户确认接线与仍未开放的执行链路。

## 当前实现

`app/src-tauri/src/managed_run_authorization.rs` 提供纯授权模型；`managed_run_authorization_store.rs` 提供独立本地策略存储和项目根身份核验：

- 新项目默认不允许运行，也不采集历史。
- project/task/run 身份在绑定时固定；跨项目、跨任务和跨运行替换均拒绝。
- planner、executor、reviewer 分别授权；一个角色不能借另一个角色的项目 grant 执行动作。
- 运行快照绑定项目授权版本、历史策略版本、稳定 runner ID、runner 进程代次与 claim version。权限变更、runner 重启或重新认领会拒绝旧快照。
- 历史写入要额外通过显式 opt-in 与当前策略版本检查；关闭历史不会改变规划/执行授权。
- 版本不能递增时拒绝且保留旧状态。标识符采用受限字符集合；不接受路径、标题或凭据作为身份。
- 项目运行 grant 不包含 Git 推送/合并、发布、通知发送或网关请求权限。
- 独立的 `managed-run-authorization.v1.json` 缺失时无授权、无历史采集；未知字段/未来版本、损坏、符号链接和原子发布失败时拒绝并保留现存字节。
- grant 记录固定 project UUID、规范根路径、卷身份和文件身份；Unix 使用设备号/inode，Windows 使用卷序列号与 128-bit 文件 ID。移动、替换或经符号链接重定向根目录后，旧 grant 不复用。
- grant/角色变化与历史采集策略分别递增版本；撤销保留版本墓碑并清空授权内容，溢出拒写。Unix 策略文件要求仅所有者可访问。
- 项目管理页用系统目录选择器展示规范路径，并要求逐项选择角色后确认；新项目不预选角色，历史采集默认关闭。
- 后端通过 5 分钟一次性候选令牌绑定项目 ID、策略 revision 与目录身份；身份不回传给 UI，确认时重新验证候选的原目录，不根据 UI 路径重建身份。取消选择或草稿不写策略文件；用户可以显式撤销或修改历史策略。
- 已授权项目不能直接删除，必须先撤销；策略文件损坏或无法读取时删除也拒绝，以免丢失唯一的撤销路径。
- 策略文件内部格式为 v2，固定随机 epoch；macOS Keychain 锚绑定 epoch、revision 与策略原始字节摘要。进程互斥锁加 OS 文件锁串行 revision 比较和写入；pending 日志只在目标摘要精确匹配时恢复。
- 策略文件被回放、删除，或只恢复旧锚时全部 fail closed。锚缺失但文件存在时，旧授权不回显；用户必须重新选择目录与角色，生成新 epoch，并逐项目重新确认，旧 grant 不继承。锚损坏、不可读或恢复目标不唯一时拒绝且保留策略。
- Windows/Linux 的本地授权明确保持关闭；只在 macOS 构建中加入钥匙串后端，避免未验收的系统凭据依赖进入其他平台。
- 存储和候选层目前有 30 条定向 Rust 用例，覆盖文件/锚回放、删除、升级再确认、恢复日志和跨进程锁；项目授权 UI 浏览器回归覆盖取消、路径预览、角色、历史默认关闭、显式开启和撤销。v0.0.437 候选的隔离 macOS VM L5 门禁已通过：实际 Keychain create/read/update/delete 与 UI、Dock、单实例、CLI、窗口生命周期共六项均通过；回执在 `.build/vm/acceptance-a95f156f1abf4a5cbb20a8470cb992a7/receipt.json`，来宾 macOS build 为 `26A434`。

## 安全边界

判据只说明调用方必须满足哪些要求，不负责证明 runner 身份。`VerifiedRunner` 只能由应用内部在核验本地进程/认证会话后构造；当前还没有该启动器。授权 UI 只写本地策略，不会启动 Agent，也不能把前端任意 JSON 当作目录身份或授权主体。

权限变化会使既有快照失效；实际 runner 尚不存在，因此当前没有撤销后停止进程的实现。macOS 的系统凭据锚识别单独回放策略文件；完整系统钥匙串快照回滚与同账户直接篡改凭据不在保证范围内。凭据与策略丢失时不自动重签；当前也没有一键恢复/重置 UI。策略不提供导入/恢复 API。runner 握手/停止、TASK-05 密文写入与生命周期，以及 Windows/Linux 原生凭据验收仍未完成。
