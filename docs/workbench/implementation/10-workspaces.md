# 10 · 本地工作空间组合

承接整体方案 §4 工作空间、融合方案 §8 E，NEW-06/UX-02；不以连接上游工具完成组合能力。

workspaces.v1.json 独立保存 schema_version/revision/items，组合含 UUID、名称、可空项目 UUID/档位 ID/布局 UUID、已登记工具 ID。只存引用，不复制配置、会话、窗口标题、句柄、位置或凭据；上限 50 个组合/256 KiB，至少有一项引用，名称唯一，存储格式严格。单进程写锁、revision 与原子落盘；坏/未来格式、链接文件及容量失败保留原件。源模块保持各自存储与治理。

workspaces_list/workspace_catalog/workspace_save/workspace_remove/workspace_preview 在后台执行。目录由任务、已保存 Codex 档位、窗口规则与工具注册表取得；项目/档位各最多 200 项，档位源读取最多 1 MiB、只输出 ID/名称/支持标志。来源部分失败分项提示，未引用的失败不阻塞有效组合。保存核对所选引用，预览重新解析；删除、不支持或重复身份不替换为最新对象。目录读取不是跨存储事务，实际配置/窗口应用仍须各模块再次核验。

工作台提供组合列表、折叠编辑、逐项核对区。项目步骤筛选对应任务；档位定位到原预览入口；布局只选中对应规则，用户载入、预览再应用；工具定位到管理项，缺管理项明确提示。打开不执行配置或窗口写入，不启动工具。关闭/Escape 回到入口，切页保留 DOM 草稿，刷新与失败不清输入；不在缓存中持久化正文或凭据。

当前已接入本地组合、分项定位和当前窗口内的分项执行收据/恢复入口。实际配置写入与逐窗执行复用原模块，执行前再次核对组合版本；修改载入规则内容后不归入原组合。配置记录失败与逐窗部分失败独立展示，返回组合继续其他分项，恢复定位原备份/操作，不自动写入或覆盖冲突。切页结果绑定原组合，执行中禁止换组合，失败保留此前恢复身份；组合变更重新核对。配置分项另有后端持久历史，窗口收据仍只驻当前运行期；两者不代表当前配置加载或窗口位置。

沙箱/纯数据浏览器证据见本轮 review；配置重启历史见下文；窗口跨重启恢复、一键跨模块执行与补偿事务尚未提供。原生品质、多屏及资源仍按整体方案退出条件继续验收，未宣称 E/M4 已完成。

配置分项的底层操作返回写入收据与备份名；写入后的应用记录保存/清除失败作为独立警告，不能丢掉已经发生的配置变更与恢复入口。还原也返回还原前备份名。工作空间按实际收据聚合分项结果；查看项目/工具不计为应用成功，分项受控验证不计为 E 原生验收完成。


## 配置操作持久记录

workspace-operations.v1.json 保存后端执行的配置分项元数据：操作 UUID、工作空间 UUID/版本、档位引用、恢复来源操作、时间、pending/applied/restored/failed、备份名和警告标志。没有配置正文、路径、会话或窗口标题。固定 schema、200 项/512 KiB、普通文件及原子替换；超限/损坏/链接失败保留历史，不自动裁剪。没有接收前端任意成功收据的写入命令。

workspace_apply_profile / workspace_restore_profile 复用原 Provider 写入，在工作空间锁内核对组合版本/档位引用，写入前保存 pending，命令返回后记录实际结果。恢复还核对原记录属于同一组合/档位且备份名精确匹配。预览、配置/备份版本与凭据保护仍由 Provider 执行。记录预写失败不执行配置操作；配置已写入但最终记录失败返回独立警告与备份，pending 留待核对，不自动重试。

workspace_operations 按组合读取历史。重启后历史与本次执行区分；待核对/失败保留最近可信备份入口，目标引用不同不加载旧收据。恢复重新进入原模块完整预览确认；不将历史视为当前客户端生效。配置外部变化、完整恢复与客户端加载仍按原门禁核对。窗口句柄/撤销不持久化，跨模块补偿与断电事务尚未提供。

故障边界使用独立可注入的 execute 接缝回归：记录预写失败不调用配置闭包，配置已发布后外部修改记录文件使 finish 失败时保留该文件、返回原备份和独立警告且不返回可持久恢复操作身份；失败的配置闭包保持原错误并记录 failed。组合身份/版本/档位删除或变更在创建记录前拒绝。

窗口分项的持久关联已接入原有排列journal的可选workspace字段，无第二份几何副本；普通预览后台核对规则模板/间距/工具顺序，当前组合和规则版本在实际执行时再次复核。窗口历史按组合过滤，恢复入口定位具体记录，重启后逐窗选择同工具当前窗口/预览/应用；恢复产生新关联记录，执行后结算警告保留实际结果和live undo。已在文件回归模拟重启及受控网页验证，不抵扣真实AX、多屏、资源和原生动效验收。配置与窗口历史统一折叠展示，最近五条窗口/混合记录后可展开；历史读取失败有独立提示，当前页面结果不冒充当前状态。
