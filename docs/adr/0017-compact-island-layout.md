# ADR 0017：紧凑灵动岛的信息层级

状态：接受。日期：2026-09-30。

收起态的视觉把手为 64×5（纵向 5×64），交互窗口为 88×17（纵向 17×88）。视觉与热区分开，内侧保留 12 点唤回区域，沿长度两端各留 12 点。状态点只表达实际工作或提醒；隐藏设置使整个把手透明，热区仍可用。

展开态使用同一中性圆角容器：标题状态与工具栏并排，监控卡片宽度为 300px，分析与设置页保持 330px；窗口按实际卡片宽度落位。智能体列表按名称、运行状态、24h 用量和当前动作分层。活动环看板与列表重复展示同一批智能体，因此主列表只保留一份；详情仍保留详细用量与按模型拆分。底部单行并列显示 24h 与累计 Token 指标，整栏进入完整分析页；费用与详细单位说明由分析页承载。

参考 UI Research 08/09 的信息分区与中性层级、12 的单一胶囊身份及 10 的动效停顿规则。常驻状态只在小点上低幅呼吸，展开入场只发生一次，周期采样不反复播放；减少动效时静态呈现。窗口定位和状态判定沿用 Rust 实现，不由外观推断状态。

普通行保留名称、状态与 24h 用量，最近活动时间进入详情；工作与待确认行保留单行当前动作。顶栏不重复列出当前动作，底部摘要同时承担唯一的用量分析入口。收紧留白与图标尺寸，操作按钮保留 24px 热区及键盘可达性。

顶栏普通状态使用稳定的智能体标题与数量摘要；确认和告警突出来源并保留排队数。常驻操作仅搜索、设置、收起，外观在设置中选择。状态点与文字摘要使用同一状态优先级。

设置面板采用稳定高度与独立滚动正文，返回栏固定。自适应窗口不能用其自身 vh 百分比约束目标内容，否则尺寸回授会不断缩小。顶部图标保持统一描边与视觉尺寸，热区仍为 24px。

页面导航使用短淡入与轻位移，进入比返回稍慢；仅路由变化播放，采样与数据注水不重播。灵动岛尺寸缓动到目标尺寸，连续导航取消旧目标，减少动态效果时直接切换。

导航过渡保留短暂的旧页视觉副本，退出与进入交叠，避免清空旧页后的闪入。副本 inert、aria-hidden、无重复 ID，结束立即移除；既有导航和采样不会与副本交互。尺寸使用平缓起步与收尾，与内容过渡保持同一时长。

灵动岛导航由持久卡壳与独立 motion 控制器协调。原生窗口只在过渡开始预留旧新尺寸的最大包络、结束收回目标尺寸；容器以 WAAPI 改变宽高，正文按目标宽度排版，避免逐帧 IPC 与文字缩放。标题先交接、正文稍后进入；中断时接续可见几何和透明度。引擎采样不重建过渡中的页面，返回监控后立即补上最新状态。键盘焦点回到对应入口或返回按钮。

原生窗口落位完成与 WebView viewport 更新是两个时点。返回导航保持最终固定几何，等待 viewport 匹配并经过下一次绘制后才清理过渡、恢复采样布局；有界等待避免平台缺失反馈时永久锁定。设置首页只显示外观、贴边、通知策略、提示音、快捷键和开机自启，其余设置默认折叠；所有设置仍使用同一字段表与保存/回滚通道，布局紧凑不以删除能力为代价。

macOS 原生包络通过一次 AppKit frame 提交同时设置位置、尺寸并重绘，返回结果代表主线程已执行，仍等待 WebView viewport 反馈。列表采样增减当前动作导致高度变化时，只缓动表面，保持正文和焦点；尺寸未变时不启动过渡。健康度在列表以观测不全、需留意、有异常、需处理表达，分数只在悬停说明中出现，健康状态不占位。
