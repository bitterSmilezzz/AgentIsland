# 0020 — 本地任务与来源关口分离，轻量界面共享投影

状态：接受。日期：2026-10-04。

## 决策

旧 Todo 是简单清单，保留原 ID 和 done 语义。Agent 任务单独存储项目、Task、Run、Attention、Artifact 引用与来源事件去重记录；当前 run 决定任务分组，不额外持久化看板状态。

来源执行、人工等待、结果就绪与来源验收分开。打开来源只是导航；本地标记已处理不会批准工具操作，等待处理后没有继续执行证据时回到 queued，结果就绪保持 ready。accepted 仅保留给可信验收事件，首批不从本地操作推断它。

人工关口记录 observed 来源证据标识，与 manual_resolution 分工：前者说明关口由语义观测产生，后者说明处理记录由用户在本地标记。缺 observed 字段的历史记录不能补推为可信来源事件。手工记录不能借用另一条来源提问或隐藏仍需处理的真实来源提醒。

灵动岛、侧栏与工作台概览使用同一只读投影：当前未归档任务，每个任务计数一次；回答、方案、结果验收优先，执行失败单独计数。历史/过期/已处理关口不计入。资源异常属于健康通道，不计为待批准任务。轻量界面最多一条事项与数量，具体编辑和运行历史在工作台。

仅当来源关口有观测证据，且明确对应同一会话 URI，才省去同一条语义提醒的重复正文与动作；外部提醒、资源异常、未验证精确跳转的工具、手工关口保留各自入口。

绑定使用后台观测身份，点击复核任务、当前运行与聚合 revision；UUID 历史会话不替换为最新文件。工作台导航按窗口投递，未创建窗口排队，不能改变岛/侧栏路由。

所有界面事件在引擎和任务写锁释放后发出；隐藏窗口停止摘要读取和周期任务重画，恢复时读当前状态，保存回执仍可归属缓存页。摘要不把会话全文、路径或密钥持久化，现有语义提问只在匹配来源的当前界面临时呈现。

## 代价

单个聚合文件仍按版本原子写，容量达到保护边界后明确拒写并保留历史。数据库来源身份和计划/结果自动引用需分别核实接入，不能用虚构标识或正文猜测填补。投影与模拟 UI 回归不替代原生窗口、导航和交付门禁验收。
