# ADR 0026 · 档位读取兼容与协议写能力分开

状态：接受。日期：2026-10-04。

当前 Codex 官方配置参考仅支持 Responses。AgentIsland 的 Codex 档位保存、捕获及应用计划按当前协议能力校验，拒绝写入 Chat；结构解析继续兼容历史 Chat 档位，使旧清单仍能查看、删除和导出。导入保留旧协议但不授予应用能力；用户核对目标接口后才能明确编辑为 Responses，不自动迁移已有数据。

工作台档位、目录选择和重应用同一协议规则，禁用时说明原因。服务端是否实现 Responses、模型是否可用以及当前运行会话是否改变是独立证据，不由配置写入成功推导。完整历史备份还原保持原文，不进行隐式协议转换；整份配置的客户端可加载性另行验证。

代价：使用历史客户端或只支持 Chat 的接口的档位不能直接应用；后续工具/协议扩展须由适配器和证据启用，不恢复无条件写入。依据 [官方配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。
