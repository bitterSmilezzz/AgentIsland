# 0021 · 窗口布局保存规则，不保存实例身份

状态：Accepted（2026-10-04）

窗口标题、AX 对象、PID 和系统窗口 ID 都不是跨启动可复用的布局意图；主屏与工作区也可能随显示器连接变化。

采用独立 `window-layouts.v1.json`，只保存规则 UUID、名称、工具偏好顺序、模板、间距和主屏/重新选屏偏好。聚合 revision、大小/数量边界、严格 schema 与原子替换保护原文件；坏文件、未知字段、未来版本与符号链接拒写，不以空清单覆盖。读取或保存错误不包含文件原文。

保存选择只能从后台当前窗口快照解析，不接受前端传入工具身份或任意窗口对象。复用时重新读取并以当前 revision 解析；仅当每个偏好工具恰有一个可调整候选且枚举完整时自动填入选择。同工具多窗、缺失、受限或读取不完整均要求人工选择，不按最新窗口或标题猜主窗。副屏规则要求重新选屏，不持久化屏幕指纹或旧坐标。

载入规则只改变页面偏好，不产生预览、移动或授权。用户仍需核对窗口、预览并显式应用；规则从不作为绕过实时身份、权限、桌面可见性或撤销冲突检查的凭据。
