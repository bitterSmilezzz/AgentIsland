# ADR 0018：界面品质以证据验收

状态：接受。日期：2026-10-03。

以 Awwwards / FWA 获奖作品的完成度作为设计方向；对 AgentIsland 的常驻桌面界面，品质体现为克制的信息层级、稳定的空间定位、连贯的表面变化和一致的控件细节。奖项目标不是自我认证，也不是增加特效的理由。

每轮界面改造先建立能失败的复现信号，再实现和反复目视核验。动效必须覆盖四个贴边方向、进入与返回、异步内容和快速中断；检查结束跳帧、反弹、残留副本、焦点与减少动态效果。设置检查默认首屏、全部字段可达、浅深色、键盘、保存失败回滚和字段语义。紧凑布局不能删掉能力或把未知数据写成零。

模拟数据截图与逐帧检查用于快速迭代；新构建必须重启后进行原生核对。独立 review 记录每轮具体发现、修正、命令结果和未通过的门禁。版本、脱敏、回归与隔离原生 UI 门禁仍遵循既有发布链路，其他验证不能冒充这些门禁。

本轮可执行清单和流程见 [界面品质基准与验收](../workbench/24-interface-quality.md)。清单随检查发现细化，本 ADR 保存长期决策。
