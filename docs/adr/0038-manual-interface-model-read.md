# ADR 0038 · 手动读取已配置接口的模型清单

状态：接受。用户已明确允许手动读取所配接口，包括厂商官方 HTTPS 地址。本决定替代 ADR 0009 中对这一具体动作的全面禁止；通知凭据、OAuth、用量与账单边界继续成立。

用户在接口目录主动点击后，应用可对已保存的 Codex Responses 档位发送一次 `GET <base>/models`，保留地址前缀。只接受 HTTPS 或字面回环 HTTP；不猜地址、不扫描端口。凭据只从该档位声明的环境变量临时读取，不能复用通知凭据、登录态、OAuth 或命令认证。请求禁止重定向、代理和自动重试，等待与响应大小有界。

响应只提取经过校验的模型名称、数量、截断标记和读取时间；不输出正文、认证值或任意远端错误。结果只留在当前页面的有界内存中，保存档位身份改变后清除；普通读取失败保留标时点的上次成功结果。选择模型只填入编辑器草稿，保存与应用继续使用现有预览、冲突和备份流程。

清单可读不证明生成权限、运行中的模型、配额或账单。启动、切页和刷新配置都不自动读取服务模型；不发起生成请求、不刷新 OAuth、不转发智能体请求，也不据此开放其他厂商 API。额度、服务用量和网关执行需分别决定与验收。技术细节及验收见实施方案 [05](../workbench/implementation/05-models-and-connections.md)。
