# ADR 0034 · 内建提示词与用户指令

状态：接受。日期：2026-10-04。

AgentIsland 自行管理本地提示词，库 CRUD 与实际工具指令写入分离。首个可写适配为 Codex 用户级 AGENTS.md，路径由后端按 CODEX_HOME 解析。显式预览完整正文替换，绑定库/来源/覆盖文件版本与目标内容；先用不覆盖机制备份，复核、原子替换并读回。还原同样绑定备份内容并保留还原前正文，不自动批准、执行工具或改项目规则。

非空 AGENTS.override.md 优先，故拒绝用户级 AGENTS.md 应用而不是提示已生效。项目规则与新会话加载需在工具内核对。默认合并文档容量限制不能由本应用单文件校验保证。缺失原文件的还原是空正文写入，不恢复不存在状态。Store 锁不是跨进程事务；有界普通文件读取、严格格式及已识别凭据检测失败保留原件，检测不是通用秘密识别器。

代价：暂不合并个性化段落，不适配未核实工具，不将上游连接入口算作能力融合。备份历史不自动裁剪，超限明确失败。官方依据见实现文档 11。

适配扩展：共享库支持 Claude Code 默认用户级 CLAUDE.md，目标身份进入预览哈希，各工具独立备份与还原。现有 Codex 路径和备份位置保留；前端仅选已核实工具枚举。Claude 自定义启动环境不可从桌面进程完整观测，默认目录能力必须明确展示，应用自身继承自定义目录时拒绝写入。其他规则与导入不展开，新会话加载须在原工具核对。
