# ADR 0028 · 数据库任务来源身份

状态：接受。日期：2026-10-04。

任务来源由产生语义信号的同一条查询带出稳定主键，不以整个库路径代表一个会话，不二次读取“最新会话”配对。Dim、OpenCode、MiniMax 的会话主键与状态索引主键是内部证据；ZCode 使用工作区/任务复合键。内部上下文不序列化原路径或键，界面与任务文件仅保留来源工具和不可逆指纹。缺键、坏键或路径与声明不符拒绝绑定，状态观测仍可保留。

事件版本与会话身份分开：更新时间改变只生成新观测，不重建来源身份；现有通知指纹维持原语义。活动来源以同一行的事件时间判断，未来/未知时间及进程退出拒绝，时间差必须保护溢出；OpenCode/MiniMax 不将未来事件解释为当前活动，文件来源仍用文件年龄。已结束运行后新的等待事件另起运行，保留历史，不推导已验收。

代价：只能识别已核实数据库方言且当前有语义证据的来源；库位置迁移/重建、未观测中间状态和真实客户端导航需要独立证据。持有会话主键不等于支持会话 URI；未核实的导航明确降级。无需安装 Todos 或任何上游任务工具。
