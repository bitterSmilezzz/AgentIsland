# ADR 0041 · AgentIsland 自有执行历史的数据策略

- 状态：接受。
- 日期：2026-11-01。
- 依据：用户确认 TASK-05 自有执行历史数据策略草案。

## 决定

1. 自有执行历史只记录 AgentIsland 获得项目授权后自行创建的受管理运行。项目默认关闭采集；普通 Todo、外部工具会话、本地产出版本以及来源事件正文都不自动迁移或复制进来。来源正文继续遵循 [ADR 0029](0029-source-artifact-content.md) 的瞬时只读契约。
2. 采集启用、授权身份和内容策略必须按项目核对；运行固定项目、运行、执行授权与策略版本。项目 ID 只表示本机数据归属，不代表远程身份或团队授权。策略未启用、身份不匹配或授权缺失时拒绝写入。
3. 正文与可识别内容元数据落盘前使用认证加密；每项目独立随机 256 位数据密钥，AEAD 使用随机 nonce，附加认证数据绑定格式版本、project/run/artifact/content-version。密钥只进执行历史专用的系统凭据命名空间，绝不复用通知密钥或现有本地产出 blob/配置备份格式。禁止明文回退。
4. 首期密钥适配器为 macOS 钥匙串专用命名空间 `com.agentisland.managed-history.v1`。项目密钥通过 `SecItemAdd` 语义原子创建；重复账户返回冲突，不更新旧密钥。凭据库锁定、访问被拒、密钥缺失或格式异常时拒绝读写并保留原密文。Windows/Linux 在独立适配器和原生验收完成前拒绝写入口。
5. 留存默认由用户手动删除；自动到期清理须显式启用。每个启用项目有有限容量，容量满时拒绝新写入，不静默驱逐既有历史。容量上限、期限范围和到期提醒方式须在磁盘/资源实测后确定；在测量和 UI 策略完成前不开放采集。
6. 删除按 project/run/artifact 精确预览并确认。项目密钥删除成功后，本机残留密文不能由应用解密；单条删除只承诺应用层不可见和文件清理，不承诺清除 APFS 快照或外部备份。删除失败须保留可恢复结算状态，不能报告成功。
7. 备份只由用户显式发起；导出整体加密并要求当次口令，不保存口令。导入先完整校验整包，之后才原子发布；损坏、错误口令、未知格式或项目 ID 冲突导致零写入。无自动云同步。
8. 不把 `tasks.v1.json` 提前迁到 SQLite；满足 [ADR 0011](0011-local-state-storage-and-migration-triggers.md) 的实测迁移判据后再单独决定。

## 当前实施边界

本 ADR 定案的是数据安全与生命周期契约，不宣告完整功能已交付。TASK-03 的真实执行授权不存在时，项目策略、正文存取和 Tauri 命令不得接入可写运行入口。实现分片与验收仍按 TASK-05 当前实施计划推进。

当前首片只实现加密封套和 macOS 项目密钥接口；容量/期限数值、加密文件存储、策略快照、删除事务、备份恢复、UI 与 Windows/Linux 凭据库仍须逐片实施与验证。

## 代价

- 钥匙串不可访问或密钥被删除后，应用不会尝试猜测、重建或明文恢复数据；用户需要解锁钥匙串或从用户控制的加密备份恢复。
- 初始平台范围受限；跨平台运行时没有安全密钥库就没有自有历史写入。
- 认证加密保护本机静态内容，但不隐藏应用运行时中用户正在查看的明文，也不覆盖用户导出的外部副本与操作系统快照。
