# ADR 0027 · 用户 Skills 配置启停

状态：接受。日期：2026-10-04。

内建 Skills 管理采用 Codex 官方用户目录 ~/.agents/skills 及 [[skills.config]] 启停配置。目录发现与配置启停只读取文件系统元数据，不读取技能正文，不安装/复制目录或运行脚本。UI 只提交后端生成的 Skill ID，路径由后端重新解析；链接按目标文件配置，已有别名按 canonical 目标匹配，多个冲突覆盖拒绝。

配置启停与实际加载分开，UI 使用“配置启用/停用”，写入后重启 Codex 核对加载，不主动重启工具。MCP 内部的通用配置事务被 Skills 共用：限额、私有字段保护、revision、备份、来源复核、原子写和读回；共用配置 Mutex。取消预览零写，失败保留预览；备份还原列 Skills 差异，不泄露路径或正文。

目录与启停条目各 200 项；未知结构及不可读状态拒绝，不能写空列表覆盖。元数据身份包含逻辑/目标路径、长度和修改时间，非正文摘要或内容 hash。任意外部写方在末次核验后的竞态仍存在，跨进程事务不作保证。文件存在不能证明 front matter 合法或客户端已加载。

代价：只覆盖用户目录的 Codex 配置启停；项目、系统、插件、旧目录及其他工具仍由各自能力和适配证据决定。安装、同步与正文编辑仍须单独实现和验收，不把启停计为完整安装器。依据 [官方 Skills 文档](https://learn.chatgpt.com/docs/build-skills)。
