# ADR 0032 · 工作空间分项执行收据

状态：接受。日期：2026-10-04。

工作空间逐项进入原模块核对、预览与应用，复用配置备份/还原和逐窗执行/撤销命令。执行前再次核对组合版本和引用；原模块仍核对实际配置/窗口版本。组合目录检查与实际写入不是跨存储事务，不宣称一键原子应用或统一补偿。

当前 WebView 保存一份有界组合上下文与分项收据，只保留组合身份/版本、分项目标、备份名、操作 ID 和静态结果摘要；不持久化配置内容、窗口标题、句柄或凭据。收据表示本次已发生的操作，不表示当前配置加载或窗口位置。项目/工具查看不记为应用成功；布局载入后修改模板、间距或窗口选择即解除原规则归属，需要自主选择屏幕的规则允许首次选择目标屏幕。

组合变更或分项核对失败要求重新打开，其他目标的操作不归入组合。执行中的收据绑定启动它的组合；切页不能把结果写入新组合，期间不允许打开另一组合。失败重试保留此前备份/撤销身份。配置记录失败单独显示部分完成；窗口按原始逐窗结果汇总。恢复入口只定位原备份/操作，仍须原模块再次预览或核对，冲突不自动覆盖。

代价：组合窗口重载后没有应用记录，用户从原模块查询配置备份；窗口恢复仍受原生模块最近操作与当前句柄生命周期限制。持久执行历史、重启恢复与整组应用属于独立契约，不能以临时收据宣称完成。顶栏复用现有高度，返回入口不改变内容起点。
