# ADR 0037 · 窗口操作历史与重启恢复

状态：接受；范围为本机已登记工具窗口。

## 决策

持久记录保存操作意图、逻辑点位置、逐窗实际读回与来源关联，移动前预写，移动后结算；不保存标题、PID、AX对象或临时窗口ID。pending表示结果未核实，finished表示当时读回，不表示当前位置。文件版本受支持且有界，损坏/链接/超限保留原件并拒绝写入；记录满100项后由用户逐项删除，不自动裁剪。

重启后原生身份全部失效。恢复由用户手动为一个历史slot选择同工具当前窗口，后台从历史读取目标，不接受任意前端矩形；检查新快照、历史revision、当前屏幕工作区、限制并生成短期预览。应用共用原生身份/几何复核和逐窗读回。恢复产生新记录，并可通过当前运行期最近一次撤销返回恢复前的位置；不自动绑定同名窗口、不自动移动。

移动后结算失败不能否定实际结果，也不能声称持久恢复身份已经确认；返回警告，保留实际结果和当前撤销，要求核对pending记录，不自动重试。删除历史需要明确说明恢复入口移除，且只操作本地记录；整文件revision发生变化则拒绝。应用与删除在本进程同一窗口服务锁内串行；外部跨进程内容CAS不在保证范围。

## 代价与验证边界

历史没有稳定原生身份，所以需要手动选择，不能一键跨重启自动恢复全组。历史位置超出当前完整工作区时要求接回原屏幕或重新排列，不静默裁剪目标。模拟重启/故障与真实文件测试验证协议和落盘；实际AX、多屏、原生焦点和资源仍须隔离环境验收。

组合关联使用窗口记录中的可选workspace上下文，包含组合ID/聚合revision、布局ID/规则revision；旧无上下文记录仍可读，不猜测归属。组合排列应用期间按workspace→rules→windows锁顺序复核并保持引用；普通排列预览的模板/间距/工具顺序必须匹配已保存规则。历史恢复目标来自历史slot，关联来源须属于同组合/布局，当前规则引用仍须可核实。重启入口定位具体record或execution身份，展开详情并聚焦新窗口选择；当前位置始终重新读取。
