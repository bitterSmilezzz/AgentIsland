# ADR 0036 · 本地技能目录发布与恢复

状态：接受。日期：2026-10-05。

技能安装是工作台内建文件操作，macOS 固定适配 Codex 用户级 `.agents/skills` 与 Claude Code 用户级 `.claude/skills`。原生目录选择由用户点击触发，路径只进入后端内存；预览/应用使用短期 opaque ID，不接受 UI 任意目标路径。目录名称来自校验后的 SKILL.md name。安装与启停、客户端加载分开；不执行脚本，不自动改变 enabled 配置，也不以安装成功声称客户端加载成功。

读取以目录描述符相对 openat 固定树，包内链接和特殊文件拒绝。节点 512、文件 256、深度 12、单文件 4 MiB、包总 32 MiB 有界，超限拒绝，不截断发布。目录及文件指纹覆盖相对名、内容与用户执行位，空目录参与版本。已识别私有文本形式、隐藏/凭据文件拒绝复制；检测不是任意秘密的通用识别器，错误不回显正文。资源和脚本按包保留，复制文件为私有权限，保留用户执行位。

同卷暂存于 `.agents/.agentisland-skill-installs/<UUID>/package`，写前独占发布不可变 receipt.json（名称、前后内容指纹与时间，不含来源绝对路径或正文）。macOS renameatx_np EXCL 发布新包，SWAP 交换更新，使旧目录留在事务目录。发布失败不回退破坏性复制/覆盖；暂存失败可能留下不可读记录，读取逐项显示，不隐藏其他有效记录。

恢复仅操作自有有效记录：核实当前目录与保留目录仍匹配预期指纹，给出文件差异，再交换或移回。原始记录不靠反复改写状态当成文件事实；目标和保留包推导 applied / inactive / conflict，prepared 与已移回不能区分时只称“目标未应用”。不自动删保留包，不提供强制覆盖。安装容量为 100 条，满额暂停安装。清理必须显式逐项预览，经短期 opaque ID 再次核实整条记录内容及目录设备/inode身份，以描述符相对 EXCL 移入当前用户 .Trash；不可用、跨卷或权限失败不回退递归删除。仅包/收据形式的自有 UUID 记录可移出，损坏或未完成收据可在完整安全扫描后预览，额外内容/链接/已识别私有文本拒绝。清理的树限额在包上限外仅增加一个容器和 4096 字节收据（514 节点、257 文件、13 层、32 MiB+4096），不放宽安装包限额。五分钟到期、取消和版本冲突无移出；移动后消耗预览，再读回身份/内容及来源移除，结果不明明确报告已移动，不自动回移。目标技能和配置不参与移动，废纸篓仍占空间，不承诺 Finder 自动放回或跨进程内容事务。清单最多完整读取 512 个目录项，超限明确拒绝；即使超过安装容量仍可清理，避免满额无退出动作。

外部进程在指纹核对与 syscall 之间修改文件不能构成跨进程内容事务；交换保留当时的旧目录，读回不符明确报告“已发布但变化”，不自动反向交换覆盖外部编辑。目录项断电持久性、各类网络文件系统和后续平台发布未作保证。元数据使用固定版本 serde-saphyr 1.3.0 的 deserialize 功能解析原始 frontmatter；支持多行、引号转义、注释、别名与合并键，发布原始文件不重写。名称与非空说明必须为字符串，同名目标必须具有匹配的技能名称。解析只接收最多 64 KiB 元数据、单文档、深度 16、4096 事件/2048 节点、32 锚点/64 别名、64 合并键及 256 KiB 累计字符串/锚点副本预算；限额错误不输出片段。拒绝重复键、未知标签，未启用 include、properties 或文件解析回调，不读取元数据引用的外部文件。原生客户端验收继续按整体方案实施。


跨工具同步为手动整包复制，共用预览/暂存/发布/恢复，不后台自动双向同步。清单仅扫描固定用户目录的名称、目录身份与普通 SKILL.md 元数据，不读取正文；每工具200项，扫描失败明确标注该组不可用，前端保留其旧条目并禁用动作。来源通过代次及 opaque ID 注册，预览核实描述符相对完整目录链、叶目录身份与元数据版本，再扫描整包；应用再次完整核对来源与目标。元数据检查不冒充内容指纹，完整版本以预览读取得到的树指纹为准。UI 不接收任意工具路径，目标仅 codex/claude 白名单。

收据增加目标工具，旧 schema 1 缺省目标为 Codex，未知目标拒绝。恢复版本绑定目标，不能利用改写收据将旧预览重定向到另一工具。中央记录目录仍在 .agents 下；Claude 安装不要求创建 Codex skills 目录。目标和记录必须支持同卷发布，否则失败关闭。保留格式的恢复记录不存来源路径或正文。

采用两工具共同的显式 YAML name 与非空字符串 description；不支持 Claude 省略名称等专属变体的自动转换，不解释或执行工具专属正文。Claude 的 synced、anthropic-skills 命名空间保留，拒绝写入。来源含链接不跟随。依据 [Claude Code 官方 Skills 文档](https://code.claude.com/docs/en/skills)，用户目录与保留命名空间已核对；这不证明当前客户端加载。


用户级正文编辑沿用整包发布与记录恢复。按已注册来源代次/目录身份/元数据版本读取并完整核实包与名称后，返回 Markdown 正文和 opaque 编辑票据；票据只保留工具/名称/目录身份/完整树版本及原元数据头，不存正文或来源路径，最多16项、30分钟有效，关闭或后续读取清除到期项。前端草稿仅当前窗口内存，不进入偏好、任务或日志。元数据原字节保留；结束标记在EOF而无换行时，添加正文需要额外换行边界，不重写元数据字段。

预览核对整个源包与读取版本一致，替换 SKILL.md 正文后复核4 MiB单文件/32 MiB完整包与已识别凭据限额，按同一树哈希得到计划。五分钟预览执行时再次核对目录链、叶身份及原完整树，扫描资源后仅替换正文；暂存/收据/SWAP/读回复用原机制。旧包包含原正文及资源，可重启后按目标恢复。不编辑元数据，不跟随资源链接，不自动转换工具语法/批准工具指令。外部修改拒绝旧编辑，不提供强制覆盖；取消预览保留草稿，关闭后不再提供内存草稿。执行结果未核实不能重复确认，关闭编辑仍要求刷新记录核对，不声称未保存。

当前命名空间复核：暂存后、发布前，重新从固定用户工具链打开skills根与中央记录根，对照保留描述符设备/inode；恢复同样核对，废纸篓转移核对记录根与当前.Trash身份。发布后再次复核，异常明确已执行而非未写入，不自动回滚。真实文件测试覆盖内容相同的根目录替换、链接替换与工具父目录替换；不把此身份检查等同跨进程内容事务或所有syscall间隙已原子封闭。
