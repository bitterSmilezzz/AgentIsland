# ADR 0025 · 内建 MCP 配置治理

状态：接受。日期：2026-10-04。范围：已核实的 Codex 用户级配置，不代表全工具/Skills 管理完成。

按 ADR 0023 拆解配置治理能力，产品内建新增/编辑/启停/删除和字段差异，不依赖上游配置应用。HTTP 与本地 stdio 根据[官方契约](https://developers.openai.com/codex/mcp/)映射 url/bearer_token_env_var 或 command/args/env_vars，仅存变量名；保存不运行服务器或读取认证。配置启用不等于连接可用或客户端已经加载。

操作枚举与配置 DTO 白名单，配置 hash 和完整操作 hash 绑定预览。读取、预览和 apply 在后台 blocking worker 完成，apply 与模型档位共享写入锁，锁等待不阻塞 UI 或异步运行时；目标只由后台指定，普通文件、2 MB、200 条目及严格输入边界。保留非目标字段与普通高级工具策略，转换传输移除旧 transport 字段。已知静态凭据字段、敏感文本及未支持 MCP 形式使管理保留只读，避免把这些内容送进 WebView 或新备份；不声称任意未知文本都能自动识别为秘密。

写入前原子备份，复核配置，原子发布并读回；同名备份拒覆盖。读回不匹配时明确已经写入及待核对，不谎报未改变。原备份还原入口保持，预览列 MCP 名称与变更类别，不暴露值，明确完整文件覆盖。未知外部写方最后一瞬间改动不能宣称全事务隔离。

UI 按需加载，四类操作都先预览；取消零写。失败保留输入，刷新配置可带草稿重新预览。JSON args 保留空字符串/空格，变量名列表只解析名称。确认区焦点/取消/背景 inert 和减少动态沿用统一页面规则，浅深色及窄窗口检查。Skills 仍只读，远程环境/插件内 MCP/其他工具需独立能力证据再交付。
