# ADR 0035 · 工作空间配置操作历史

状态：接受。日期：2026-10-04。

工作空间配置操作历史由后端实际命令产生。配置写入前原子保存 pending 元数据，原模块返回后保存实际结果和备份名；前端不能提交任意成功收据。组合锁覆盖引用核对与操作，配置版本继续由 Provider 核验。还原绑定同一组合、档位、具体历史操作和备份，复用完整配置预览/备份/还原。

历史仅保存有限元数据，不写正文、路径或凭据，不自动清理。记录坏格式/未来版本/容量/链接失败阻止新的组合配置操作；写入后的记录失败独立警告，保留返回备份，不能报普通失败诱发重复写。重启后 pending 显示待核对，不推断执行失败或自动重试；历史不证明客户端加载。

代价：pending 无法证明进程中断发生在配置写入前还是后，需要用户核对；非跨文件事务，不承诺断电持久性。窗口原生句柄仍仅驻内存，跨重启撤销和跨模块补偿单独实现。实现契约见工作空间文档 10。

预写与结算在独立执行接缝中串行；结算失败不返回持久恢复操作身份，当前备份仍可沿原配置模块明确预览还原。组合身份、全局版本和档位引用先复核，再创建操作记录。
