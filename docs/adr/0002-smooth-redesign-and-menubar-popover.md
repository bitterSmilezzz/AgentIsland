# ADR 0002: 侧边栏与菜单栏体验丝滑化、MenuBarExtra Popover 与设置分栏重构

## 背景与问题

在 C7 中，灵动岛由屏幕顶部悬浮岛移至屏幕右侧隐藏侧边栏。用户反馈当前整体体验「不够丝滑、很笨拙」：
1. **菜单栏过于简陋**：原有 `MenuBarExtra` 使用系统原生下拉菜单（`.menu`），排版粗糙，甚至残留「提示：鼠标碰屏幕顶部滑出卡片」的遗留文案，缺乏视觉吸引力与状态快速感知。
2. **侧边栏滑出与动画生硬**：采用硬编码的 `0.42s easeInEaseOut` 动画，全高 24pt 热区易在误触右上角关闭按钮或右下角系统通知时意外触发；窗口动画与内部 SwiftUI 帧未深度对齐。
3. **设置界面拥挤笨拙**：单页长表单排版扁平堆砌，缺乏现代 macOS 系统的分栏层次与清晰分类。
4. **视觉质感欠缺**：缺乏精致的 1px 微反光边缘与高级毛玻璃层次感，呼吸动画较硬。

## 决策（经过两轮盘问对齐）

1. **菜单栏升级为精致 Popover（Compact Island Popover）**：
   - 将 `MenuBarExtra` 样式由 `.menu` 改为 `.window`（macOS 13+ 支持）。
   - Popover 提供紧凑实时的灵动状态摘要：发光呼吸状态徽标、正在工作的 Agent 胶囊状态、24h/累计 Token 摘要、直达「展开侧边栏」、「偏好设置」、「退出」的操作底栏。
2. **侧边栏防误触与物理弹簧动效（Apple Spring）**：
   - 热区优化：缩窄至 12pt，且仅限制在屏幕垂直居中 60% 区域（`visibleFrame.midY ± height * 0.3`），彻底规避屏幕顶角与底角的误碰。
   - 动画重构：采用物理弹簧动效（Response: 0.34s, Damping: 0.82），进场平滑带有极轻微柔和回弹，收回顺畅利落无震荡；与内部内容动画对齐。
3. **设置窗口重构为现代 macOS 分栏（NavigationSplitView / Inset Grouped）**：
   - 左侧侧边栏提供 4 个分类：【通用与外观】、【Agent 监控】、【引擎与性能】、【关于】。
   - 右侧使用标准 Inset Grouped 视觉规范与卡片式模块，精细重构滑块与开关微交互。
4. **视觉与材质全方位精致化**：
   - 卡片增加内圈 1px 高光描边（动态色：深色微白高光，浅色微暗勾边），增强悬浮层次。
   - 优化深浅色模式下的文字层级与对比度。
