# ADR 0023 · 内建能力融合优先于上游工具关联

状态：接受。日期：2026-10-04。依据：用户明确要求拆解上游功能融入本产品。

借鉴 CC Switch 的配置治理、Magpie 的紧凑模型选择与快照、Todos 的任务/人工关口、New API 的模型/接口/协议/路由与额度能力，转译为本产品内建模块。按业务能力组织 UI 和验收；不要求用户先安装上游产品，不复刻多个项目导航。

外部连接、读取状态或打开工具是可选互操作，不计为功能融合完成。已有连接模块保留为辅助能力，后续开发优先内建任务、模型/接口选择、配置快照与受控工具适配。路由执行/渠道治理单列请求授权、凭据、协议、重试计费与资源验收，不由一个 connected 标签代替。

本地目录选择档位复用现有配置核心、预览、revision、备份及还原，不另建第二份档位状态。配置目标、运行模型、服务可访问能力分别展示。MCP/Skills 只读清单不能当成可编辑管理交付，任务组织不能当成自动执行编排交付。

代价：已经完成的外部连接存储和只读检测只算互操作；方案进度必须回到内建能力逐项验收。功能借鉴不默认许可复用上游源码，实际复用仍核对许可证与归属。
