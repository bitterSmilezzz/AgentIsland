# ADR 0024 · 可选服务的手动只读传输

状态：接受。日期：2026-10-04。范围：可选互操作，不代表内建功能融合完成。

状态读取只由显式按钮触发，后台执行，全进程同时一项。New API 仅匿名 GET api/status，Magpie GET 根路径核对服务身份；保留代理路径前缀，CC Switch 无核实接口则不发送请求。返回 readable 只说明受控状态可读，模型/用量权限保持 false。失败分类、版本与时间为白名单字段，不返回外部正文或诊断。

使用 reqwest 0.13.5 blocking + native TLS；HTTP(S) 无 URL 认证、查询或片段，Bearer 仅按连接环境变量引用在明确动作中读取。HTTP 凭据明文风险在对应按钮与行内显示。5 秒请求/连接边界、512 KiB 正文上限；只接受 JSON，拒绝重定向、自动重试、代理继承和压缩响应。证书校验不关闭，不使用 cookies 或工具 OAuth。

HTTP 客户端第一次手动读取时惰性创建并共享，无请求时不创建运行时；避免每请求销毁阻塞客户端时等待内部 DNS 线程。一次完成或失败后释放操作租约，返回前复核 revision 与完整连接内容；变更拒绝旧结果。页面缓存只保留瞬态结果，标注上次读取时点，重试先清除旧成功；不落盘原响应。

代价：共享客户端在第一次读取后持有一个运行时；真实 TLS/服务部署兼容和资源预算需独立验证。GET 只读意图不保证任意第三方服务器无副作用，因此只调用已核实状态路由。当前依据上游路由源码与本地受控夹具，不宣称已授权真服务验收。
