# ADR 0029 · 任务来源内容与版本引用

状态：接受。日期：2026-10-04。

任务内建问题/结果查看，不依赖 Todos 或其他上游应用。来源导航仍是辅助入口；打开会话不能代替工作台内容能力交付。可信事件的引用绑定任务、运行及事件内容版本；来源版本变化或丢失不得用最新会话替代。只保存不可逆事件指纹及通用标题，正文按需只读，不复制到任务文件，不进入诊断输出。

Codex 的明确问题事件与成功完成结果分别形成问题/结果引用；完成不自动验收，通用提醒不推断方案确认。人工本地标记与来源回答/批准继续分开。协议字段参考 [问题结构](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/request_user_input.rs) 与 [事件结构](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)，实际适配以本项目已识别的 rollout 方言为准。

读取在后台执行，前后核对聚合 revision，目录遍历、文件尾窗与正文长度有界；仅展示具体引用匹配的事件正文，不格式化无关事件内容。显式私密输入和已识别凭据形态拒绝展示；检测是启发式保护，不是对任意敏感文本的完整脱敏保证。正文以纯文本呈现，关闭清除，晚到结果拒绝。未核实协议或不在读取范围内明确回到来源，不伪造可用能力。

代价：历史引用仍依赖原来源记录存在且位于有界读取范围；目录移动、尾窗淘汰或内容改写会导致不可读。当前只支持 Codex 问题和完成结果，不宣称跨工具内容、方案审核、回答或执行编排已经完成。真实原生导航和内容流程仍须独立验收。

Claude 人工关口及明确内联正文的扩展见 [ADR 0030](0030-claude-attention-artifacts.md)；不扩大原始来源正文的持久化或文件访问范围。
