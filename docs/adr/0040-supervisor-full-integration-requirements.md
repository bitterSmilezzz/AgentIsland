# ADR 0040 · Agent 监工台与完整 Magpie / Todos 能力目标

- 状态：需求范围已接受；实现方案、分模块权限/预算和测试runner待实施。
- 日期：2026-10-14。
- 依据：用户最新明确要求“Agent的监工台、即时邮箱/短信/手机通知、Magpie全部功能、Todos全部功能”，并确认产品身份；选择本机优先，完整能力可自托管/接入服务；自动开发参考Magpie作者机制。

## 决定

[需求基线](../需求.md)为当前产品范围单一入口；[功能对齐](../功能对齐清单.md)定义上游证据与子能力，[测试框架](../测试框架.md)与[矩阵](../需求测试矩阵.md)定义充分验证与持续扩展的方法。

完整目标明确包含：模型网关/协议转换/智能路由/账号与用量；Chief/受管理任务执行/审查/Git/定时/多机器/团队/MCP/Skills/Memory/移动；SMS为额外新增渠道。外部云能力可通过可选部署/服务适配实现，不要求自营支付套餐。不能以只读探测、简单待办或仅外部链接替代完整能力。

## 取代关系

本决定取代 ADR 0039、旧CONTEXT、旧05/21/25/26/28等规划中“本产品不架网关、不做智能路由、不做任务执行/版本存储”的目标排除，保留这些文件为历史取舍。技术主线仍沿ADR 0016，具体网关/执行/移动架构需另定方案；当前已发布产品没有因此获得新实现。

旧的只读监控/凭据/出网限制继续约束已实现路径；新子系统在正式启用前须具备专属认证、存储、授权、重试计费、资源和数据生命周期契约。不得通过需求翻案顺手关闭TLS、认证或校验，不读取未经授权账号，不输出/提交秘密。

外部监控继续只读来源版本；自有受管理执行允许按内容策略保留自身方案/diff/对话历史，二者不可混淆。原“单版本就明说”仍适用外部源，不限制本产品自有运行的版本能力。

## 自动开发与通知边界

参考Magpie的LESSONS、复现/Red/Break/Not run、独立审查SHA、CI完成再发布等机制。可配置预授权全自动；用户指定参考并不自动授予当前会话任意代码执行、推送、部署、短信支出或凭据访问。默认需求/发布人工门保留，项目明确预授权后按范围自动推进，超范围暂停。

本轮仅文档：没有构建、真服务/短信/邮件/手机发送、任务执行、runner实施、云部署、提交或发布。需求与测试矩阵完整登记不等于所有上游细项已实现或验收。
