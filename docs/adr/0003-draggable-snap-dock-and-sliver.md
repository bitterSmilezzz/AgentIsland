# ADR 0003: 自由拖拽四边贴靠、6pt 微细条常驻感知与光标碰触自动弹出

## 背景与问题

在 C8 交付后，用户提出了明确的交互进阶需求：
> 「我想要的是可以移动，移动到侧边它自动就贴到侧边栏，移动到顶部它自动贴到顶部这个栏。不论是侧边还是顶部都留一个非常细小的条，能看到这有个东西，然后光标碰到上面之后它自动弹出来。」

先前的设计中：
1. 灵动岛固定锚定在屏幕右侧，不可自由移动与换边。
2. 收起状态下窗口完全滑出屏幕边缘（零残条），导致用户无法直观感知灵动岛的位置与当前是否有 Agent 正在工作。
3. 只能依靠鼠标盲碰屏幕边缘盲区来唤出。

## 决策

1. **自由长按拖拽与四边智能吸附（Drag & Snap-to-Edge）**：
   - 展开卡片的顶栏注入全局 `DragGesture`，用户按住即可自由在全屏幕拖拽面板，实时跟随光标移动。
   - 释放拖拽时，根据面板外框到可用屏幕上、右、下、左四边的物理距离自动判定贴靠目标：
     - 顶部或底部：吸附为**水平灵动岛**（`DockEdge.top` / `.bottom`），保持并钳制水平坐标；
     - 右侧或左侧：吸附为**垂直边栏**（`DockEdge.right` / `.left`），保持并钳制垂直坐标。
   - 贴靠边缘与锚点位置保存至 `UserDefaults`（`dockEdge`, `dockAnchorX`, `dockAnchorY`），跨启动持久化。
   - 吸附就位采用 Apple 阻尼流体弹簧曲线（`response: 0.34s, dampingFraction: 0.82`）。

2. **常驻 6pt 晶莹微细条（Sliver）**：
   - 收起状态（`displayState = .docked`）下，窗口在贴靠边缘保留露出 6pt 厚度的半透明微细条（顶部/底部为 140x6pt，左侧/右侧为 6x120pt）。
   - 材质采用毛玻璃 + 1px 晶莹高光描边（`Theme.dockedSliverFill`, `Theme.dockedSliverStroke`）。
   - 微细条中心内置呼吸工作绿灯：当后台有 Agent 处于工作状态时，细条发出柔和绿光，即便收起态也能一目了然。

3. **光标碰触自动弹性弹出（Hover Auto-Pop）**：
   - 当鼠标光标碰触微细条（或微细条边缘 14pt 触发热区）时，自动触发 `.expanded` 展开。
   - 顶部向下、右侧向左、底部向上、左侧向右展开；收起时反向回到对应微细条。
   - 鼠标移出卡片后，在 `collapseDelay` 延迟后平滑收缩回收起微细条。
   - 拖拽中挂起收起任务，防止拖动中误折叠。

4. **单向圆角动态自适应**：
   > 状态注记（R19，2026-09-12）：本决策第 4 条的「ShadowHostView 单向投影同步」已被实现
   > 取代——阴影整体停用（面板窗口与玻璃卡同尺寸，阴影无处落地，见 IslandPanelController
   > 与 Theme 注释），单向圆角由 GlassCardBackground/SideNotchShape 承担；决策 1-3 仍然有效。
   - `GlassCardBackground` 根据当前 `dockEdge` 动态选择：
     - 顶部贴边：仅下方两角圆角（topRadius = 0, bottomRadius = 16）；
     - 右侧贴边：仅左侧两角圆角（rightRadius = 0, leftRadius = 16）。
   - `ShadowHostView` 单向投影同步根据贴边方向更新遮罩路径。

5. **设置面板与重置能力**：
   - 设置界面「通用与外观」提供选择器，可主动在四个贴边位置之间切换，并提供「重置位置」按钮恢复屏幕中轴停靠。

## 修订（R43 · 2026-09-15）

- 吸附范围从顶部/右侧扩展为上、右、下、左四边，底部与左侧使用对应方向的镜像倒角、微细条、热区与 tooltip 箭头，交互保持对称。
- 自动收起的浮层守卫必须同时满足“真实岛交互浮层、窗口可见、鼠标在该窗口内”；`NSStatusBarWindow` 只是宿主且可能拥有宽泛 frame，明确排除，避免将面板误判为持续悬停。
