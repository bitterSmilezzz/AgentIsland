# ADR 0022 · 服务连接偏好与凭据引用

状态：接受。日期：2026-10-04。范围：连接配置，不代表服务适配完成。

## 决策

独立 connections.v1.json 保存 schema_version、revision、items。连接 UUID 由后台生成，编辑保持 UUID 与创建时间，停用是本地偏好；删除不影响服务。HTTP(S) 地址必须没有 userinfo、query、fragment，保留代理路径前缀并规范尾斜线。所有错误只返回受控文字，不引用原配置/解析诊断。

凭据字段当前只支持 null 或 environment/name 引用，大写变量名，不携带值。保存与列出不读取环境变量、钥匙串、账号登录或 OAuth。未来钥匙串适配须绑定连接 UUID，不能用任意条目名读取现有远程通知凭据；在真实实现前未知来源拒绝。模型/流量/响应/运行状态不进入偏好文件，禁用不能伪装网络已经关闭或远端服务已经停止。

聚合 revision 对应用内保存/删除做乐观并发检查，进程 Mutex 保证单写方；严格 schema/字段/身份/名称/40项/256KiB/JS整数边界，坏、未来、超大或 symlink 文件保留并拒写。原子暂存校验后替换，失败保留原文件。不宣称已经保证任意外部进程复用旧 revision 手改的全事务隔离。

界面将保存与检测分开；尚无适配器时明确未检测，不展示 connected 或虚构目录。服务接口必须有版本、路由、授权与受控响应证据；后续测试请求显式触发，按来源区分远端用量与本机净消耗。保存不启动网关、不写 Codex 配置、不生成流量。

## 代价

仅环境变量引用在 GUI 启动环境中可能不可用，UI 说明启动环境要求；未提供钥匙串入口，不以保存引用冒充凭据已可读取。页面缓存保留未保存输入，失败不清空；保存/取消执行原生 form reset 后重建草稿基线，避免空表单持续阻止工作台闲置回收。
