# 采样节律保留在 ActivityEngine 内聚，不抽独立 Sampler module

2026-09-06 多轮架构重构（C1–C6）收尾时评估：架构审查曾建议把采样生命周期（timer / samplingInFlight / 降频调度 / 线程编排）抽成独立 Sampler 深 module。决定**不抽**——token 轮询生命周期已收归引擎单一 owner（C1），安装缓存节律已内聚到注入的 InstalledAppsCache（C4），剩余采样节律仅约 80 行、状态机合法组合有集中注释、且有测试守护；此时抽取只搬移代码、不开新能力，却引入真实的采样/动画回归风险（动效是批次 3/12 打磨出的资产）。「最后写入时间」双缓存的 locality 问题以 FileMonitor 单调 merge 写回 + 引擎影子缓存退役解决（本 ADR 同期），不动节律本身。若未来采样需要多种策略变体或节律复杂度显著增长，可重开本决策——在那之前，请勿以「架构整洁」为由再提议抽取 Sampler。
