# ADR 0031 · 本地工作空间引用组合

状态：接受。日期：2026-10-04。

工作空间是内建项目、工具、配置档位与窗口规则的引用组合，不是上游工具链接合集。只保存稳定 ID 与用户名称，各源模块继续单写方。保存/打开不应用配置、不移动窗口、不执行工具，用户在对应模块核对与预览后动作。

打开重新解析每项引用，失效、不支持与身份重复明确拒绝；部分来源错误不阻塞未依赖它的有效项。引用保留历史对象身份，不以最近项目/默认档位/新规则替代。UI 进入具体项目筛选、档位预览入口及布局规则，不复刻配置写入、备份或撤销路径。

目录是多个源模块的短时读快照，不提供跨文件事务保证。配置/窗口动作仍按原模块版本、能力、预览、备份与撤销核验。移除组合不删除来源数据，来源删除也不静默清组合；编辑可修复失效引用。

代价：当前逐项行动，一键组合执行与失败恢复若实现，须另定可核实的运行与补偿契约；不能将保存组合称为完成原生实际应用。工作空间容量及元数据目录有界，超限与坏格式保留原件，不后台淘汰历史。
