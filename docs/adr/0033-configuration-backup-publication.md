# ADR 0033 · 配置备份不覆盖历史

状态：接受。日期：2026-10-04。

配置切换、MCP/Skills 写入与还原前备份共用 atomic_create_validated：同目录独占暂存、写入/sync、调用方校验，再以 hard_link 原子占用目标名。目标已存在或被并发创建时失败，不删除或覆盖目标；发布完成移除暂存别名。Unix 0600 延续现有基础层。普通设置/配置替换继续使用 atomic_replace_validated，两者共用暂存与清理机制。

同名时间戳冲突停止后续配置写入，用户可重新预览再操作；不为避免一次冲突而改变已有备份命名与白名单。文件系统不支持 hard link 就明确失败，不回退覆盖式 rename。未声明断电后目录项持久性，也不提供跨进程配置事务。

档位实际写入、配置还原复用既有 Codex 配置 can_backup 私有字段/未支持形式保护；不因目标 Provider 无认证字段而复制其他区域中的已识别认证字段。检测递归覆盖数组、表数组和内联表；不是任意秘密的通用识别器。命中时保持只读，前端预览 writable 明确区分查看与还原，后台重新检查。旧备份保留原件，可脱敏查看；拒绝复制并不删除原文件。元数据档位捕获不读取认证值，凭据保持环境变量或钥匙串引用。

代价：部分高级/私有配置不能通过本应用完整备份或改写，需用户在原工具处理；多个工具快速操作发生同名冲突时需重试。保护失败不会削减扫描或改写原配置。
