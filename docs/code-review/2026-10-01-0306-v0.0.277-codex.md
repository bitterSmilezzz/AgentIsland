# v0.0.277 工作台深链审查

审查者：Codex。基线：v0.0.276。范围：Workbench 意图的窗口唤回。

## 发现与修复

Workbench 已被 reveals_window 通用分支匹配，后面的 Rust 专用显窗分支无法进入；工作台前端又未处理该意图，结果 CLI 请求成功却不显示窗口。前端现使用已有 show_workbench 接口唤回当前窗口，不重绘内容；删除不可达分支，沿用导航缓存及串行消费链，冷启动和运行期共用一处呈现规则。

## 证据

- Node 回归加载工作台真实 boot，旧实现准确失败于“workbench intent must reveal the window”；修复后运行期和冷启动缓存重放均通过，并核对分析页路由保留。原有灵动岛两种模式继续验证。
- Rust 全量回归：548 通过、5 忽略。
- 构建后执行 restart-app.sh，立即发 CLI workbench 指令，原生辅助功能树确认工作台显示。
- 原生分析页隐藏后以同一指令唤回，仍为分析页；完整路径结束正式应用后通过 workbench 深链冷启动，直接显示工作台概览。
- 工作区脱敏扫描、diff 空白检查通过。发布脚本继续检查全历史、版本漂移、原生 UI 冒烟及单实例。

## 边界与结论

不修改样式、监控口径、设置或外部通知，不恢复归档端；唤回不渲染页面，因此沿用现有草稿与滚动状态。原生检查确认窗口和页面，不宣称像素布局验证。范围内无阻断问题，可发布。
