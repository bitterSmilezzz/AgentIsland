# 灵动岛顶栏精简

顶栏保留搜索、设置与收起三个真实按钮，外观选择继续使用设置页的现有入口，移除直接切换的重复入口与闲置监听器。按钮采用透明底，仅 hover / focus 反馈；默认标题稳定为「智能体」，状态摘要显示工作数量，在线数去掉重复的「本机」。确认和告警仍优先显示智能体来源、外部状态和排队数，长名称截断时可通过 title 读取全文。

状态点跟随 headerPresentation 的 tint，避免告警文字为红而状态点仍按普通工作状态为绿。未接入明细源仍保留待核实口径。徽标不挤压，名称让位给状态与操作区。卡片宽度保持 300px。

实际 UI 模块浏览器验证：工作数量与稳定标题、搜索入口、设置页外观选项、长名称外部告警和队列 +2；顶栏高度 47px，未出现横向溢出。截图核对普通和告警布局，未发现 JS 错误。Rust 全量回归与扫描由 release.sh 执行；原生自动化仍受隔离桌面会话门禁约束。
