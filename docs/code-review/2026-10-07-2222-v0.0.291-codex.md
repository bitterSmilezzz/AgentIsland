# v0.0.291 · 原生动画证据与资源目标复核

审查者：Codex。范围：本轮工作区相对 v0.0.290 的动画诊断、VM 运行器、资源协议及文档；不重写旧版本报告。

## 问题与修正

- 浏览器算法回归不能证明 AppKit 窗口的真实位置。增加显式诊断模式、只读原生 frame 与合成内容驱动，覆盖四边各9个进返/快速逆向/晚到报告场景。普通启动拒绝诊断命令、不加载驱动，诊断运行不恢复 hooks 或启用远程通知。
- 首次原生执行发现驱动试图改写只读 Tauri invoke，在切页前失败。修正为后端校验诊断能力后，由薄封装延迟报告交付；只读夹具覆盖拒绝普通模式、合法延迟与原接口身份保持。失败输出仅保留固定错误分类和几何，不记录用户正文。
- VM 内多份应用注册相同 URL scheme，会使全局 CLI 派发命中其他包。资源协议改用 explicit bundle 派发，并继续复核目标启动身份和新日志；不以此证明全局 CLI 的选择正确。
- 原生专项与默认三个发布门禁的 receipt 明确区分；子测试仅接受父运行器持有的互斥锁，不将旧结果复用为新验证。
