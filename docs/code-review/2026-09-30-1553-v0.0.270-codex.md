# v0.0.270 · 本地日历接口优化审查

审查范围：本轮新增 `localclock.rs`，以及 forecast / remote / tokens / smtp 的调用迁移、POSIX 棘轮上限与 UI 冒烟进程清理。工作区已有 Windows 调查与版本改动，以及工作期间出现的 Swift 测试修改，不作为本轮优化成果。

## 结论

本轮范围内未发现阻塞问题。四处本地日历系统调用统一到一个平台边界：Unix 的重入接口与 Windows 的安全接口各自处理参数顺序与返回值。调用方保留原有失败降级。邮件偏移由同一时刻的本地与 UTC 日历计算，覆盖相邻日期、跨年及含秒的历史偏移；分钟向零取整，与 Unix 原行为一致。

UI 冒烟只按应用 bundle 路径清理旧实例，并按自身 PID 结束冒烟进程，不按同名 CLI 的进程名清理。POSIX 棘轮上限从 8 降至 4；该指标不代表 Windows 应用已可构建。

## 边界

当前机器仅有 Command Line Tools，缺少 SwiftUIMacros，Swift 全套测试与原生回退应用构建未验证。Windows 整体应用仍有进程、主机名、文件权限等移植缺口。工作区的独立调研库迁移已另行提交；本轮代码随后续 UI 优化统一发版。
