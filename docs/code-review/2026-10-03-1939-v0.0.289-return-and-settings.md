# Agent 用量返回与设置精简

## 发现与修复

原生外框采样观察到详情 330×370 与监控 300×333 两个稳定状态，未捕获重复的原生尺寸反弹；该采样不能证明所有 WebView 绘制帧都正确。继续检查原生落位和 WebView viewport 的交接，建立 scripts/test-island-return.mjs：原生请求返回后延迟 25ms 送达 viewport；旧控制器提前恢复布局，测试在 330×370 / 300×333 比较失败。新控制器保留固定几何，等待 viewport 到达并经过绘制帧后才恢复采样，测试通过。等待有界，缺失平台反馈时不永久锁定。

窗口边界变化越过静止鼠标会触发 mouseleave，旧处理直接启动自动收起；scripts/test-island-click.mjs 已复现返回过渡中误收起（expanded=false）。导航期间忽略该边界事件，路由变化清除旧计时，正常鼠标离开仍按原策略收起。回归由失败转为通过。移除 Agent 行的重复 click 绑定和重复显式注水，浏览器确认每次点击只读取一次报告。

设置页保留统一字段表与原保存/回滚通道：六项常用设置在首屏，其余 22 项放在默认折叠的更多设置；展开状态在同窗口重绘时保留。固定 410px 设置面板、48px 返回栏，开关、文本选择器与分隔线统一。初次截图发现旧样式优先级覆盖新控件尺寸且首屏滚动，补上形态作用域并收紧组距；第二次检查发现折叠边界仍有溢出，进一步收紧后首屏 scrollHeight=clientHeight=362，无横向溢出。浅深色截图已逐张检查。

## 验证

- 延迟 viewport、鼠标误收起、异步报告 retarget、设置保存与回滚回归通过。
- 浏览器模拟原生 viewport 更新，四边返回各检查 46–50 帧：贴边锚点偏差 0，返回高度反弹 0，无残留副本、无 JS 错误。
- 12 次快速进入/返回，报告延迟 90ms，最终无过期报告 DOM 或副本；焦点回到 Agent 行。
- 六项常用设置首屏可见，全部 28 项保留；键盘展开与状态保留、减少动态效果返回和焦点检查通过。
- 品质基准与流程写入 ADR 0018 与 workbench 24，不用奖项目标代替可复现的验证。

最终结果：605 项 Rust 回归通过，6 项既有忽略；版本检查、发布脱敏扫描通过，打包完成，restart-app.sh 验证新应用 PID 71360。macOS 原生检查完成详情进入、返回、焦点回到 Agent 行；返回后鼠标位于缩小边界外仍保持展开，没有误触发收起。设置首屏六项与自动保存状态可见，更多设置包含所有细项，正文滚动时返回栏固定。没有保存真实用户会话截图。
