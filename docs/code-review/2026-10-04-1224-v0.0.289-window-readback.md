# 原生窗口延迟读回审查

范围：C2 排列与撤销共用原生 write。

## 实现

AX setter 成功不等于应用已经采用目标。尺寸写入后先等待读数，位置写入后连续两次完整目标匹配才结束等待；每次读数复核工具启动与权限，最终重新 inspect 身份、可见性和限制。等待不再次执行 setter，沿用后台 worker，应用与撤销共用同一条实现。

每阶段轮询预算 600ms、间隔 40ms；单次 AX 读取另有消息超时，因此不是操作全程严格 600ms 上限。尺寸受应用约束时可继续设置位置，最终按实际矩形报告部分失败并保留撤销。权限/身份/读取失败停止，保留最后可见矩形用于后续核对，不将其报为成功。

## 证据

三项无真实窗口写入的时钟/读数夹具测试覆盖延迟生效、瞬时目标后回退、尺寸受限到期及工具退出立即停止。全套 Rust 663 项通过、0 失败、6 忽略（`.scratch/window-layout-c2/readback-release.log`）。工作区与 Git 对象扫描通过，零新增豁免。真实 macOS 应用响应、AX/CG 同步延迟和整个操作资源耗时仍需隔离环境取证，当前不能宣称原生兼容验收完成。
