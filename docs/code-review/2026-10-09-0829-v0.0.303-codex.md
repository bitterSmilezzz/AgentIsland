## 反馈与修正

对正式v0.0.302既有实例连续两拍只读采样，活动成员六个，unresolved_membership均为1、complete=false。逐条匿名核对定位为state=Z的PID；coalition返回ESRCH，运行任务用量不可读，但PID仍存在。排除了系统PID0和读取权限假设。状态首字符语义见[Apple ps手册源](https://github.com/apple-oss-distributions/adv_cmds/blob/main/ps/ps.1)，未复制上游实现。

枚举加入state字段，仅过滤明确Z状态及自身创建的ps观察者，未知状态和其他同名ps继续参与核验。解析格式异常整拍返回sampling_failed、退出2，不静默丢弃潜在成员、不泄露原始文本。真正未知归属、成员缺读/重启、同组采样器和不稳定观察继续保持partial，未将它们折成0。

先运行回归确认旧枚举失败，再修正：16项采样器回归通过，长测协议及结果分析各6项通过；全量Rust899通过、0失败、14 ignored。当前正式宿主目标修正后连续两拍complete=true、unresolved=0，六个活动成员保持；这只是测量边界验证，不是受控负载或资源预算结论。
