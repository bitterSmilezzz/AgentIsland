# v0.0.436 自审：TASK-03 项目授权确认界面与命令

日期：2026-11-07。审查者：Codex（与实现同一上下文；不是独立复审）。审查范围为本轮授权候选、Tauri 命令、项目管理 UI、项目删除守卫、测试注册与状态文档。

## 结论

项目 grant 现在只可通过原生目录选择后的短期一次性候选进行确认。候选把目录文件系统身份、项目 ID 与策略 revision 保存在后端内存；前端只收到规范路径用于预览。取消不会写策略文件，确认时重新验证相同目录身份；策略 revision 冲突、根目录变化、损坏/未来格式和无法安全读取均拒绝。新授权不预选角色，历史采集默认关闭；授权撤销和历史开启要求二次确认。删除项目会在同一任务存储锁内检查并阻止删除启用授权。

审查未发现本轮增加的 runner 启动或来源工具副作用路径。生产 runner、Run now、TASK-05 密文历史写入仍未接入。

发现并登记 BUG-019：授权策略只有文件内 revision，没有可信单调锚。将策略文件替换为此前有效副本可能复现旧 grant；路径身份核验不能检测策略整体回放。当前没有导入/恢复入口，runner 仍关闭。ISSUE-06 负责设计和验证跨平台锚定；在此之前不得声称回滚可检测。
