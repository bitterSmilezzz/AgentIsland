## 接入与核验

- inspect 核对注册 bundle、PID、launchDate、AXWindows 对象成员和 CGWindowNumber；可见元数据仅用 OwnerPID/Bounds/Layer/Number，不读取名称、图像或废弃的 workspace ID。相同几何的多个 AX 窗口或多个当前桌面记录不猜对应关系，明确限制。窗口系统 ID 与初次读取不符视为身份变化。
- 权限、应用隐藏、最小化、全屏与位置/尺寸可写能力独立检查；未知状态拒绝，不把缺证据当可写。resize 在 position 之前，未改变的属性不重复设置；每步检查启动身份，尺寸后再核实可见身份；最终读取实际矩形。没有使用私有 AX 获取窗口 ID 函数。
- apply/undo 在后台执行，屏幕工作区经主线程读取；broker 校验预览与单次消费。撤销原位置所在屏幕消失时逐窗返回失败并保留重连重试，其余窗口可恢复；未观测冲突不接受强制选择。跨平台分支明确不支持。
- 工作台静态控制区配选择列表、比例预览与结果区。选中顺序决定主窗，改变选择或布局即取消旧预览；到期禁用应用，读失败取消旧目标。请求完成可更新本窗口缓存页，切页保留选择，不重复读取。授权仅由按钮显式打开系统设置。
- 自查截图发现 mini-btn 作者样式覆盖 HTML hidden，导致已授权仍显示去授权；补显式 hidden 规则并通过可见性回归。布局颜色使用已有主题 token，没有添加独立硬编码主题。
