范围 M4/P0：无界面 --memory-core-probe 的有界参数、元数据输出、阶段计时和外发阻断。普通引擎不启用诊断，未新增UI或配置项。

计时：单调时钟，阶段互不重叠；total_us包括诊断计时及cache_stats_us，不含采样等待、JSON编码或闲置页收集。other_us覆盖状态、导航、健康、事件等其他引擎工作，不假定只有账本计算；reclaim_us单列。计时不开启时不读取阶段Instant或扫描缓存统计。

隐私：有版本的JSON行仅输出计时、序号/时间、功能开关及缓存基数/容量，无路径/会话/模型/正文/通知/秘密。缓存容量为元素个数，不声称是字节或进程footprint。观察模式在在场探测/外发调度/钥匙串前返回，设置关闭远程发送仍作为独立防线。无窗口、hook或设置写入。

契约：默认20样本/2000ms，样本1..900、间隔100..60000ms；参数错误、未知参数、重复数值参数在Settings读取和建引擎前退出2。普通应用通知/计量保持；诊断模式保留本地事件和来源数据，但只序列化元数据。演示态重置阶段结果，避免借用此前真实缓存指标。
