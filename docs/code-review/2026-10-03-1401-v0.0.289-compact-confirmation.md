# 灵动岛确认提醒精简

将提醒横幅收成单行：动作摘要、智能体详情与忽略按钮。顶栏已有智能体身份、待确认状态和排队数，横幅只去掉消息开头重复的确认状态，不重复身份；原始消息保持不变，点击摘要或 Enter 可展开全文与附加原因，焦点回到摘要按钮。删除独立的「原因」与「直达」操作行，原先名为直达的行为实际上进入智能体详情，现在用准确的可访问名称。

忽略只调用原有 clear_latest_event，不批准智能体请求。摘要与详情入口都是真实 button，详情区域可滚动且换行，展开/收起触发窗口尺寸更新。提醒缺少正文时显示「等待你的确认」，不会消失成空行。

验证：实际 UI 模块的浏览器夹具覆盖双重状态前缀、长命令、无损全文、键盘展开/收起、排队 +2 保留、忽略命令与详情导航。默认横幅高度 34px，展开后完整文本可读；截图核对 300px 卡片布局，未发现 JS 错误。Rust 全量 603 通过、6 个既有忽略用例；发版扫描通过，原生 UI 自动化仍受隔离会话门禁限制。
