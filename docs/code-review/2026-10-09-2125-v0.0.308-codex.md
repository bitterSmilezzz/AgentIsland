审查对象：基于 v0.0.307 的配置操作反馈、工作空间手动选窗归属与直接撤销收据。审查者 Codex；2026-10-09 21:25 开始，原生复验与清理完成后收束。对应 M1/UX-02、D2、E 的工作空间分项体验；本报告记录发布前证据，不追写发布结果。

## 实现与反例

原生旧包在较长页面应用配置后，提示被追加到页面末尾，当前视口看不到备份。结果现置于当前配置摘要下方，使用既有内联样式、文字节点和 polite 状态语义。操作开始时记录焦点归属；焦点、键盘、指针、滚动、窗口失焦或离页使显露资格失效。状态读取的每个异步边界也检查资格，避免迟到的刷新覆盖新草稿。实际写入成功与刷新失败分开展示，记录警告保留，不把读取失败解释为写入失败。

同一工具有多个窗口时，旧包载入规则后手动选择会清空规则引用，真实排列成功却脱离工作空间。现保留已载入规则，并在预览前核对工具顺序、数量、窗口唯一性及限制；调整布局参数仍是独立操作，后端 revision 和逐窗身份检查不变。直接撤销只有精确匹配当前工作空间本次操作的可恢复收据才进入恢复意图，其他操作与已离开的意图不继承归属。

本次撤销更新当前流程的收据及真实窗口位置；既有持久排列记录仍描述当时的应用结果，不改写成重启后的当前状态。没有增加跨模块自动补偿、配置协议或凭据文件。
