# v0.0.289 · 采集组合链路与已打开正文的生命周期

审查者：Codex；时间：2026-10-06 18:53（Asia/Shanghai）。

## 问题与实现

底层缓存清除不能自动移除已打开查看区的 DOM 正文。采集读取现在附带首次采集期限的剩余毫秒数，普通 transcript 正文不附带临时期限。页面扣除请求往返时间，不通过读取或重复投递延长期限。到期清空正文并显示来源提示；暂停或配置确认触发即时失效，单独清理备份不触发。临时正文查看期间每五秒核对精确版本，无法读取或核实失败时清空；隐藏文档不持续读取，重新可见时核对。离开页面结束当前查看。失效时正文持有焦点则移至关闭按钮，不抢其他焦点。浏览器调度及文件系统操作不保证绝对时限。

新增受控组合回归使用真实内核 Unix socket 投递到已配置并明确启用的 Runtime，经生产 attach_capture 与 read_with_capture 路径关联和读取。关口、运行 ID 与事件收据不因正文晚到变化；任务文件不含正文；暂停后同一引用不可用、关口仍保留。该回归模拟 hook 投递，不声称真实 Claude 客户端通过。

- 组合回归：真实 socket ACK 成功，生产关联/读取有正文，任务持久文件无正文，暂停后不可读。
