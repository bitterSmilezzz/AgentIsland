# v0.0.184 独立复核 · DSH · 2026-09-27 08:45

## 范围与结论

复核无头自检的迁入（`selftest.rs` + `--selftest` + `run_selftest`）、进程匹配的纯函数抽取，
以及「最近活动」文案口径的统一。结论：**自检在本机真跑通（22 项全绿、退出码 0）**；
一处同表面不同口径被修掉；一处我自己引入的并行竞争被修掉。Swift 侧零改动。

## 可核验的行为证据

- **实物运行**：`./agentisland --selftest` 打印 22 行 ✅ 并返回退出码 **0**（不是只跑单元测试）。
- **自检在健康机器上必须全绿**：`the_selftest_passes_on_a_healthy_machine`
  —— 断言 `failed == 0`、`passed >= 22`（下限的作用是「检查项被删掉时显形」）。
- **报告可读且通过项不带噪声**：`the_report_is_readable_and_every_check_says_what_it_checked`
  —— 失败项才带 `（实际：…）`，退出码随失败变化。
- **文案口径（含 nil）**：`the_ago_text_matches_the_reference_including_the_nil_case`
  —— 4.4s ⇒ `刚刚`、**5.0s ⇒ `5s 前`**（阈值 5，不是 10）、`9s 前`、`2m 前`、`2h 前`、
  `200000s ⇒ 55h 前`（**没有「天」这一档**）、`None ⇒ —`、负数 ⇒ `刚刚`。
- **反向验证**：
  ① 把 `profile_matches` 的路径排除表去掉 → 自检那条「路径排除表命中时即使名字对上也要否决」红；
  ② 把 `is_hung` 的「观测不足」改成 `Some(false)` → 3 条红（含自检那条）。
- **测试数**：Rust **220 → 223**；编译警告保持 **22**；稳定性：修完并行竞争后连跑 **8 次**全绿。

## 本轮修掉的两处问题

1. **同表面不同口径（第三次遇到）**：`time_ago_text` 与 Swift `ActivityEngine.formatAgo` 是同一列
   （`lastActivityText`），却写了不同的单位、不同的阈值、多一档。用户在岛上看到 `2m 前`、
   在侧边栏看到 `2分钟前`。已统一；并把 `None → —` 收进函数内部（调用点不再各写一遍）。
   与 `compact`（v0.0.181）同一判断：**审美偏好不足以支撑与参考实现分叉**。
2. **并行竞争（第二次遇到）**：自检的临时目录用进程号命名，而两个用例会并行跑 `run()` ⇒
   互相删目录 ⇒ 失败表现为「写入后读不到最新活动时间」（看起来像文件扫描坏了）。
   改成「进程号 + 进程内序号」。**这是与 v0.0.178 端口竞争同一类病**：
   共享资源 + 并行 = 间歇性红，而且症状都指向错误的方向。

## 设计取舍

- **自检只碰自己的临时目录**：不读用户的会话目录、不启动采集。理由写在模块头：
  自检回答的是「这台机器上判定逻辑还对不对」，它必须在任何机器上全绿——
  否则失败就不再指向「包有问题」。
- **抽取 `profile_matches` 是为了让自检与单元测试跑同一段判定**，不是为了少写几行。
  以前排除规则只能靠真机碰运气；现在夹具能逐条断言。
- **`decide_level` 开成 `pub(crate)`**：自检要用它复现判定路径。代价是内部 API 面变大一点；
  收益是自检覆盖的是**生产那段代码**，而不是一份「差不多」的复制品。

## 边界与后续风险

- **自检覆盖的是「判定逻辑」，不是「采集链路」**：进程真在不在、会话目录真读不读得到、
  token 真不真——这些自检都不断言（它们依赖机器状态，断言了就会飘）。
  所以「自检全绿但界面还是空的」是可能出现的组合，那一类问题要看 `observability` 判定与采集日志。
- **`--selftest` 走的是同一个二进制**：Tauri 应用在 headless 模式下启动前就 `exit(0)`，
  但**它仍然链接了整个 GUI 栈**（启动时间与体积不受益）。若日后要做成 CI 门禁，
  更合适的是单独一个 `[[bin]]`。
- **`run_selftest` 无 UI 消费方**：与其余几条命令同一状态。
- **`time_ago_text` 改成 `Option`**：调用点少了一处 `unwrap_or_else`，但 API 面变了；
  若有别的调用方（今天没有）要一起改。
- 同前几轮：同一人既改又审；真正的护栏是两处反向验证的红、以及 8 次连跑的全绿。
