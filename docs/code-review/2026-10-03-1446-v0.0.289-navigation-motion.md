# 页面切换动效

页面导航使用 Web Animations 的淡入与轻位移：进入 210ms、返回 150ms。灵动岛、侧边栏、工作台分别按路由记录，仅切换时播放。周期采样和数据注水不重播；原有 card-inner CSS 入场动画改为仅初次展开时添加。

灵动岛原生宽高在同一短时段内缓动，仍由 Rust place_island 保持贴边定位。尺寸请求按路由与目标去重；快速导航取消旧目标，避免停在过渡中的尺寸。设置仍为稳定 480px 内容高度，含边框窗口 482px。系统减少动态效果时内容与窗口直接切换。

浏览器使用实际模块与模拟 Tauri 验证：设置只有一个 210ms 导航动画；返回为 150ms；同页重渲染动画数为零；减少动态效果为零；设置窗口最终 330×482；快速进入并返回最终 300×306；工作台与侧边栏进入及返回均按预期播放。未出现 JS 错误。

全量 Rust 回归 603 通过、6 个既有忽略；发布扫描通过。新构建经 restart-app.sh 校验重启，原生 WebView 验证监控→设置→监控→用量分析，目标页面与窗口尺寸正常，没有保存包含个人数据的截图。
