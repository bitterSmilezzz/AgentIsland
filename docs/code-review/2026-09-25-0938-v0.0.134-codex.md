### P1 — 重要

- **`Sources/AgentIslandCore/ActivityEngine.swift:896` — 采信自报改了对外状态之后，引擎级的 `anyWorking` 仍按观测算**
  - 审查者原文：*When a trusted report changes the displayed level—for example, inferred `idle`
    becomes self-reported `working`—`anyWork` has already been derived from the original `level`
    and is never updated. The snapshot then says working while `anyWorking` remains false.*
  - **症状→后果**：`anyWorking` 不只是一个汇总位——它决定 `fileMonitor.setScanUrgency(highFrequency:)`
    （`ActivityEngine.swift:935`）与节电采样节律（`:1393`）。于是**卡片说这个 Agent 在干活，
    而引擎按「没人干活」把扫描降频**：界面上那句 working 越久，底下的证据越旧，
    下一拍又可能因为读不到新写入被降回 idle。这是同一拍内部的两个答案，正是本仓「一个事实一个出口」要拦的形态。
  - **作者核实**：成立。`anyWork = true` 在 `:797` 由观测的 `level` 决定，而 `displayLevel` 的
    覆盖发生在 `:879` 之后，两者从未对账。
  - **修法（本轮已落地）**：在算完 `displayLevel` 之后补一句 `if displayLevel == .working { anyWork = true }`，
    注释写明「引擎的聚合位必须跟着对外那一拍走」。新增用例
    `来源: 采信之后的引擎聚合位与可观测性依据要跟着改口` 断言 `e.anyWorking == true`，
    变异 m71（把这句改回不可达）验证它会红。
  - **能否自动修**：是（已自动修完）。

### P2 — 建议

- **`Sources/AgentIslandCore/AgentObservability.swift:64` — 自报来的状态被写成「本轮读到了会话强语义」**
  - 审查者原文：*When a snapshot has `.selfReported` provenance, `AgentObservability.evaluate`
    still bases its verdict only on `level`: a self-reported working state is labeled observed with
    evidence claiming session semantics were read…*
  - **症状→后果**：这句依据会直接印在 `doctor` 输出、岛内自查卡与报表里。自报冒领「读到了会话强语义」
    等于**拿别人的证据给自己的结论背书**——用户据此会以为日志里真有那条信号，
    而实际只是一个带令牌的声明。这是本仓第一口径（不得把没看到讲成没有）的反向版本。
  - **修法（本轮已落地）**：`evaluate` 先看 `snapshot.provenance == .selfReported`，
    是则依据写「状态由带令牌、TTL 内的自报确认」，分类码暂时仍是 `.observed`（可信），
    因为**新增第六类结论是 05 号票的活**（那里要一起改「五类相加即总行数」的不变式）。
    这条取舍写进了代码注释与 05 号票的 Comments。
    同一处也顺手挡掉反向误报：自报与强语义**一致**时也走这句——那句话在两种子情形下都为真，
    而旧句在「压过兜底推断」那种情形下为假。
  - **能否自动修**：是（已自动修完）。

- **`Sources/AgentIsland/IslandView.swift:747 — 货架副标题只处理了冲突，没处理「可信自报」**
  - 审查者原文：*This branch handles conflicts, but a valid non-conflicting `.selfReported`
    snapshot falls through to generic subtitles such as "工作中" or "等待你确认". The main ring
    shelf therefore hides whether the state came from self-report.*
  - **症状→后果**：收起状态下用户只看得到货架那一行。若那里不写来源，
    「这一维」就只在展开列表里存在——恰恰是最需要它的时候（一眼扫过去）看不见。
  - **修法（本轮已落地）**：`"工作中" + AgentProvenance.badgeSuffix(snap.provenance)`，
    与卡片、悬停、详情共用同一个 Core 出口；结构断言补一条「IslandView 必须出现 `badgeSuffix`」。
  - **能否自动修**：是（已自动修完）。
