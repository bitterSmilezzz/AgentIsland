## 实现与反例

`usage_projection.rs` 使用原 serde_json 解码器，仅构建现有用量/上下文消费字段的 Value。逐项对照 tokens 与 Cursor 的字段访问，保留家族优先级、字段存在性、null、转义键、重复键最后值、缓存详情数组顺序以及原计算函数。未知值递归校验，不采用会放宽部分未知数字/Unicode校验的 IgnoredAny。根、标量及数组的错误类型不能意外暴露后备来源；原快速字符串预筛选和完整行读取保持。

这降低无关正文树的驻留与复制，未限制原始输入行、选中字段长度或全局缓存字节；含转义正文仍需要 serde_json 临时缓冲。详情数组仍可保留必要计数。未新增依赖、改变费用/净消耗、引入第二扫描器或宣称应用内存预算完成。

资源采样只在枚举后归属不可读且正 PID 的 signal 0 存在性检查明确返回 ESRCH 时单列退出。EPERM、其他错误、仍存在但不可读进程保持未知；已确认成员读回丢失保持 partial，主目标消失失败。signal 0 不投递实际信号。非原子枚举与身份复核的局限不变，旧 partial 不回填。
