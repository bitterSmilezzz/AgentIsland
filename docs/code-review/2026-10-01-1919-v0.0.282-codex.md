# v0.0.282 — Agent 身份图标审查

审查者：Codex。范围：内置 Agent 的身份映射、本地图标资源、五处 UI 接入、侧栏对齐与发布资源清单。

## 结论

当前改动无已知阻塞问题。身份与运行状态保持分离，收起贴条尺寸及检测、阈值、通知行为未改。全部 26 个内置档案都有独立身份；部分产品未核实官方图标，使用字母徽标，不能将其宣传为官方标识。

## 核查与修复

- 贴条展开列表和工作台原先共用终端图标，侧栏没有身份槽，详情方环依赖未打包的私有区字体字符。现共用本地静态身份渲染器，详情标题与方环同源。
- 注册表 `copilot` 对应 Tencent ima.copilot，审查拒绝 GitHub Copilot 图标映射；WorkBuddy 两个档案采用不同字母。自定义名称、标识与类名转义，继承属性不会被误认成目录项。
- 固定 Lobe Icons 修订，保留完整 MIT 许可与每组素材来源。SVG 均为独立静态向量，无脚本、外链图片或运行时 CDN；配色随主题调整，不随运行状态变化。
- 首轮截图发现 CSS 自定义变量中相对 URL 按消费它的样式表目录解析，图标为空；改用相对模块 URL 的绝对资源路径。截图等待所有 SVG 完成解码，避免把未完成加载误判为已验证。
- 嵌入资源哨兵曾拒绝遗漏的新增资源，现完整覆盖新增 JS、CSS、SVG 与许可文件；新增原生 WebView 检查在三个窗口解码全部 SVG 并检查遮罩尺寸，加载或样式失败即阻断发布。
