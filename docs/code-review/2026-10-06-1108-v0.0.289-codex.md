# v0.0.289 · 临时方案正文与任务关口连续性审查

审查者 Codex，2026-10-06。本轮范围：claude_plan_capture 独立主事件版本、macOS语义探针上下文、task_sources 指纹选择、tasks 既有事件晚到正文关联、task_artifacts 按需读取提示和五项受控文件集成回归。

问题与结果：临时正文进入/退出缓存不应成为新人工关口。消息元数据齐备的缺正文Claude方案使用可信源物理身份、主消息UUID与准确工具内容的不可逆版本，计算不依赖缓存存在或启用；artifact.event_ref仍保留正文摘要，专供精确读取，不进入该关口指纹。正文早到沿既有创建路径，晚到只补当前仍等待的开放observed方案关口，不新增运行、关口或收据。正文过期、停用或移出时保持现有引用与任务事件，读取只说明不可用并回来源。

归属与自检：任务/运行来源一致、当前运行、匹配收据、开放关口/类型、未具正文引用均必须满足。等待步骤可能复用同一运行，最初仅核对run_id不足以防止旧步骤误接新关口；已增加该运行最新观测收据复核，并以真实任务Store双步骤回归证明旧方案不会接入新关口。已人工处理、运行就绪、旧步骤或已有精确引用均不补正文；重新采集不同正文可生成另一个缓存引用，却不能替换任务中原版本。

来源与平台：版本共用既有逐级描述符来源校验，目录链与文件创建身份加入源摘要；文件追加不会因mtime变化而制造新关口。消息元数据齐备但身份无法核实时停止任务事件投影，避免从有版本退回无版本造成假新事件。缺必要主消息身份的历史方言沿既有路径，明确正文仍沿既有普通读取。正式探针的临时方案身份路径限macOS，不让Windows/Linux因未实现的本机文件身份能力失去原有语义投影。主消息或物理来源替换是不同版本，不冒称同一任务事件。版本计算不读计划文件、不接受planFilePath授权、不输出正文或路径。

受控证据：实际语义探针、生产task_sources/Store、真实临时来源文件和不可逆持久引用；正文先到的原回归，以及晚到/重复/过期/停止/容量移出/Store重建保持原关口；已处理/已结束不接晚到正文；不同正文不替换原引用；同ID主消息变化/同路径物理文件替换具有不同版本，symlink来源不投影；同运行新步骤拒绝旧收据正文。最初旧fixture的路径经过canonicalize而来源根未对应更新，严格身份核对正确拒绝；fixture改为同一自有canonical根，未放宽生产校验。

局限：尚未把缓存接进正式探针、读取命令与服务生命周期；运行中的当前版本正文还需真实Claude验证，Store重建不是原生UI或真实客户端证明。已有旧软件的不同指纹收据不能在没有消息版本证据时猜测迁移，不声称跨版本历史事件同一性。没有回答、批准或来源工具操作。
