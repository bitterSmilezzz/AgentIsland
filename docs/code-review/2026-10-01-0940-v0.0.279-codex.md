# v0.0.279 macOS 常驻与 Dock 审查

审查者：Codex。基线：v0.0.278。范围：应用呈现策略与图标。

## 改动与理由

隐藏工作台窗口不等于取消应用在 Dock 的身份。bundle 合并 LSUIElement=true，保留原有 URL scheme 声明；启动切换 Accessory，工作台唤回切换 Regular，收起和关闭共用隐藏入口并回到 Accessory。最小化保留 Regular 以便在 Dock 恢复。普通重复启动只复用实例，不自动展示工作台。macOS 之外不调整 activation policy。

应用资产采用原创 SVG 的暖白底板、深色胶囊与柔和状态点，由 Tauri icon 生成 PNG、icns、ico；菜单栏独立单色 template，不再使用缩小的应用图标。参考 UI Research 索引的常驻 UI 克制与静态身份规则，没有复制案例业务或加入动效。

## 验证

- Rust 全量：549 通过，5 忽略。门禁检查 bundle 合并配置、LSUIElement 及完整 icns 文件；深链 scheme 守护仍通过。
- 打包后的 Info.plist 确认 LSUIElement=true。
- 系统 AppKit NSRunningApplication 查询：默认 activationPolicy=Accessory，CLI 明确打开工作台后为 Regular。
- 原生回归脚本对正式 bundle 观察到 [Accessory, Regular, Accessory, Regular, Accessory]，覆盖默认、打开、收起、再次打开和标准关闭；该回归加入发布脚本。
- 普通重复 open bundle 后仍为 Accessory，未自动唤回工作台。
- 图标本地预览核对；工作区脱敏与空白检查通过。发布流程继续运行全历史门禁、UI 冒烟、原生 Dock 回归及单实例检查。

## 边界

系统已固定到 Dock 的快捷方式由用户的 Dock 管理，本轮控制运行时应用身份，不删除用户固定项。保留用户明确选择的侧边栏形态与命令行启动覆盖；默认设置为灵动岛。原生 Dock 回归通过测试参数临时驱动窗口，不在普通启动中运行，且不修改用户设置。

结论：范围内无阻断问题，可交付。
