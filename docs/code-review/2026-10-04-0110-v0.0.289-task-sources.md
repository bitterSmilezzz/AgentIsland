# 任务会话来源与同步审查

范围：implementation/03、07 的 B2/B3 来源绑定、事件同步与工作台导航。上轮本地任务报告保持原时间点，不改写。

## 核实与修正

- 引擎公开的是语义探测实际选中的来源，不是最新无关文件；来源文件路径只哈希为会话身份，动作原文不进入任务来源 DTO。无信号或无稳定来源文件时不提供虚构身份，CPU 本身不能绑定。Active 额外要求进程存在、文件近期更新，未知时间或旧活动不观测为执行中。
- UI 从后台来源列表选择工具和会话身份，绑定时再次核对；来源列表在草稿保护期间刷新也保留原选项对应身份，拒绝因索引漂移误绑另一会话。一个会话仅绑定一个任务，已有来源运行历史不换会话。
- 事件批量合入使用独立任务写锁，引擎锁已释放；没有绑定时不自动制造任务。去重包含来源命名空间和事件阶段，旧问题随新步骤过期。结果就绪不等于 accepted。
- 本地运行先存在再关联来源时，旧运行保留无来源身份，旧本地关口过期，新来源另起一轮。运行增加独立 source 快照，兼容缺该字段的旧本地记录。
- Codex 来源提问来自既有 request_user_input 解析分支，映射待回答；其他未分类提醒仅为需要确认。计划与结果自动引用仍未接入，手工记录继续明确为本地操作。
- 存储 UUID 通过既有 Codex 路由导航；历史会话不替换为最新会话。其他桌面工具复用已注册应用并标注仅打开工具，CLI 无入口明确说明。
- 工作台任务列表订阅记录和来源能力变化，来源未观测时给出标记，运行中显示“最后记录”口径；保存或读取期间的后续刷新合并到下一次读取，避免先到旧快照吞掉后续变更。详情编辑不被更新重画。
