# 窗口循环交换与撤销审查

范围：macOS 窗口执行规划、原生私有身份域、应用/撤销服务接缝及文档。无界面视觉改动；不宣称整体 macOS 计划或跨平台完成。

## 问题与实现

同尺寸双窗按相反顺序选择时，直接移动第一窗会与第二窗同几何，原生身份保护正确拒绝。红回归得到 Failed/Skipped；新的纯规划器在工作区内寻找短距离临时位置，必要时尝试4点尺寸收缩，每窗最多一次临时步骤，总步骤不超过2N。全部规划与能力核验先于写入，每步继续复核真实身份并实际读回；规划提示不放宽原有1点容差。

撤销复用同一规划，保留原始 before 与最后已知实际位置；已选但未变化窗口保留有界句柄，防止其占住全宽恢复的中间几何。含临时步骤的计划发生检查/写入/读回失败即停止，已知改动仍可撤销；未知读回不忘记前一步。手动漂移保持明确确认，失败返回目标矩形也不能直接宣称恢复成功。临时矩形、进程身份、原生句柄不作为IPC输入或持久字段。
