# v0.0.273 收起把手审查

审查者：Codex。日期：2026-09-30。

范围：Rust/Tauri 灵动岛收起态的四向把手。参考 ui-research 案例 12 的单一胶囊身份及索引的克制、非对称动效规则。

## 处理

- 旧微细条与工作台风格未同步。改为中性圆角底板、中央握持线与独立状态点，工作和提醒仅改变状态点。
- 沿用横向 152×20、纵向 18×132 窗口：横向把手 136×12 加内侧热区 8，纵向 12×116 加内侧热区 6；四向不越出窗口。
- 周期采样复用原有 DOM，只更新状态、名称，避免每次重新开始呼吸动画或丢失焦点。
- 增加可访问按钮语义、Enter / 空格唤回。隐藏设置仍覆盖整个胶囊的透明度；内部状态点不影响隐藏行为。
- 减少动效关闭点动画与过渡；减少透明度使用实色底板。视觉反馈不扩张窗口尺寸，不改变定位规则。

## 验证

Rust 全量回归、模块求值与样式隔离守护；浏览器四向几何、明暗外观、隐藏态和键盘展开验证。发布门禁继续执行扫描、三个窗口冒烟与冷启动单实例检查。

边界：Swift 回退界面没有改动，主交付物为 Rust/Tauri；旧版 macOS 与 Windows 未作实机视觉验证。
