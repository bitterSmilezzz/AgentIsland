# 灵动岛导航：持久表面与分层交接

用户连续反馈跳转生硬，本轮按真实体验重新检查。旧实现的主要问题是每帧原生 set_size/set_position 带来跨线程布局与落位，整页文字交叠产生重影；之前检查动画存在和最终尺寸，不能据此证明过程的品质。

本轮将灵动岛导航从通用页面淡入中分离，独立控制器保留同一个卡壳。原生窗口在开始预留旧新尺寸的最大包络，结束回收到目标；四个贴边方向的根容器对齐保持可见表面的锚点。内部宽高由 WAAPI 的同一时钟驱动，进入 420ms、返回 340ms，起步与收尾平缓；正文固定目标宽度排版，不缩放文字。标题先交接，正文稍后带极小位移进入，不让整页文字叠在一起。

中断读取当前可见几何与透明度，取消旧目标；周期采样不重建过渡中的页面，回到监控落定后补上最新状态。临时副本 inert、aria-hidden、去掉重复 ID，并排除用量数据注水。键盘进入聚焦返回按钮，返回聚焦原入口，同页采样保留焦点。减少动态效果直接切换，途中开启后导航也会取消旧动画。

自检迭代：首轮发现起步偏急、80ms 附近标题重影，调整形变曲线与标题交接时序；次轮检查四边的 160ms 中间帧，全部锚点固定；连续快速切换 16 次最终 300px 宽、无残留副本，焦点为设置入口。正常设置导航保持卡壳同一实例，原生落位命令仅预留和回收两次，最终 330×482。截图只使用模拟数据，未保存真实用户用量截图。

异步报告延迟 120ms 检查发现：取消 Animation 后再读取 finished 会得到新的未完成 Promise，旧几何对象若还在等待集合中，控制器永远无法落定。修正为取消前从等待集合移除旧几何。scripts/test-island-motion.mjs 模拟真实 WAAPI 的 finished 重新生成语义：旧实现在 300ms 门槛失败，当前实现通过；已接入全量 Rust 回归。浏览器重测延迟报告，加载占位目标不小于旧表面，数据到达后最终 330×520、副本清零、JS 错误为零。

检查范围包括正常进入、返回、快速中断、四边锚点、异步内容、减少动态效果和键盘焦点。获奖目标属于设计方向，不能仅凭这些检查宣称已达到某奖项的评审结论。正式发布仍需隔离桌面会话 UI 门禁，浏览器与手动原生检查不替代它。

最终验证：604 项 Rust 回归通过，6 项既有忽略，版本门禁与发布脱敏扫描通过；新构建由 restart-app.sh 验证重启。原生资源表包含新 motion 模块。实际进入设置仅记录两次 330×482 的预留/最终落位，未记录逐帧尺寸调用；返回后焦点为设置入口，真实用量页面与数据正常呈现。正式 release 脚本仍在隔离桌面 UI 门禁停止，未创建本轮 commit、tag 或 Release。
