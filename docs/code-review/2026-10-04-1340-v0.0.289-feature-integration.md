# 内建功能融合方向与首个目录选择流程审查

用户澄清融合要求后，整体方案、功能方案、开发方向及批次定义已改为内建能力优先。ADR 0023 明确连接上游/读状态不计为功能融合；ADR 0024 记录已完成的辅助传输边界。

模型目录按接口与协议保留身份，每个保存档位有独立选择，不任取同名模型的第一个接口。入口复用 provider_apply_profile 现有预览、expectedProfile、配置 revision 与备份链路；读取失败无可用动作，编辑器打开或折叠后仍有草稿时阻止跳转应用；取消编辑复位后可继续。前端受控验证预览、取消零写入与编辑保护通过，选择能力无需运行外部产品。并未新增其他工具写入或宣称改变运行会话。

传输六项真实 loopback HTTP 测试覆盖 GET、响应和认证边界、拒绝重定向/过大/压缩、受控错误与超时；服务四项纯测试区分身份/业务失败/权限，操作租约补充重入与释放验证。前端受控 IPC 验证手动触发、接口未核实不探测、成功权限不夸大、鉴权失败、配置变更清除旧成功、在途返回与控件解锁。实际截图检查发现通用标签将失败显示为绿色，已按语义改色并拉开标题间距。

全仓 cargo fmt --check 存在大量存量格式差异，不作为本轮全仓格式改造；仅格式化本批传输模块。真实网关/TLS兼容、完整原生 UI 与资源门槛继续保留，模拟页面不替代这些验证。

首次全套 Rust 回归 682 通过、0 失败、6 忽略，扫描含全部 Git 对象通过。受控补验覆盖折叠草稿保留、取消编辑释放保护、目录预览取消零写入，及未检测标签为中性颜色。后续构建重启结果见收尾记录。

补齐折叠草稿保护后的全套回归发现存量 TLS 夹具偶发失败（681 通过/1 失败）：两个并行用例以同一进程 PID 建目录，覆盖证书与密钥，Identity 导入返回 -50。夹具改为每用例 UUID 私有目录并作用域清理；10 项 transport 回归全部通过，不降低生产 TLS 验证。最终全量与重启仍按脚本收尾。
