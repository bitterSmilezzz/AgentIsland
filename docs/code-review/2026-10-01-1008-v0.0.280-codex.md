# v0.0.280 点击导致贴边跳动审查

基线：v0.0.279；审查者：Codex。范围为展开灵动岛的标题栏事件与吸附尺寸，未修改监控、Dock 策略或视觉样式。

## 问题与修复

标题栏原先对每次 mouseup 都调用 snap_nearest_edge，按钮事件冒泡和普通标题点击也会重新吸附。实际模块回归在旧实现上失败：按钮点击预期零次定位，实际一次。吸附高度还比内容尺寸多 20 像素，与正常内容尺寸校正不一致。

现在仅在左键从非交互区域开始、移动至少 5 像素后吸附。吸附使用内容高度与既有 520 像素上限，移除额外 20 像素。延迟回调遇到收起或标题节点被替换时退出，失败记录上下文。

## 验证证据

- 实际 JS 模块事件回归：按钮点击和标题点击零次定位，真实位移一次定位，传递高度 240 而非 260。旧实现红、修复后绿。
- Rust 全量回归：550 通过、5 忽略。
- 本轮构建成功并立即按约定重启。
- 原生 WebView 冒烟：三个窗口完成、无 JS 错误；实际按钮派发按下/松开后，Rust 定位命令入口的 test://snap 观察信号为零。信号仅在 --ui-smoke 模式发出。
- 工作区脱敏扫描通过；交付脚本还会执行全历史扫描、最终全量回归、Dock 显隐与单实例回归。

## 边界

原生验证为 WebView DOM 事件派发及 Rust 命令观察，未声称硬件鼠标拖拽或逐像素屏幕坐标验证。保留既有拖拽吸附算法和周期尺寸校正；本轮解决普通点击误触发定位与吸附尺寸不一致。

结论：未发现阻断项，按项目交付脚本发版。
