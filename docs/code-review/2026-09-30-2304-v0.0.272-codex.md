# v0.0.272 UI 审查

审查者：Codex。日期：2026-09-30。

范围：侧边导航、本机摘要、工作台概览和全部独立页面的控件与排版，及共享报告注水。

参考：ui-research 案例 08 的内容与侧栏信息分区、案例 09 的中性导航与细节权重。采用信息层级和颜色规则，不移植外部组件或装饰动画。

## 发现与处理

- 概览的全局 route 为 list，旧注水按全局 route 决定模板，会把用量区域填成智能体详情；首个选择器也遗漏同时存在的另一明细区域。改为遍历各区域、按父页面属性取模板及 agent ID，并忽略断开的区域。
- 智能体开关在工作台错误调用侧栏重建。按当前容器分派，保留工作台导航与页面。
- 报告缺少当前格式状态，未生成即可复制。加入可访问的 pressed 状态、生成期间禁用复制，并忽略过期格式响应；失败时继续禁用复制。
- 新侧栏摘要规则最初放在工作台样式中，被侧栏样式完整性守护发现。将侧栏摘要容器规则归入 sidebar.css，完整回归通过。

## 验证

- Rust：549 passed，0 failed，5 ignored；包含模块实际求值、样式覆盖与容器隔离守护。
- 浏览器合成数据：浅色概览、深色 880px 工作台表单、360px 侧栏；格式选择后复制启用；智能体开关留在管理页。
- 正式 Mac bundle：本机工作台渲染、导航摘要与用量趋势核对，重复打开保留同一进程。
- 发布流程继续执行脱敏扫描、三个窗口 UI 冒烟与冷启动单实例回归；脚本失败即停止发布。

## 边界

macOS 本机验证。Windows 与较旧 macOS 未作视觉实机验证；SwiftUI 宏插件缺失时发布脚本沿既有机制跳过 Swift 回退构建与测试。此次不改变监控、用量口径或配置业务。
