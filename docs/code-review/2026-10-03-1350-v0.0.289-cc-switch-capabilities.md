# CC Switch 可迁移能力审查

范围：协议模板、档位 JSON 迁移、备份关键字段预览与恢复、本机 MCP / Skills 只读清单。借鉴交互和边界，独立实现，没有引入第三方配置数据库或代码。

## 行为与边界

- 模板在现有接口来源选择器内，仅提供 Responses / Chat 结构。模型和 API 地址由用户填写，Chat 是否支持仍由目标客户端决定。
- 导出重新校验档位白名单后，用 create_new 写下载目录，拒绝覆盖已有文件。导入限制 64 KB、100 个档位、schema_version=1；未知字段、非法地址、重复 ID 拒绝。已有 ID 跳过，本机清单的 SHA-256 版本在确认时复核；单次原子写入，不应用 Codex。
- 备份预览仅返回五个关键字段和版本摘要，不返回 TOML、认证字段、命令或环境变量值。相同文件无需恢复。恢复核对双方版本，先保留当前文件，再原子写入经过验证的备份字节。恢复包含整个配置文件，界面明确提示 MCP 等设置会被替换。
- MCP 清单只检查 Codex 的 command / url 是否存在、enabled 状态，不返回其值。Skills 只检查固定目录下的子目录及 SKILL.md 存在性；不读取内容、执行工具或验证客户端加载。支持 CODEX_HOME，错误不能转换成空清单。
- 辅助区域保持折叠；清单首次展开才读取，没有新增导航或灵动岛入口。导入和恢复沿用确认框的 Escape / Tab 焦点约束。

## 验证

Rust 全量：603 通过、6 个既有忽略用例。新增测试覆盖导入冲突与版本变化、未知字段拒绝、导出文件、双版本恢复保护、还原前状态可恢复，以及清单输出不包含命令/变量值/技能正文。后续 CODEX_HOME 调整的定向测试通过。

浏览器使用实际 UI 模块与模拟命令，验证协议模板、按需读取、导入取消无写入与确认新增、备份差异及双版本参数、Tab 焦点约束、导出位置反馈，未发现 JS 错误；视觉检查确认折叠区域与控件布局正常。浏览器验证不替代原生 WebView 自动化。

发布脚本完成全量 Rust 回归与 Rust/Tauri 打包，本机应用经 restart-app.sh 校验重启；原生 AX 验证窄条与展开监控、设置页可显示。

发布仍受原生 UI 脚本的隔离会话要求约束：release.sh 没有传递隔离会话参数，当前桌面也不是隔离环境。没有绕过门禁或声称 tag / Release 已完成。

## 已知限制

预览只展示顶层模型与 Provider 字段，原生 profile 覆盖不展开；恢复前提示完整文件范围。外部程序在最后版本检查与文件发布之间仍可能竞争，进程内操作由全局锁串行化。MCP / Skills 是限定目录的配置清单，不是运行能力证明。导入只兼容 AgentIsland 的白名单格式。
