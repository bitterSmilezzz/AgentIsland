# v0.0.163 独立复核 · Codex · 2026-09-27 00:13

## 范围与结论

复核 Rust 可观测性判定、快照序列化、灵动岛顶栏和状态标签，以及与 Swift 既有
五类结论的差异。未发现阻止本轮发布的问题。修正了没有在线 Agent 时顶栏仍称
「全部待机」的文案。此轮只给 Rust 当前可取得的证据下结论，不声称行为完全对齐。

## 可核验的行为证据

- `observability.rs` 的纯函数测试覆盖五类代码、优先级、安装状态未知的处理、
  出站 JSON 结构、路径不是目录和采样时间边界。生产引擎只在进程在线且闲置时
  检查已登记会话根目录能否列举，判定与快照同拍输出。
- `app/ui/js/views.js` 的在线闲置行展示对应诊断；顶栏优先保留待确认、工作中、
  已完成信息，然后区分状态待核实、没有在线 Agent 和可信待机。
- `cargo test --locked --manifest-path app/src-tauri/Cargo.toml`：62 通过、0 失败；
  `cargo build --locked`、`node --check app/ui/js/views.js` 与 `git diff --check` 通过。
  发版脱敏扫描最初因 macOS Bash 的 `SIGTRAP` 停在提交前；批量 grep 与 C locale
  修复后，工作区 + 2172 个历史 blob 扫描通过，扫描器七条守护通过。Swift 测试
  由发布脚本执行。

## 边界与后续风险

生产采样没有安装探测，因此不会给出 `notInstalled`；`blindSessionSource` 只覆盖
会话根目录的访问错误，深层文件和解析故障尚无原因链。十分钟写入窗口也不能代替
Swift 的活跃会话数；历史 token 总量只能证明曾有记录。UI 未做自动化截图比对，
本轮只验证脚本语法与 Rust 出站结构。M3 后续需补齐证据来源和端到端界面验收。
