# v0.0.288 独立审查记录（Codex）

## 范围与结论

审查 Token 来源契约、请求修订、canonical SQLite 优先、模型/趋势时间范围、图标尺寸及内存方案。没有实施方案中的窗口销毁或后台暂停；内存基线属于上一正式构建，不能包装为本轮节省收益。

- Claude 不能用 Codex inclusive-input 减缓存公式；缓存创建总项与 TTL 分项取 max，不相加。message.id 优先合并同调用内容块，改动文件重建并取最完整修订；不变文件沿用文件戳缓存。
- MiniMax/OpenCode 独立缓存创建参加新鲜计数。ZCode 输出已经包含 reasoning，不另加；canonical DB 成功后不扫 rollout 镜像，schema 不可读才后备。engine 用量存在性包含声明的 SQLite token root。
- WorkBuddy primary/raw usage 兼容数组缓存明细与正值 cache miss；仅完成 assistant 或 function_call 入账。全局跨文件重复身份、Codex replay/event-only 与费用分量计价仍为明确边界，未宣称所有工具绝对准确。
- 模型累计与 24h 分开；折入旧 JSONL 仍保留模型归属。SQLite 周期导出和小时图共享来源时间字段。原生图标尺寸验证使用 canvas 的实际 alpha 边界，PNG 不裁剪或改源文件，DOM 外框统一。
- secret 基线未扩大。新增文档不包含私人会话、账号路径、实际用量、凭据；本地比较只存计数于忽略目录。
