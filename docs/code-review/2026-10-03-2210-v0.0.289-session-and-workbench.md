# 会话动作、设置返回与工作台审查

审查时点：2026-10-03；版本 0.0.289。本报告只记录这一轮证据，累计未发版改动另见同版本前序报告。

## 问题与修改

- 设置返回：表面收缩与标题/正文反向位移叠加。真实导航模块回归在旧实现失败；移除文字位移，并在预留原生空间后等待 viewport 回执。测试证明该叠加路径已移除，不能据此宣称所有原生抖动根因均已排除。
- 状态行动：资源问题给出 CPU 偏高、内存增长或疑似卡死；等待确认显示当前动作，完成显示查看本轮结果。按钮与用量详情分开，避免嵌套可点击控件。打开会话不自动批准或忽略提醒。
- 定位：本机应用注册的 `codex` scheme 与应用源码中的 `codex://threads/<threadId>` 一致。Codex 目标来自语义探测选中的 rollout；内部提醒冻结触发时目标，外部无可靠 ID 的事件只打开工具。服务器校验事件、所属 agent 和 expected URL，不接受任意可执行地址。
- 工作台：概览保留监控、待办与常用入口，详细配置和导出进入独立页；切页保持导航、顶栏和正文容器，当前页重复点击不重建输入。正文短交接，连续导航取消旧动画，旧副本 inert / aria-hidden，减少动态效果时直接切换。
