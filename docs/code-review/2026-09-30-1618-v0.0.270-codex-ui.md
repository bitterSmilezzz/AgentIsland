# v0.0.270 · 桌面面板与重复图标修复审查

## 改动与原因

侧边栏与工作台使用共用 panels.css，表面、边框、悬停态由深浅主题的语义变量提供。工作台两栏分别容纳监控/待办/报告与用量/档位。导航、待办、报告与返回使用原生按钮；字段有持久标签，焦点可见。待办重绘保留草稿与勾选按钮焦点，输入法组词回车不会提交。监控详情局部切换，不重建其他表单。

重复图标有两个已核实来源：ps 显示旧 AgentIsland-Rust.app 与主应用两个进程；Tauri 本地源码 app.rs 的 build 路径会依据 app.trayIcon 自动创建 main 托盘，而本项目 setup 又调用 TrayIconBuilder::with_id("main")。删去配置自动托盘，保留交互托盘；单实例插件首先注册，并启用 deep-link 转交。重复启动显示已有工作台。CLI 在插件与窗口初始化之前退出，不受单实例限制。

## 边界与结论

当前机器没有 SwiftUIMacros，Swift UI 回退包与 Swift 全套测试未验证；本轮主交付物为 Rust/Tauri。Windows 日历模块可编译不等于 Windows 整体应用可编译，保留既有边界。截图与合成验证夹具留在本地、不入发布包。审查未发现本轮范围内阻塞问题。
