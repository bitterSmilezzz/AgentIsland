# v0.0.289 Codex 档位优化审查记录

本报告审查本轮档位后端、Tauri 命令与静态页面的工作区改动。该版本同时包含已经提交的后台内存与窗口生命周期改造；本报告不代替那部分的原生验收。

## 结论与边界

档位身份不再仅由 Provider 名称推断：模型、Provider、地址、环境变量名与协议均须一致，多个完全相同的别名不强行选择。页面展示配置目标，不声称运行会话已经换模型；无法从现有监控快照独立证实运行模型时保持明确的生效条件说明。

上次应用记录只保存档位字段。模型与接口字段漂移由磁盘事实判断，普通注释和不受管理的重试字段变化不报漂移；特殊认证覆盖不判一致。重新应用先备份，保留当前只解除记录、不写 Codex 配置。配置版本与待应用档位快照分别防止外部文件改写和另一个窗口的档位编辑；本应用写入互斥，外部进程在最后检查到原子替换之间仍有极短竞态，不承诺跨进程事务。

从当前配置保存采用字段白名单，原始 TOML、认证头、auth.json 和凭据值不交给界面。原生 profile 与不能重现的认证方式明确拒绝；向含特殊认证的已有 Provider 写入亦拒绝，要求使用独立 Provider 标识。地址拒绝 userinfo、query 和 fragment，模型限制为保守标识。清单损坏时读与写均报告失败，保存、删除不会将损坏文件覆盖为空清单。错误不输出解析原文，配置细节不写 UI 日志。

页面保留现有主题；编辑器以名称、模型与接口来源为入口，高级字段和备份折叠。模型按钮可直接进入编辑器；保存不立即应用，应用先看差异。保存失败保留输入；替换编辑内容、刷新、还原与删除都有显式确认。确认框隔离其他控件，Tab 在确认/取消之间移动，Escape 取消并恢复焦点。
