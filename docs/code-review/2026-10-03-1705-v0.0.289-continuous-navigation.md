# 连贯页面过渡修正

用户反馈上一轮淡入仍像硬切。实际浏览器复现：点击设置后旧画面副本为零，仅新页 210ms 入场。上一轮只证明动画存在，未证明旧新页面连续过渡，验证标准不足。

修正为旧页退出与新页进入交叠。进入 320ms、返回 260ms，内容带 14px 方向位移，旧页在该时长的 70% 内淡出。副本 inert、aria-hidden、移除重复 ID，结束立即移除。只在路由变化时创建；采样不创建，减少动态效果直接切换。尺寸使用同一时长的余弦缓动，放缓起步与收尾。

实际模块的浏览器回归：点击设置时观察到一个旧页副本与 224ms/320ms 两个动画；副本不可交互、无重复 ID；动画结束副本为零，窗口目标 330×482。连续快速跳转最终 300×306，副本为零；减少动态效果动画与副本均为零；JS 错误为零。浏览器最初缓存旧脚本，发现仍显示 210ms 后换新 origin 重测，以上记录均来自新脚本。

旧页副本是临时视觉内容，不保留事件处理，不写入磁盘，不替代正式导航或真实数据。无法仅以动画时长断言主观丝滑程度；最终仍需原生应用体验核验。

全量 Rust 回归 603 通过、6 个既有忽略；脱敏扫描与 diff 检查通过。新构建由 restart-app.sh 验证重启，原生监控与设置页面正常呈现。工作台也验证旧新交叠与结束清理。正式 release 脚本仍停止在隔离桌面会话门禁，尚未提交、打 tag 或创建 Release。
