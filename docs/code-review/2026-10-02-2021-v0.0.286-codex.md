# v0.0.286 真实产品图标复核

审查者：Codex。范围：国内产品原始素材、身份对应、原色渲染与离线交付。

## 证据与修复

上一轮用原创图形代替缺图标产品，未满足真实标识要求。本轮逐项核对来源：DimAgent、ZCode、Qoder、Vibe Usage、WorkBuddy、WorkBuddy AI 的 Info.plist 包标识与 CFBundleIconFile 对应本机原始 ICNS；通过 sips 转为 128px PNG，没有重画、裁剪或改色。ZCode 3.14.4 的真实图案为黑底白 Z，删除原创闪电 SVG。两个 WorkBuddy 5.6.2 的原始 ICNS SHA 相同，保留真实相同图标而以名称区分。

ima、TRAE、Xiaomi MiMo 取各自官网 HTML 声明的 favicon，不通过第三方百科或素材站猜测。MiMo 与本机另一个 MiniMax Code 包不是同一产品。OpenViking 与 DSH 取各自官方仓库固定提交的 favicon。完整 URL、提交、包标识、版本、处理和校验和在 official-sources.json 中；ima 仅 CRLF 转 LF，MiMo 仅 ICO 转 PNG。上游许可原文保留，来源说明区分产品素材、Lobe 标识和本项目原创兜底。

共享组件增加原色图片分支，官方图片不走单色遮罩。浅色 backing 保持黑色/透明素材在深色主题中可见；所有资源随应用嵌入，不运行时联网。旧原创文件删除；检测、用量、Agent 合并与禁用迁移不改。

## 验证

目视核对本机六个应用图标和官网素材预览，真实品牌图形与已核对来源对应。Rust 577 通过、0 失败、5 忽略；身份脚本增加静态文件路径、PNG 签名、官方来源及 SHA-256 守护，五处共享视图和自定义兜底检查通过。功能 UI 和 diff 检查通过。

原生冒烟扩展到 PNG/SVG 图片解码、自然尺寸、显示尺寸以及已有遮罩 SVG。构建、三个窗口、Dock、单实例与全 Git 对象脱敏由 release.sh 在提交前执行，任何失败中止。提交前报告不预先宣称发布门禁通过；本轮未启动 Chrome。
