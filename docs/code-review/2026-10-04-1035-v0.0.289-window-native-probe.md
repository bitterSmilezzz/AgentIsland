## 实现与修正

- NSScreen 在主线程读取；AX 枚举在后台执行，带单消息超时与批次时间预算。按注册 bundle ID 选择真实应用实例，保存 PID、启动时间与 retained AX 对象。标题不是身份，也不写文件或日志；CF 值读取前核对类型，所有 Copy/Create/Retain 值有释放。
- AXWindows 先读取数量再按实际数量有界复制；避免固定请求 32 个时，小窗口列表被系统以越界拒绝。超过上限和超时返回警告，不能宣称完整枚举。
- 辅助功能检查不触发 prompt，不激活或移动用户窗口。移动/缩放能力分别检查，错误不当作可写；最小尺寸未知不猜数。全屏/最小化已读为真时明确限制；其他桌面可见性还需 C2 接入核实。
- 主屏菜单栏坐标原点转换工作区矩形，使用逻辑点；屏幕 ID 来自当前屏幕几何/顺序指纹，应用前必须重新读取核实，不能当作长期物理屏幕身份。
- 后台 Store 持有对象，IPC 只含 UUID；预览只能使用后台列表中的窗口/屏幕。刷新替换所有身份并清除预览，版本或 60 秒列表时限不满足拒绝。选择顺序保持，15 秒预览时点已记录；实际 apply 尚未实现，不宣称已经执行过期校验。
