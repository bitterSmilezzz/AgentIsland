# v0.0.290 · 隔离验收环境落地与原生门禁 VM 化

审查者：ZCode。2026-10-07 00:30（Asia/Shanghai）。

## 背景

v0.0.289 发版时确认的两大欠账之一是「隔离原生验收」：原生 UI/Dock 测试要求
`--isolated-session`（隔离用户会话或虚拟机），本机两者皆无，导致原生层验收
自 v0.0.288 后长期空转（traework 图标回归正是趁虚而入）。本轮目标是把这条路
永久打通：搭建 macOS 虚拟机隔离环境，并把原生验收欠账清掉。

## 隔离环境（tart VM）

- **宿主**：Apple Silicon，macOS 27.0.1 (26A434)，32GB；**guest**：tart 2.40.1
  （Cirrus Labs 官方签名二进制，SHA256 与官方 checksums 交叉核对后经镜像加速获取）
  + Apple 官方 IPSW `UniversalMac_27.0.1_26A434_Restore.ipsw`（与宿主同 Build），
  `tart create --from-ipsw` 无人值守安装，6 vCPU / 12GB / 50GB。
- ** guest 与宿主同大版本 macOS**，WebKit 验收保真；guest 拥有独立 WindowServer/Aqua
  会话，测试的全部焦点扰动留在隔离会话内。
- **SSH 通路**：自动安装未跳过 Setup Assistant（语言/迁移/Apple ID/年龄/外观/
  定位/分析/屏幕时间/Siri/FileVault/自动更新/Liquid Glass 十余屏），全程用
  vncdotool（VZ experimental VNC + 截图驱动）逐屏完成 OOBE；随后在 guest 终端
  以 `launchctl enable/bootstrap system/com.openssh.sshd` 启用远程登录
  （`systemsetup` 因 Full Disk Access 限制不可用），注入公钥后免密。
- **guest 内依赖**：无 Xcode CLT——Dock 策略读取用宿主预编译的 `policy-helper`
  （`POLICY_HELPER` 环境变量注入，`test-dock-presence.py` 默认行为不变）；
  Python 用 guest 内 Miniconda 3.14.7（清华镜像），运行器经 `PYTHON` 变量显式指定。

## 隔离会话发版门禁（本轮主交付）

`run-gates.sh`（VM 内）依次执行：

1. **UI 冒烟**（`ui-smoke.sh --isolated-session`）：三窗口 `state=done`，
   island 5、sidebar 7、workbench 16 个可点元素，27 个图标尺寸达标，零页面错误；
   空态正确（「暂无在线智能体」空态在场，box=144.78）——**PASS**
2. **Dock 显隐回归**（`test-dock-presence.py --isolated-session` +
   预编译 helper）：五段序列「默认隐藏 → 打开显示 → 收起隐藏 → 再打开显示 →
   关闭隐藏」完整，`observed == [1,0,1,0,1]`——**PASS**
3. **单实例回归**（`test-app-instance.py --cold`）：冷启动双开仅保留一实例——**PASS**

汇总 `ALL GATES PASS`，RC=0。证据：`.build/vm/results/gates-isolated.log`（guest
`~/agentisland/results/gates.log` 原样取回）。这意味着 08 号文档「发布环境：真实
隔离 UI 会话/VM」门槛**已具备**，后续发版可在 VM 跑原生门禁，不再依赖桌面授权模式。

## 应用侧改动（随本轮发版）

1. **`agentisland://workbench-hide` 深链 + CLI `open workbench-hide`**：与
   `workbench`（打开）对称的收起动作，走关闭按钮同一条 `conceal` 路径
   （隐藏而非销毁，90 秒无草稿后释放）；`reveals_window()` 为 false，不触碰
   任务/配置状态。动机：内存专项需要程序化开关工作台，同时补齐工作台深链面的
   show/hide 不对称。deeplink 解析与 CLI 命令表均有测试。
2. **`test-dock-presence.py` 支持 `POLICY_HELPER`**：指向预编译 helper 时跳过
   swiftc（VM 无 CLT）；默认现场编译行为不变。
3. **`--dock-smoke` 实例标识隔离**（v0.0.289 发版轮已做，随本轮入库）：测试实例
   不与运行中的应用撞单实例机制。
