## 已修正的实际问题

- 同时冷启动时，单实例插件的 socket 异步绑定尚未完成，可能留下两个实例。应用进入 Tauri 前获取文件描述符管理的启动锁，setup 完成后释放；CLI 先行分派。新增同时冷启动回归，两个进程一个退出 0，一个保留，并继续验证重复打开。
- 详情保护不能只看报告容器存在：另一智能体路由需要重建详情。以已渲染路由与当前路由相等作为保留条件，周期采样保留报告，切换详情允许刷新。
- 工作台提前返回导致后方深链监听不可达。监听移到工作台启动分支，分析、导出与智能体详情各自进入正确页面。
- 冒烟添加八项导航后，原 15 秒窗口不足。提高为 30 秒；空态检查区分存在真实智能体与没有智能体，不将有数据时没有空态误判为失败。
