# v0.0.285 图标补齐复核

审查者：Codex。范围：内置身份图形覆盖、自定义兜底和资源交付。

## 发现与实现

注册表 24 个内置项都有映射，但其中 10 个仅使用字母徽标，用户仍视为缺图标。补齐这 10 个本地静态 SVG：Dim、ZCode、VS Code、Aider、ima、两个 WorkBuddy、Continue、Vibe Usage、OpenViking。保留既有产品标识与全部列表/详情的共享组件。

自定义、未知和空名称使用独立 SVG 兜底。移除依赖名称首字母的显示分支，动态 ID 仍 HTML 转义，对象原型同名 ID 不读取继承属性，资源名只能来自静态映射或固定兜底。没有联网图标或字体依赖。

图形是本项目原创识别图案，不声称官方商标；逐项说明与本项目 MIT 许可对应。更新嵌入资源样本清单与准确长度，原生冒烟覆盖所有内置图形和自定义图形，而非仅检查 CSS 类名。

## 验证

系统 Quick Look 渲染合成的 18px 明暗图集并逐项目视核对；图集只包含图标与公开产品名，不含用户会话，不入库。Rust 全量 577 通过、0 失败、5 忽略。共享身份脚本要求每个内置项均使用图形资产，并检查五处视图和未知/空名称/对象原型同名兜底；功能 UI 和 diff 检查通过。

构建、三个原生 WebView 图形解码、Dock、单实例和脱敏扫描由 release.sh 在提交前执行；失败中止发布。本报告不预先宣称门禁成功，不修改检测和 token 统计语义。本轮未启动 Chrome。
