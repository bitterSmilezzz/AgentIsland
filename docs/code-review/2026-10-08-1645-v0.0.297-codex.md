## 行为复现与修复

没有 thread_id 的 Claude 来源，在列表中显示来源编号尾号，搜索却只覆盖 thread_id，输入可见编号得到零项。现把已有 source.session_id 纳入同一搜索范围，完整编号与可见尾号都可查找，并与工具、来源、任务名称筛选组合。来源身份、目录扫描与打开能力不变；找到该来源仍明确显示“打开工具”。旧实现的可失败用例已复现，补齐编号及能力边界回归后通过。

工作空间异步预览无条件滚动并聚焦关闭，用户等待期间选择顶部“前往”后仍被拉回。生产页面与受控延迟 IPC 红例核对实际 activeElement 和滚动调用；修复在滚动和最终聚焦前分别检查焦点归属，主动选择其他控件时只呈现结果。正常预览仍定位关闭，失败或中途切页保留草稿，离页响应不聚焦其他页面。

50 个组合的最小工作台中，Esc 恢复焦点但入口在视口外；同步 focus 或 instant scroll 在滚动中返回仍会遭遇旧合成帧再移动266px。最终关闭先中断滚动，恢复焦点后在下一动画帧核对当前页面、预览隐藏与用户焦点，再定位可见入口；后续用户选择优先。已完成、动画中、减少动态和返回后立即选择其他控件四场景通过；原预览四场景继续通过，不改变组合写入、补偿或来源校验。
