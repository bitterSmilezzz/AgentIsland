# v0.0.275 深链交互审查

审查者：Codex。基线：v0.0.274。范围：Rust/Tauri 前端的运行中深链导航。

## 发现与修复

- 灵动岛导航处理位于只供侧边栏执行的 boot 分支，在岛窗口中没有订阅。移回岛的启动链，并处理 Collapse；展开、切换、用量、详情均沿用现有渲染与窗口定位接口。
- Rust Debug 意图中的 Agent(String) 包含 JSON 引号，原先仅去掉括号，把引号写入 agentDetail 路由。三种窗口共用解码函数，损坏意图不改变当前路由。
- 用量和详情完成渲染及注水后同步窗口高度；解码模块纳入完整资源校验清单。

## 验证证据

- cargo test --locked --manifest-path app/src-tauri/Cargo.toml：545 通过、5 忽略。
- 新增 Node 回归加载实际 main.js boot，记录实际事件订阅并投递意图，验证展开/收起尺寸与页面路由；同一回归在 v0.0.274 代码中准确失败于缺失订阅，在修改后通过。
- 打包并执行 scripts/restart-app.sh 后，经 CLI 和原生辅助功能树核对：展开显示监控列表，收起恢复微细把手；用量打开分析页；Codex 详情在工作台和岛窗口均识别为正确智能体。
- 工作区脱敏扫描通过，版本五处一致；发布脚本继续执行全历史门禁、原生 UI 冒烟和单实例检查。

## 边界

无配置或外部通知写入，无监控口径、样式或归档端改动。DOM 桩验证事件行为，不代表布局截图验证；原生验证针对已完成启动的应用，不扩展冷启动深链时序处理。保留已有启动及窗口广播机制。

审查结论：本轮范围内无阻断问题，可按仓库发布流程交付。
