# Vibe Usage 身份边界审查

Vibe Usage 是用量统计工具，移除误列为 assistant 的内置档案，包括进程和 bundle 匹配、会话目录以及前端身份资源。引擎由内置档案驱动，因此该工具不再进入内置监控和管理列表；没有移除真实 Agent 的 Token 读取器或外部调研引用，也没有修改用户自定义档案。

现有身份边界回归更新为 24 个档案，并断言 Vibe Usage 与 Ego 浏览器不在内置集合。身份资源测试通过所有内置档案与五处 UI 渲染检查，git diff --check 通过。CONTEXT 固化工具与智能体边界；工作台历史对拍文档增加当前口径提示。

构建、Rust 回归、扫描和重启结果在提交前补记。发布仍遵守原生测试隔离会话门禁。
