## 实现与边界

正常应用启动接入可选 Runtime；默认不采集、不安装用户 hook。已保存显式 opt-in 仅在自有命令与配置绑定仍一致时恢复。demo、后台测试与 UI smoke 不恢复服务。引擎关联与精确正文读取注入同一内存缓存，仍沿用主消息版本、物理来源与原调用输入验证，不由采集单独制造任务或关口。

配置预览先复核再停止有效接收，错误确认不会打断服务；自有备份清理不停止接收。暂停先清缓存，再保存重启设置，保存失败明确区分本次已停与重启未核实。接收线程每秒独立核对配置与启动绑定，完整帧入缓存前再次核对；失效时清缓存、关闭自有端点。读取还保留同步 guard。锁中毒停用时回收 guard，避免带锁等待工作线程；工作线程退出也恢复中毒锁以清缓存。文件系统调用仍不具绝对延迟保证。

扩展区默认折叠，配置与启动分别操作。恢复记录按时间排列，正文不进入列表；状态含当前版本是否可还原。操作绑定记录 ID，避免列表顺序变化作用于其他记录。后台刷新保留展开记录和按钮焦点，预览期间不轮询。刷新旧预览先取消；未知执行结果清掉确认并阻止重复修改。
