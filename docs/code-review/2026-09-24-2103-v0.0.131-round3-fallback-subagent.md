### P1 — 重要

- **P1-1 `Sources/AgentIslandCore/SelfReport.swift:271 + :803` — `text()` 取消「纯空白按没给」之后，未鉴权请求可以把岛内横幅主行与系统通知正文刷成空白，并让 `ask` 遮蔽掉 `detail`**

    改之后 `ask: ""` 与 `ask:"   "` 都是**非 nil 的空白串**，`message` 就此被它占住。而下游三处消费都只区分
    「nil / 非 nil」或「nil / 非空」：
    - `Sources/AgentIslandCore/Models.swift:482-485`（`summaryText`）：`if let message, !message.isEmpty`
      —— 纯空白**过得了这个闸**，于是横幅主行返回 `" "`（岛内那一行变空白，`completed/attention/costSpike`

    可达性：**不需要令牌**。`LocalEventServer.swift:317-327` 对无凭证请求照样走
    `SelfReportFallback.post`，任何本机进程（macOS 13 那条构建路径下还包括局域网，见 `SelfReport.swift:745-747`

  - **建议修法**：协议层保持 `text()` 不动（内容不许被改，这条立得住），把「空白等于没说」放到**出口侧**判：

    `message: [submission.ask, submission.detail].compactMap { $0 }.first { !$0.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty }`，

    已经是这个意思，只是判断写窄了）。补一条**落回层**的用例（现有那条只钉在协议层）：
    `state:"attention"` + `ask:"  "` + `detail:"在等确认"` ⇒ 事件 `message == "在等确认"`、`summaryText` 非空白。
  - **能否自动修**：是（一处取值 + 一处 `??` 链 + 1 条用例）。
