# 窗口排列执行与撤销协议审查

范围：NEW-04 / C2 的可替换执行接缝与预览消费。原生只读探针报告保持原时间点。

## 修正与行为

- AX 后台读取补 autoreleasepool；设置消息超时失败时停止相应读取，不以默认超时继续。预览失败清除旧目标，使用单调时钟记录真实寿命。
- broker 拒绝未知预览/版本、15 秒过期、时钟回退、目标屏幕丢失及工作区/scale 漂移。有效预览单次消费，选择来自后台持有的句柄，不接受前端矩形。
- inspect/write 接缝承载原生身份核验。写前全部预检，一窗失效或漂移则零写入；执行中再次核验，不把过程竞态变为自动整体回滚。逐窗 Applied/Failed/Skipped 保留实际读回；不使用请求目标冒充实际结果。
- 失败但已发生部分位置/尺寸变化同样保留撤销记录。未知实际结果不盲目恢复，返回核对说明。非有限读回不当作有效位置。
- 撤销区分已关闭/身份变化与暂时不可用：前者跳过，后者保留重试。用户手工改动先返回 Conflict，强制选择只接受已观测冲突身份；恢复部分失败保留最后可读位置，避免用旧 target 掩盖副作用。
