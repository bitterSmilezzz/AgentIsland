## 本轮抓到的真 bug（静态推理，不是测试）

`island.css` 的 `#root { position: fixed; inset: 0; display: flex }` 在**侧边栏窗口同样生效**，
而侧边栏的 `.sb` 是 `#root` 的 flex 子项 ⇒ **整列缩成内容宽，而不是铺满窗口**。
它不报错、只是长得不对，而本机看不到像素 —— 所以从 v0.0.187 起一直存在。
修法与原文不同（见下），但**目的是达到了**，而且这次留下了能静态核对的东西。

## 可核验的行为证据

- **哨兵**：`the_two_shells_styles_cannot_bleed_into_each_other` 守三条事实，各自反证过：
  1. `sidebar.css` 每条规则都在 `.shell-sidebar` 下（反证：加一条裸 `body { color: red }` → 红，
     报「sidebar.css 里有一条没收敛的规则会漏到灵动岛」）；
  2. `island.css` 的元素级规则都在 `html.shell-island` 下（反证：把 `#root` 收回 → 红）；
  3. 挂形态类的内联脚本排在样式表**之前**（反证：挪到 `</head>` 前 → 红，
     报「收拢的规则会在第一次绘制时缺席」）。
- **运行时证据**：两种形态各起一次，日志里两个窗口**各记下自己的形态类**
  （`[webview] shell=shell-island …` 与 `shell=shell-sidebar …`）。顺带印证「隐藏窗口也会跑 JS」——
  这正是 v0.0.188 那个 capability bug 的成因。
- **「切十次无残留」改为结构性证明**：`tauri.conf.json` 只声明 2 个窗口；运行时
  **没有任何** `WebviewWindowBuilder` / `destroy` / `close`；切换只做 `show()` / `hide()` + 摆位
  ⇒ 残留不可能发生。**比按十次更强**（十次只证明那十次），但我仍标注「没按十次」。
- **测试** Rust 271 → **272**；连跑 5 次全绿；编译警告保持 **14**。

## 为什么不用原文的做法

原文第 7 条要「拆成 island 专属 + 共用组件两份、专属部分只在 island 壳下挂载」＝条件加载 CSS。
那一步写错会让**灵动岛整块失去样式**，而本机无法证实结果 —— 与本计划自己的纪律
（「任何一个模块迁完无法证实行为不变，该模块回退」）相反。
改成**收敛元素级规则**：同样达到「不串味」，且失败路径有明确回落（取不到形态就 `island`，
与默认值一致），代价是类级规则仍靠命名空间（`sb-*`）隔离。
**差异与理由写进了计划文档**，不是悄悄改掉。

## 边界与后续风险

- **类级规则的隔离靠约定**：若有人在侧边栏里用了灵动岛的类名（`.card` / `.row` …），
  哨兵只能间接发现（`.sb-*` 的覆盖哨兵会要求它出现在 `sidebar.css` 里，但用岛上的类名并不要求）。
  真要根治得给两套样式各自加前缀并逐个改选择器，收益不大、改动面很大。
- **像素级实样仍未做**：这是整个改造唯一没有实样支撑的部分，已写进 README 与 ADR。
- **`~/.codex/config.toml` 从未被真实切换过**：验证全在沙箱/临时目录。
- **Rust 端尚未成为默认交付物**：ADR 0012 记了理由与「新用户默认看侧边栏」这个开放项的答案（不做）。
