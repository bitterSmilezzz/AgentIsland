# v0.0.287 独立代码审查 — Codex

范围：远程通知简化、飞书/微信/QQ 接入、图标与单条完成行、灵动岛导航、MiniMax Code 状态与 Token 账本。

## 审查结论

未发现阻止进入发布门禁的问题。凭据由 password 控件单独交给钥匙串，不进 Settings；空保存不会删除，业务失败不误记成功，预览遮盖 URL 路径、Token 与签名。飞书地址限官方 HTTPS bot 路径；QQ 地址不得嵌入认证参数，令牌禁止 HTTP 头控制字符。重定向仍拒绝。

MiniMax 用量只读独立账本，时间戳按毫秒、缓存计数不加到新鲜 Token，不扫描消息镜像。状态只读投影列，不把未使用 idle 或过期 started 当作完成/在途。覆盖默认目录；命名 profile、厂商实时额度、所有框架的授权等待不在本轮承诺内。

原始产品图标不重画；白边来自额外显示底板，彩色图标取消底板，仅黑色透明 ima/DSH 保留浅色衬底。ChatGPT 图标取当前包 CFBundleIconFile，MiMo 与 MiniMax Code 取已核对包标识的当前桌面应用 ICNS。所有新资产进入嵌入清单并核对身份来源。
