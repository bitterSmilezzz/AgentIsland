# 本机工具预算审查

范围：NEW-06、KEEP-03、UX-02；工作台的按工具滚动24h预算、来源状态、阈值提醒、持久化和草稿生命周期。接口历史归因、服务商配额、路由执行及整体macOS品质不在本批完成声明内。

## 实现与边界

预算直接消费工具快照的净token，与卡片同源；未取得用量和关闭监控保持未知，实际零值可见。提醒按工具独立80/100/75阈值滞回；没有数据或关闭提醒不消费跨级、不重新武装；调整/删除预算复位记忆。默认空表无额外用量扫描或网络请求。整体与工具预算可以各自提醒，不强行归属某一会话。

逐项保存验证工具ID、整数范围和期望上限，引擎锁覆盖比较、原子设置写入与内存发布；失败不发布新状态，保留其他设置。常规设置patch拒绝整表覆盖。规范化和写入容量有界；这不是跨进程文件事务锁。

入口默认折叠，首次展开优先选择需留意的预算。每工具草稿与原比较值独立保留，刷新不隐式覆盖冲突；取消采用已读取的当前值。写入中禁止重复提交，切页仍可继续，回执更新原缓存页。全部隐藏草稿及待完成请求维护原生窗口租约，工具选择不产生虚假未保存状态。WebKit禁用输入后恢复焦点的条件限当前展开页面且用户未移走焦点，支持失败后Enter重试，不激活缓存页面。
