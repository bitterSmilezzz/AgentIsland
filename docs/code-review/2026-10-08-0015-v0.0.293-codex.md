## 现象与修正

受控浏览器880×560中，窗口排列页的固定240px画布把预览/应用按钮推到y625，首屏无法同时选择窗口和执行主要动作。收紧本页标题/工具栏/规则留白，画布随视口有界变化；候选列表独立滚动。长工具名允许换行、会话标题省略，焦点轮廓和键盘滚动可用。没有更改原生窗口最小尺寸、启动放置或后端排列坐标。

画布压低后，目标屏幕必须同时适配宽高并保持原比例，否则示意会拉伸。使用后端工作区长宽比限制示意宽度，目标窗口继续按原百分比坐标绘制；纵向屏幕也保持正确比例。保存与历史仍折叠，错误/结果可以自然滚动，不自动应用布局。

交互中复现撤销结果替换旧按钮后，焦点落到屏幕外的“读取窗口”（y约-27）。更新后明确选取当前结果中的冲突确认、撤销按钮或结果区，最小滚动至反馈；结果区可程序聚焦，不进入普通Tab顺序。异步结算仍检查页面内焦点，导航或其他页面焦点不被夺取；待聚焦引用在结算时清除，不遗留到后续请求。
