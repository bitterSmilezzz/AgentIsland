## 边界与结果

通知测试按钮为用户手动操作，仍受总开关限制，通过后台线程发送；发送结果只表示服务器接受，不保证手机或收件箱到达。现有 SMTP 465 与 HTTP/TLS 离线回归保留，本轮没有使用用户凭据或主动发真实测试消息。IM 使用 HTTP 模板，不新增各家机器人协议。锁屏标记仍未读取，显示器睡眠/无输入时长已接入，无法采集时遵守既有 fail-open。

目录扫描保持深度/条数上界；不宣称对每个第三方工具都有完整会话语义。阈值在下一次采样生效，UI 文案如实说明。旧版本已清空的字段不能猜回，用户可在通知页核对后使用手动测试。

结论：本轮已复现问题均有回归证据，未发现发布阻断项。
