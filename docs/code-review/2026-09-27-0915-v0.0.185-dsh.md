## 范围与结论

复核 Token 消费报表导出的迁入（`report.rs`）与区间用量合计（`tokens::range_totals`）。
结论：四处口径照搬、区间分档真的按 cutoff 生效；**M3 的 12 个模块已迁 11 个，只剩
`TaskDurationTracker`**，因此本轮不宣称 M3 完成。Swift 侧零改动。

## 可核验的行为证据

- **区间真的分档**：`the_range_cutoff_actually_separates_recent_from_old_detail`
  —— 同一份明细（1 小时前 + 14 天前各一条）在 24h / 7d 档得 4000、30 天档得 8000，
  且 30 天成本是 24h 的两倍（成本随区间缩放，不是照抄 24h 的数）。
  **反向验证**：`range_totals` 忽略传入区间（恒按 24h）→ 红（`left: 4000, right: 8000`）。
- **汇总行的零是空**：`the_grand_total_cost_line_is_empty_at_zero_because_it_uses_cost_not_cost_text`
  —— 断言 `- 累计历史总用量：0 ()`。**反向验证**：改用 `costText`（零写 `$0.00`）→ 红。
- **CSV 有 BOM 且列数固定**：`the_csv_has_a_bom_and_quotes_the_text_fields`。
  **反向验证**：去掉 BOM → 红（「Excel 需要 BOM，否则中文乱码」）。
- **费用格不写 `—`**：`the_fee_column_always_shows_money_never_a_dash`（未发现的来源也写 `$0.00`，
  由状态列说「未发现」；小于一分钱写 `<$0.01`）。
- **估价标记**：`the_estimate_marker_is_the_tilde_in_the_row_not_the_dead_marker_in_the_header`
  —— 行内 `~$0.02`；费率表里没有的 id 不估、不标；有记录值照实写。
- **周期与桶数**：`the_range_labels_and_buckets_match_the_reference`（文案、时长、24/28/30）。
- **排序**：`sources_are_sorted_by_usage_descending_and_ties_keep_input_order`（且稳定）。
- **测试数**：Rust **223 → 233**；编译警告 **22 → 21**；稳定性：连跑 3 次全绿。

## 本轮记住的两件事

1. **夹具陷阱**：第一版夹具把明细放在 8 个月前，区间查询全返回 0——不是被测代码错，
   而是 `parse_file` 用**真实时钟**算 70 天明细保留窗口，太老的明细已被折进累计。
   夹具改成「相对真实 now」并留时区余量。**夹具必须贴近现实的时间轴**，否则测的是另一件事。
2. **又一个死分支（第三个）**：汇总行「(参考估算)」在两边都不可能打印——那一行不带 modelId，
   而 `isEstimated` 只在那条路径上为真。真正可见的估价信号是行内的 `~`。
   照搬并用用例钉住实际行为（而不是发明一个更合理的语义）——
   这类「参考实现自己也走不到」的分支已经出现三次（另两次：月末预估的 `else`、
   `engine::compact` 的分歧实现），值得当成一类现象记着。

## 边界与后续风险

- **`Timeline` 不带 `points`**：图表数据由 `get_report` 的 `hourly30d` 单一来源提供。
  好处是不会有两份桶序列各说各话；代价是若将来报表要「每个桶一行」，得先决定谁是权威。
- **`build_timeline` 每次都全量扫 token 根**：导出是低频动作（用户点一次），可以接受；
  若做成定时导出要先看代价。它与 `get_report` 各扫一遍（没有共享缓存）。
- **`is_available` 的口径**：Rust 用「任一 `token_root` 目录存在」，参考实现用监控器的发现结果。
  两者在常见情况下一致，但**边界不同**（目录存在但空 ⇒ Rust 报已连接）。
- **剪贴板未迁**：`copyToPasteboard` 是 `NSPasteboard`，属 UI 层；Rust 侧返回正文由界面复制。
- **`token_report_*` 无 UI 消费方**：与其余几条命令同一状态。
- 同前几轮：同一人既改又审；真正的护栏是三处反向验证的红与上述判别性用例。
