# 多窗口布局几何审查

范围：NEW-04，C1 的平台无关计算接缝；不代表 C1/C2 完成。

## 实现与审查

`window_layout.rs` 的 DisplayArea、WindowCandidate 与 Geometry 使用逻辑点，已有工作区不重新猜测 Dock/菜单栏。三种模板保持显式选择顺序，不以标题当身份；主窗口固定首项。网格最后一行用满可用宽度，每个选择有且只有一个输出框。

拒绝非有限坐标/尺寸、非法 scale、空或重复临时身份、非法最小尺寸、负间距与超过上限的选择。模板窗口数不符直接返回说明，不静默截断。原生限制优先保留；只有实际需要移动/缩放时才检查相应能力，已处目标位置的固定窗口不制造错误。已核实的最小尺寸不足会标为不可应用，不猜各工具的最小尺寸。

首版一次 1–16 窗、间距 0–64 点，边界与工作区末端统一处理。没有持久化原生对象、移动窗口、调用批准或新增占位导航。本模块仍需接后端临时句柄管理，前端不能直接构造原生对象。

## 验证

6 项专项测试覆盖负坐标副屏与逻辑点/DPI分离、主辅窗剩余面积、1–16 个横竖屏网格不重叠不越界、不能调整/最小尺寸/原生限制、无效输入与错误模板数量、已处目标的固定窗口。全套 Rust 642 通过、0 失败、6 忽略，日志 `.scratch/window-layout-c1/full-tests.log`。
