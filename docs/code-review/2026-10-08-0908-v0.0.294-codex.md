Tao 创建 NSWindow 的 alloc/init 已返回 +1 所有权，随后 Retained::retain 又添加一次。setReleasedWhenClosed(false) 与 Rust drop 只平衡其中一份。改为 Retained::from_raw 接管已有所有权；异步 close 自身的临时 retain 沿用原实现，不在应用层手动 release，不修改全局 Cargo 缓存，不缩短生产回收延时或取消草稿保护。
