## 结果与保护

- 独立规则文件只保存模板、间距、工具偏好及主屏/重新选屏意图，名称和 UUID 属于规则；没有窗口标题、原生句柄、PID、系统窗口 ID 或旧矩形。
- 保存 ID 来自后台当前窗口快照，要求版本与时限匹配；不接受前端构造工具身份。列表、保存、删除、复用均检查规则聚合版本。原子替换前严格验证 schema/字段/数量/大小/名称/工具/模板，坏文件、未来版本、过大文件或 symlink 拒写并保留原文。
- 复用只在完整枚举且工具各有唯一可用窗口时自动填入。多窗、缺失、受限和读取不完整清空自动选择，副屏要求重新选屏。载入不调用原生写，不自动预览或批准操作。
- UI 保存失败保留名称与选择，切页不丢草稿。规则反馈与窗口状态分开，预览到期不会吞掉保存错误。坏规则文件不阻断独立窗口读取/排列，但拒绝继续写该文件。
