## 实现检查

索引以16MiB保守容量计费和8000文件数双约束回收，LRU记录实际读取及未变化命中，批量降到7/8低水位。计费覆盖路径/向量/字符串、唯一共享引用和带余量的表容量；游标可保守重计一个上下文。更新仅在文件实际重建/追加后计算，热命中不重新遍历字段；回收同时扣除账本并按需缩表。计费不是allocator实占或OS物理内存上界，临时读取/排序/计费集合、数据库和报告不在此预算内。

当前文件在累计、模型、小时和上下文消费完成前保留。单文件自身超预算时单列临时项，汇总后先释放它，保持既有合规温缓存；周期查询同样在消费后执行回收。不裁长行或丢数字，不改变时间窗口、去重和折入规则。文件超过缓存容量时重读可能更多，这是明确代价。

同文件模型名称以共享引用保留，跨增量追加通过名称表复用。可修订或已折入来源必重建，释放跨轮不再使用的名称表；已折入文件释放空去重表桶。汇总借用名称查表，仅新模型入表时分配键。输出仍是原响应模型字符串，Codex独立响应原本没有模型则保持unknown，不用请求上下文/当前配置回填。
