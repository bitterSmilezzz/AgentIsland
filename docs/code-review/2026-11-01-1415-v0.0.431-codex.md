## Standards

- 加密封套使用 `ring` AES-256-GCM，随机生成 nonce；AAD 以长度前缀绑定格式、project、run、artifact 和内容版本。密钥在 Rust 内存缓冲区以 `Zeroizing` 承载；认证失败、错密钥、错身份、未知格式和截断均不返回正文。
- 项目密钥使用单独的 `com.agentisland.managed-history.v1` 命名空间。macOS 创建走 `ItemAddOptions::add` / `SecItemAdd`，重复项目密钥返回冲突；代码没有调用 upsert。`core-foundation` 与 Security.framework 依赖保持 macOS target 门控。
- 当前模块未接入任务 JSON、现有明文 blob、Tauri 命令或受管理运行写入口。策略尚未量化的容量/期限没有擅自设值；其他平台没有密钥后端时拒写。
- 未发现本轮代码违反 ADR 0011 / 0029 / 0040 或仓库数据边界。
