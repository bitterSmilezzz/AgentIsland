# v0.0.437 自审：TASK-03 授权策略凭据锚

日期：2026-11-08。审查者：Codex（与实现同一上下文；不是独立复审）。审查范围为策略文件 v2、macOS Keychain 锚、原子恢复日志、跨进程文件锁、未锚策略重新确认、前端状态、原生 VM 探针和状态文档。

## 结论

没有发现能绕过项目显式授权、将旧 grant 恢复成有效授权或打开生产执行写入口的路径。策略读取和写入在 Windows/Linux 显式拒绝；macOS 策略与 Keychain 锚不一致、锚损坏/不可读、策略单独删除、pending 恢复缺少精确摘要证据时均 fail closed。无锚 v1/v2 文件只作为待重新确认数据；下一次明确确认会清空全部旧 grant、生成新 epoch，并只签发当前项目的新角色。策略写入由进程锁和 OS 文件锁串行，pending 日志匹配完整文件摘要后才可恢复。

这片没有启动 runner、实现 Run now、写入 TASK-05 历史或增加外部副作用授权。TASK-03 仍为 partial。策略锚不防系统 Keychain 历史快照回滚、同账户恶意进程直接篡改 Keychain，也不提供凭据丢失后的自动重签；这些边界与 ADR 0044 一致。
