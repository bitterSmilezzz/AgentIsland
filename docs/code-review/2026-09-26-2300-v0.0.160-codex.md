## 边界与后续风险

并发写入仲裁、目录落盘同步或正在运行的 Codex 进程热更新承诺。Phase 2 接入实际
档位时仍需决定配置目录的来源，并按 ADR 0009 在钥匙串边界处理真实凭据。
