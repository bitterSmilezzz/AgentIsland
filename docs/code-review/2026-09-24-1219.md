### P2 — 建议

- **`Tests/AgentIslandTestsRunner/DebtPayoffTests.swift:368`** — `tableIDs` 仍**硬编码 `cells[1]`**，而同一段代码在 `:341` 专门建了「列名 → 索引」映射 `idx(_:)`，并在 `:348-365` 的逐行校验里用 `idx("编号")`。
  - 为什么是问题：本轮 CHANGELOG 把「列索引从**表头**推，不硬编码 `cells[3]`/`cells[4]`：插一列会让硬索引静默改指别的列」列为已修项之一，外部 review 的 P2-1 也记为「**已修**」。但 `tableIDs` 这一处没跟着改——在编号列前插入一列（例如 `| 序 | 编号 | … |`）时，`idx("编号")` 会正确指向 2、逐行校验照常通过，而 `tableIDs` 会去读第 1 格的「序」列内容、`boldID` 返回 `nil`、`tableIDs` 变空集，于是 `noRow = bodyIDs` 全量非空 → 测试**会红**。
  - 定级说明：**后果是响亮的、不是静默的**（这是它没被定成 P1 的原因），但报出的消息会是「正文引用了清单里没有的编号：全部」——把「列位置变了」误诊成「编号没成对」，排查方向被带偏。所以问题不在会不会发现，而在**声明与实现不一致 + 诊断信息误导**。
  - 建议：改成 `let tableIDs = Set(dataRows.compactMap { boldID($0.cells[idx("编号")]) })`。注意 `idx` 定义在 `if let h = headerAt { … }` 块内（`:341`），需把它提到块外（或在块内就地把 `tableIDs` 算好再带出来），改动约 3 行。

- **`Tests/AgentIslandTestsRunner/DebtPayoffTests.swift:395-400`（同义说法禁令的作用域）** — 禁令以**行**为单位（`if line.contains("**V")`），而该文档的段落是**跨行**书写的。
  - 为什么是问题：CHANGELOG 自己把这条修的教训写成「**改写不等于拆掉**——把同一个判断换个词再说一遍，第二个出口还在」，方向是对的；但实现用的是「同一行内既出现 `**V` 又出现同义说法」才算违规。文档的清单小节恰恰演示了段落跨行——`:270` 是含 `⇒ **V#**` 的那一行，`:271` / `:272` 是同一个段落的续行（`上一版删掉了 6 处括号里的状态词，却把同一个判断留在括号外（「本轮没逐字复核」「未找到正文依据」）…`）。**这两行正落在同义说法名单上，却因为不含 `**V` 而不被检查**（本轮实测：该段落未被判违规，测试绿）。
    也就是说：把状态判断写在编号引用的**下一行**即可绕过。当前文档里那两行是解释规则的元叙述、不该被判违规，所以现状是**对的**；但同一个格式位置也能承载真正的第二出口——判据与被守约定的对齐程度，取决于「编号引用与状态判断必须同行」这个未被写下来的前提。
  - 建议：把扫描单位从「行」改成「段」（按空行切分，或把 `**V#**` 所在的段与其续行合并后再匹配同义说法）。这样既保住「元叙述段落不误伤」，又堵住「续行藏状态」；改动集中在 `:372-375` 的 `nonTable` 构造与 `:390` 的遍历，约 10 行。若倾向不加复杂度，则退一步：在文档里显式写明「状态判断必须与 `⇒ **V#**` 同行」，把前提从隐含变成约定。
