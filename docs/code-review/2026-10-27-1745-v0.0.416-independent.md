# v0.0.416 团队资源配置独立审查

## 范围与结论

独立审查覆盖资源声明的持久化、Tauri 命令、隔离实例与任务页交互。此批只保存用户声明，不启动工人、不验证真实能力、不授予记忆访问权限；不能以此作为执行授权。真实执行器仍需可信能力来源、独立授权、运行身份与槽位租约。

## 发现与修正

1. **隔离实例指向真实配置**：初版与正式实例共用配置路径，两个进程的锁也不能互相保护。现由同一隔离启动判定选择只读空快照、拒绝写入；五种隔离模式均有单元断言。此证据不替代正式包原生验收。
2. **后台刷新丢失键盘焦点**：配置行重建曾将编辑/删除焦点丢到页面主体；保存或取消时隐藏表单也会丢失焦点。现按操作和配置身份恢复，用户已转移焦点或离页时不夺回；受控浏览器覆盖上述路径。
3. **矩阵生成器重复追加空行**：实际调用生成器两次会改变文件尾部。先用临时仓测试复现，再修正替换边界；连续生成字节一致并保留手写尾部。

## 证据与边界

- 资源存储定向测试覆盖读写重载、版本冲突、同进程并发、损坏/未来格式、容量、软链、声明不相容及隔离模式；同进程锁不声称是跨进程比较并交换。
- 浏览器测试通过受控 IPC 验证界面增删改、失败禁写、冲突草稿、迟到读取、焦点和文本转义；不代表真实客户端执行能力。
- 修改前基线 Rust 测试 1358 通过、15 忽略；本机 Windows 全 crate 交叉检查因已登记 BUG-011 失败，Windows 片段与统一 CI 门禁通过。原生与长时验收以本轮实际执行结果为准。
