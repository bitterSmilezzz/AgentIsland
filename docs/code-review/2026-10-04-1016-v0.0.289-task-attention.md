# 轻量任务摘要与定向导航审查

范围：NEW-01、NEW-02、UX-02，实施批次 B3。此报告记录本轮时间点，不改写来源绑定报告。

## 行为与修正

- 岛、侧栏、工作台首页共用当前任务投影：只计未归档任务当前运行的开放关口或失败，每任务计一次；优先展示待回答、计划批准、结果验收、确认，再展示失败。历史或过期事项不进入摘要。
- 摘要只有任务详情与来源跳转，所有批准仍在原工具执行。本地记录与可信观测有独立标识，旧记录默认不拥有可信观测身份；只有精确会话匹配且来自观测的事项才合并原提醒和借用临时提问文案，资源提醒独立显示。
- 点击携带任务、运行和全局版本，前端与后端均复核；旧 DOM 不跳往新首项。单窗口导航可排队到懒创建的工作台，已有窗口选中任务；编辑中保留草稿，隐藏窗口停止读摘要与任务快照。
- 同内容摘要不替换 DOM，避免采样打断焦点或吞掉失败反馈。成功来源跳转不增加一行布局；失败保留可见说明。
- 用户变更广播和引擎同步广播均在任务写锁释放后执行，避免 UI 读取与发布持锁相互等待。
