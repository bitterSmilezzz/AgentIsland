# v0.0.435 自审：TASK-03 项目授权策略存储

日期：2026-11-07。审查者：Codex（与实现同一上下文；不是独立复审）。

## 范围

- `managed_run_authorization_store.rs` 的策略解析、默认关闭、授权版本、文件发布、项目根身份复核与拒绝路径。
- `windows-sys` 文件系统 API feature、模块注册、需求状态/测试矩阵同步及实施文档边界。

## 结论

本片没有发现会开放未授权生产执行的路径：策略模块尚未接 Tauri 命令或执行器；新文件缺失表示无 grant/无历史，坏格式、未来格式、路径身份变化及文件发布失败均拒绝。主机范围外的绝对项目路径只保存在本机策略文件，不进入远程账本。

目录身份捕获通过打开的目录句柄读取身份，再与规范化路径及二次打开结果比对。Unix 使用 device/inode；Windows 使用卷序列号和 128-bit file ID。策略快照的 grant version 与 history-policy version 独立递增，过期全局 revision 与版本溢出拒绝写入。

## 后续边界

- `confirm_project` 目前只是存储层 grant 签发 API；用户确认 UI/Tauri 命令尚未接入。
- 尚无策略文件抗回滚或备份恢复机制；不能把策略文件恢复视为安全。
- 写锁现为进程级，可串行化同一进程内多个 Store handle 的写入；17 条测试包含相同 revision 下并发提交只允许一个成功。跨进程仍依赖应用单实例约束；若未来允许多个进程写同一策略文件，需先加入文件锁或等价的跨进程序列化。
- runner 握手、撤销停止、真实 Run now、TASK-05 密文事件生命周期与钥匙串原生验收均未完成；生产执行和自有历史写入仍关闭。
