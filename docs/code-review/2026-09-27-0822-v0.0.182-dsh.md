# v0.0.182 独立复核 · DSH · 2026-09-27 08:22

## 范围与结论

复核「导出与自检」组第一件：审计报告导出（Markdown/CSV）+ 给事件补 `duration`。
结论：三条口径各有判别性用例，一处**静默降级**被修掉。Swift 侧零改动。

## 可核验的行为证据

- **表格单元不能注入行/小节**：`a_table_cell_cannot_inject_rows_or_sections`
  —— 攻击串同时含 `\n`、`\r`、`|`；断言 (a) 报告**行数不变**（与正常名字生成的报告逐行比），
  (b) 每个表格行的**未转义**竖线数与该节列数一致，(c) 反斜杠不被转义。
  **反向验证**：把 `cell()` 改成原样返回 → 红。
- **`—` ≠ `0`**：`a_missing_usage_reads_as_not_measured_instead_of_zero`
  —— Markdown 印整行 `—`、CSV 印**空列**；**反向验证**：把没取到当 0 → 红。
- **跨源口径差额要写出来**：`the_cross_source_total_and_the_listed_sum_are_both_stated_when_they_differ`
  —— 头条用面板口径 9.60M、正文写明逐条相加 1.20M 与差额来源；两边一致时不许多嘴。
  **反向验证**：去掉该分支 → 红。
- **时长有真值、不适用印 `—`**：`the_report_carries_the_real_duration_and_marks_not_applicable_with_a_dash`
  —— `3分12秒`；`0` 印 `—` 且报告里不出现「0秒」；完成摘要带时长（Swift `summaryText` 同口径）。
- **会话源不可读单独列出**：`blind_session_sources_are_called_out_because_idle_can_mean_no_signal`。
- **CSV 转义**：`csv_escapes_quotes_and_commas_so_one_agent_cannot_shift_columns`（含列数一致）。
- **文件名与正文同拍**：`an_export_carries_a_filename_from_the_same_instant_as_its_content`。
- **两种写法不许分叉**：`the_observability_code_in_csv_matches_the_json_spelling`
  —— CSV 里的 `blindSessionSource` 必须与 serde/JSON 的拼写逐字相同。
- **测试数**：Rust **201 → 211**；**编译警告 25 → 23**（`AgentTaskEvent::summary` 等两处
  死代码被导出的消费方吃掉）。稳定性：连跑 3 次全绿。

## 本轮修掉的静默降级

`AgentTaskEvent` 在 Rust 侧没有 `duration`（Swift 有）。后果有两处，都不报错：
① 完成摘要少一段（Swift 写「X 任务完成 (3分12秒)」，Rust 只写「X 任务完成」）；
② 审计报告第 3 节的「耗时」列只能永远印 `—`——而**「没记」与「零秒」是两件事**，
一份运维报告里后者会被读成「这个任务瞬间完成」。
已补字段（0 = 不适用）+ 真实时长（与 `notify_outbound` 取同一个起点，两处各算一次必然打架）。
`duration_text`（`3分12秒`）与通知正文的 `duration_short`（`3分`）是**两道不同粒度的口径**，
不是重复实现——报告要精确到秒，通知只要说个大概。

## 边界与后续风险

- **Raycast 清单未迁，且原因是硬阻塞**：它要把版本号写进 JSON，而 Rust 的 `Cargo.toml`
  是 `0.1.0`、与 App 版本（`0.0.182`）**并未同步**。直接用会把错号发给用户；
  要迁先得定「第四个版本位」的规则（并让 `release.sh` 与 `build-app.sh` 都检查它）。
  **这条本身是个发现**：Rust 侧今天没有任何地方读 Cargo 版本，所以漂移一直没暴露。
- **Swift 状态列的 `AgentProvenance` 后缀没有对应物**：Rust 没有 provenance 概念，
  所以报告里那份「工作中」可能来自带令牌的自报，而报告读者分辨不出（Swift 专门为此加了后缀）。
  这是本轮**唯一明知而留的 parity 缺口**，写在矩阵表里。
- **`audit_report_*` 无 UI 消费方**：与 `remote_status` / `token_forecast` 同一状态——
  命令齐了，界面还没做（Phase 1/2）。「导出到剪贴板」这条路径今天只有 API。
- **会话源不可读那一节用的是 `observability` 判定而不是 Swift 的 `sessionProbeHealth`**：
  信息等价（`BlindSessionSource` + evidence），但**文案来源不同**，逐字比对会不一样。
- 同前几轮：同一人既改又审；真正的护栏是三处反向验证的红与上述判别性用例。
