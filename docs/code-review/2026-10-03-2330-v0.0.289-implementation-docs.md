- 旧Target使用camelCase：新DTO与transport规范明确保留旧序列化兼容。
- Attention需要稳定ID：补充id以及聚合文件attentions集合，匹配拟定命令。
- 来源跳转、标记本地已处理与工具批准分别定义；首版不远程审批或执行。
- 窗口撤销复核身份和后续手动移动，部分失败真实报告；平台API候选仍需探针验证。
