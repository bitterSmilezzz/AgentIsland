# v0.0.284 身份与列表复核

审查者：Codex。范围：ChatGPT / Codex 重复身份和 Ego Lite 浏览器分类。

## 一手依据

本机只读取应用 Info.plist 的公开身份字段：ChatGPT 的 CFBundleIdentifier 为 `com.openai.codex`，可执行名称为 `ChatGPT`；ego lite 的包标识为 `com.citrolabs.ego.lite`，可执行名称为 `ego lite`。`ego-browser --help` 提供浏览器导入、升级和嵌入 Node 脚本控制接口；技能文档描述其为供人与 AI Agent 使用的 Chromium 浏览器。未读取浏览器用户数据或启动浏览器。

- [OpenAI 官方说明](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)：ChatGPT 桌面应用内提供 Work 与 Codex。
- [Ego 官方产品说明](https://www.egolite.app/document/en/docs/product-introduce)：区分 ego lite 浏览器和 ego 个人 Agent，外部 Agent 通过技能控制 lite。

## 实现与兼容

后端合并身份而非仅隐藏 UI 行：稳定 ID 保留 codex，桌面/CLI 进程共同归属同一档案，保留唯一 Codex 会话与 token 根、桌面包直达。没有从应用配置目录推断 Work 明细。移除内置 Ego Lite 档案；自定义 Agent 不受移除影响。

旧 chatgpt 禁用选择迁移到 codex 后去重，原任一禁用项使统一身份保持禁用；去掉已退休 Ego 的禁用孤立项。此迁移可由用户在管理页重新启用，不改浏览器安装与运行状态。演示身份同步。

## 验证

Rust 全量 577 通过、0 失败、5 忽略。唯一归属测试覆盖 ChatGPT、旧 Codex 桌面、Windows CLI、Node CLI，断言只有一个所有者和一个用量根。设置迁移测试覆盖重复 ID、退休 ID、自定义 ID 与幂等性。共享身份测试验证当前 24 个内置档案及五处视图，功能 UI 与 diff 检查通过。

构建、原生三窗口、Dock 显隐、单实例与全部 Git 对象脱敏由 release.sh 在提交前执行，失败即中止。发布前复核不预先宣称这些门禁通过。
