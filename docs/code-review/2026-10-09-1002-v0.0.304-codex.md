# v0.0.304 发布前审查

审查对象：基于 v0.0.303 的快捷导航确认保护、配置/提示词反向 Tab 入口及相关验收和历史归属文档。审查者 Codex；时间 2026-10-09 10:02。此报告记录发布前状态，不追写后续提交与发布结果。

## 问题与实现

旧实现从顶栏进入待确认区时聚焦首个写入按钮，并漏掉 Claude 方案采集预览。受控生产 DOM 中，紧接回车会误写一次；新增焦点策略回归对旧实现失败。配置和提示词的反向 Tab 也将容器入口误算为已在控件内，分别复现一次误写。

快捷导航现在保留预览内的既有焦点，从区外返回则聚焦容器。Claude 预览加入既有门禁；隐藏/折叠预览不挡正常导航。纯函数区分容器入口与控件循环，正向进入首项、反向进入末尾取消；配置和提示词控制器共用该顺序。没有新增 IPC、权限、键盘监听或轮询，未放宽写入确认及原生身份核验。
