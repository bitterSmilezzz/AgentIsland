# v0.0.289 · 实际 Claude 客户端格式取证

审查者：Codex。2026-10-06 19:07（Asia/Shanghai）。

## 实施

增加可重复的 macOS 独立客户端测试脚本，固定官方 npm 平台包版本2.1.291，运行前验证签名及版本。包安装与原始输入/输出均在忽略目录，不全局安装；进程环境采用白名单，独立 CLAUDE_CONFIG_DIR，restricted 模式，禁用非必要流量与更新。模型只指向本机模拟端点。测试宿主只拒绝权限请求，观察 hook 本身不输出决定、不代答或批准。此配置不声称 OS 级网络隔离。

真实客户端实际注入 plan 和 planFilePath，session_id 与唯一主 assistant 消息的规范 UUID 对应。该版本同时把注入正文保存到 transcript，故只读来源模块优先读取它，临时采集覆盖层应拒绝接管已有明确正文。新增两项显式回归分别验证真实 hook 与主消息对应、采集协议接收、覆盖层不接管，以及精确 transcript 读取、普通来源无临时期、拒绝后不再投影确认方案。

首次测试把已有明确正文误当缺正文采集目标，断言失败；核对实际输入与既有守卫后，修正测试期望，保留正确的产品边界。没有为了让测试通过而放宽覆盖层的来源规则。

## 验证

- 运行官方签名客户端，版本输出2.1.291，退出0；hook实际触发；权限请求实际到达宿主并被拒绝。
- 两项 real_client_ 显式回归通过；默认全量861通过、11忽略。两项客户端测试依赖独立安装与模拟服务，故不伪装为默认回归自动通过。
- 脚本在修正路径引用后重新运行成功；Python编译、工作区脱敏扫描、git diff --check通过。
- 官方一手契约见 https://code.claude.com/docs/en/setup 、https://code.claude.com/docs/en/hooks 、https://code.claude.com/docs/en/env-vars 。受控 API 响应不是实际 Anthropic 服务证明。

实际日常账号/会话取样、正式应用接收与客户端连续操作、隔离原生几何和动效验收仍未完成。观察 hook 是独立取证命令，不能冒充正式 AgentIsland 收集入口的端到端通过；该入口已有独立内核与运行生命周期回归，后续仍需完整组合。整版交付保持未完成。
