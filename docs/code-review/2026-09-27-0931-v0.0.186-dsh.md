# v0.0.186 独立复核 · DSH · 2026-09-27 09:31

## 范围与结论

复核 `TaskDurationTracker` 的迁入（`duration.rs` + 引擎接线 + 快照字段 + 自检两条），
并核对 **M3 的 12 个模块是否全部到位**。结论：12/12 到位、各自有测试；
一处被漏掉的门槛（≥3.5 秒才算一次任务）已对齐。Swift 侧零改动。

## 可核验的行为证据

- **门槛判别**：`a_flash_of_work_shorter_than_the_threshold_is_not_a_task`
  —— 2 秒的抖动既不推事件也不进统计；随后 5 秒的那次照常记。
  **反向验证**：去掉门槛 → 红（「2 秒的抖动不该算一次任务」）。
- **条数上限**：`only_the_newest_hundred_records_per_agent_survive`
  —— 150 条 → 留 100，且丢的是**最早**的（最长的那条仍在）。
  **反向验证**：去掉上限 → 红（`left: 150, right: 100`）。
- **窗口边界**：`the_window_filter_is_inclusive_and_uses_the_callers_clock`（含边界）；
  另有一条「时间戳在未来的记录仍算窗口内」——时钟回拨不该让刚记的那次凭空消失。
- **排版文案**：`the_total_text_switches_units_at_the_right_boundaries`（`2分钟` 不写 `2分0秒`）、
  `the_average_text_keeps_the_per_task_suffix`。
  **反向验证**：平均时长为零写成 `0秒/次` → 红（`left: "0秒/次", right: "—"`）。
- **旧用例的拆分**：`repeated_semantic_fingerprints_do_not_repeat_notifications` 的流程是
  「attention → completed」，从未经过工作态 ⇒ `work_started_at` 为 0 ⇒ 按新门槛不该推事件。
  已拆成「attention 去重」与「completed 去重（含真实 4 秒工作）」两条。
  **这不是为了让用例变绿**：原用例把「完成」与「工作过」这两件事混在一起了，
  拆开后两条各自表达一件事，并且门槛本身另有一条判别用例。
- **自检实物**：`agentisland --selftest` → **24 项全绿、退出码 0**（含新增的任务效能两条）。
- **测试数**：Rust **233 → 243**；编译警告保持 **21**；稳定性：连跑 3 次全绿。

## 「M3 完成」意味着什么、不意味着什么

- **意味着**：12 个模块在 Rust 侧存在、各有测试、口径逐条对齐（差异都在矩阵里标了理由）。
- **不意味着**：UI 已完成。设置页、侧边栏，以及 `remote_status` / `remote_preview` /
  `token_forecast` / `audit_report_*` / `token_report_*` / `agent_process_tree` /
  `run_selftest` / `remote_secret_*` 这些命令**都没有界面消费方**。
  也就是说「能力已就位」而「用户还摸不到」。
- **也不意味着 Swift 测试可以退役**：Swift 本体今天仍是实际交付的产品。
  ADR 0010 里那条「M3 完成后 Swift 侧转归档、测试退役」要等 Phase 1–4 落地后再做，
  并且那一次必须写进 CHANGELOG 而不是静默删除——已把这条判断写进 CHANGELOG 与 ADR。

## 边界与后续风险

- **未搬 `prune`**（参考实现里的死 API，且被条数上限覆盖）。若将来要按时间而非条数收敛内存，
  得先把「谁调用它」想清楚再搬。
- **不加锁**：追踪器由引擎持有，引擎本身在 `Mutex` 后面。若日后有别的线程要直接读它
  （例如导出命令），要么走引擎，要么先给它加锁——**别绕过引擎**（类型注释里写了）。
- **`workStats` 进快照的代价**：每个 Agent 每拍都重算一次窗口统计（≤100 条记录，代价可忽略），
  换来界面不必按需查询。若将来记录上限调大，这里要重新看。
- **门槛改了事件流**：短于 3.5 秒的完成不再产生事件，因此也不再走外发闸门。
  这是**对齐参考实现**的行为变化，但用户的岛在今天（Swift 侧）就是这个行为——
  Rust 侧此前会多报，现在不会了。
- 同前几轮：同一人既改又审；真正的护栏是三处反向验证的红与上述判别性用例。
