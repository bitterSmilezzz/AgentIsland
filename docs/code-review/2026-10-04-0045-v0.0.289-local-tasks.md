## 实现与边界

- 独立 `tasks.v1.json`，单进程互斥写入，聚合 revision 复核后原子替换；未知格式、坏关联、损坏、超量或写失败保留原记录。旧 `todos.rs` 及 Todo 文件未改逻辑。
- 项目与任务、四组列表、编辑、归档恢复、运行记录及简短产出引用；人工关口分别显示待回答、确认方案、验收结果。结果就绪不等于来源验收，本地处理不会发批准，也不会推断工具继续运行。
- 存储层来源采用工具命名空间和会话指纹。未绑定来源不会自动制造任务，重复事件不增加运行；来源绑定和采样尚未接真实引擎，用户命令未暴露任意 URI。
- 保存期间防止输入继续改动；写冲突保留输入。缓存页在隐藏期间仍接收属于自己请求的保存回执，避免返回后重复提交已保存内容；过期请求无权覆写新页面。
- 详情修改阻止破坏性重画，不影响整页 DOM 缓存；未保存其他详情表单时拒绝破坏该草稿的操作。
