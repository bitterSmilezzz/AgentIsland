# v0.0.305 发布前审查

审查对象：基于 v0.0.304 的窗口历史浮点读回、工作台结果焦点与显露修复。审查者 Codex；时间 2026-10-09 16:00。此报告记录发布前证据，不追写后续发布结果。

## 问题与实现

真实三窗口网格排列完成后，原实现将历史保留 pending，并显示意图记录变化的警告。实际文件接缝的最小回归在旧实现失败；位级探针确认 JSON 读回坐标的一位差异。启用 serde_json `float_roundtrip` 后，相同输入和回归通过；锁定的依赖版本及依赖集合不变。文件 revision、记录内容严格比较和原生1点读回容差均未放宽，有效0.125点外部编辑仍拒绝结算并保留原文件。

原生 WebKit 鼠标激活可能将焦点留在工作台正文容器；旧结果回焦只接受 body 或页面内元素，遗漏这一归属，导致撤销入口藏在下方。共享策略仅接纳当前已连接页面自己的正文容器；顶栏、其他页面和已分离缓存页仍保留用户焦点。结果短于视口时显露整个结果区，较长时显露标题；普通模式平滑滚动，减少动态时直接定位。没有新增 IPC、权限、订阅、写入或轮询。
