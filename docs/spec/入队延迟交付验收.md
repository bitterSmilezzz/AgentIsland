# 结构化 hook 入队延迟：交付与验收

本次交付对应 [需求基线](需求.md)的即时通知指标：结构化 hook 进入本地 HTTP 服务到通知入队 p95 ≤1000ms。NOT-01 的其他通知能力保持部分覆盖，桌面提醒和手机最终送达不在本指标内。

## 产品行为与测量口径

- 计时起点：本地 `tiny_http` 补丁在接受新连接时记录首请求时刻，后续请求在解析前记录；包括解析、正文读取、HTTP库内部排队、应用处理及引擎等待。TCP握手和内核accept之前的等待不在应用服务计时内；长连接首请求前的闲置可能计入首样本，属于保守高估。补丁不改HTTP解析规则。
- 计时终点：常驻引擎接收 hook 事件并加入通知队列；调用来源隔离，深链与内部事件不参与该统计。
- 最近 1000 条非负毫秒样本，nearest-rank p95；至少 20 条且累计无负样本丢弃才给达标结论。负样本使结论未知，超过 60 秒的有效慢样本仍保留。
- 延迟使用单调时钟，通过仅HTTP通道使用的 `HookEvent` 传递，墙钟事件时间只供展示，系统校时不影响耗时。样本只在进程内保留，重启后重新积累；初始 ≤1000ms 目标仍需正常负载下持续实测，不承诺所有请求都小于该值。
- 常驻进程 `get_engine_state` 的 `notify_latency` 提供摘要。CLI 的独立引擎不会读取 GUI 进程的累计统计。

## 验收要求

1. 真 TCP/HTTP 请求通过产品接受循环和生产等待/消费路径自动入队；长周期等待不能使 hook 必须等满一拍。
2. 至少 20 条请求；从 EngineState 读取样本数、p95、可判定状态与目标结论。
3. 突发请求的唤醒合并有界，不阻塞 HTTP；等待与 UI/托盘派发在引擎锁外。
4. 负例验证：取消唤醒后长等待验收必须失败；拒绝请求不产生事件或唤醒；深链不混入样本。
5. 临时端口、无真实凭据、无真实系统通知，测试线程可停止并回收。
6. 通知页读取当前常驻统计；未知、样本不足、测量不完整、达标和未达标显示准确，刷新不发送通知。
7. 构建正式本地产物并验证源码绑定收据，记录当前运行证据。
8. 计时须包含HTTP库内部排队，前序慢请求不能使后续等待超过1秒的请求被计为近零；半包保持连接时停止服务须有界退出。

## 实测证据（2026-10-16）

真实本机 TCP：每条流发一条请求，服务接受循环读取 prompt 正文，经由生产 `HookScheduler::wait_and_consume` 自动消费后入队，直接读 `EngineState.notify_latency`。

| 场景 | 样本 | p95 | 判定 |
| --- | ---: | ---: | --- |
| 20 条 5 秒长等待内**开启合并唤醒** | 20 | 2ms | ≤1000ms，达标 |
| 同一 consumer 与请求代码**切断唤醒** | 20 | 5009ms | 等待满一拍，未达标 |

服务内排队与读取（原复审 P2）修复后另有三类真实慢请求，全部正确计入并判未达标：

| 场景 | 样本 | p95 |
| --- | ---: | ---: |
| HTTP 内部 messages 队列拥塞（大正文占住 consumer，20 条已排队 1.25s） | 21 | 1264ms |
| 慢请求头（`POST` 行后停 1.25s） | 20 | 1264ms |
| 慢小正文预读（首字节后停 1.25s） | 20 | 1265ms |

半包保持连接下停止服务：Drop 在 **约 0.5ms** 内完成，不再阻塞等待客户端。

## 仍未验 / 局限

- **未在真实 GUI 常驻进程压测对外 p95**。测试内的真实 HTTP 与生产调度单元给出了上表数字，常驻进程也被证实能收 hook（20/20），但运行中 WebView 的统计无法从外部读取，**故不声称「常驻进程实测 p95 = N ms」**；真实值请在通知页「刷新入队统计」查看，或另作长时压测。全量采样 tick 正在执行、锁竞争或高负载下的表现仍未取证。
- 指标只覆盖即时性三条要求中的**一条**（hook → 入队）。来源事件→桌面提醒、外发入队→首次发出两段未实现测量。
- 长连接首请求前的闲置会计入首样本（保守高估）；读超时只在请求在途时生效，空闲 keep-alive 连接**不会**被 408 断开（无超时的空闲连接由服务 Drop 时的 socket 取消负责，退出有界）。
- `vendor/tiny_http` 是对上游 0.12.0 的最小本地补丁，须随代码入库，否则他人克隆后构建失败。
- NOT-01 的入队幂等、重启恢复与批量并发仍未覆盖；本轮未提交、未推送、未发版。

真实常驻进程核验（发布产物运行中）：

```sh
python3.14 - <<'PY'
import socket
body = b'{"agent":"latency-probe","event":"completed"}'
for i in range(20):
    s = socket.create_connection(("127.0.0.1", 42000), timeout=3)
    s.sendall((f"POST /notify HTTP/1.1\r\nHost: 127.0.0.1:42000\r\n"
               f"Content-Type: application/json\r\nContent-Length: {len(body)}\r\n"
               f"Connection: close\r\n\r\n").encode() + body)
    print(s.recv(64).decode(errors="replace").split("\r\n")[0]); s.close()
PY
```

通知页查看“本地事件入队延迟”，点击“刷新入队统计”只读取常驻状态。统计达到 20 条之前保持未判定；不要把命令行新引擎的零样本当作常驻进程结果。
