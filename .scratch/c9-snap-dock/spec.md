# Spec: C9 — 自由拖拽、顶部/右侧智能贴边与微细条悬浮弹出

> 产出：用户反馈「我想要的是可以移动，移动到侧边它自动就贴到侧边栏，移动到顶部它自动贴到顶部这个栏。不论是侧边还是顶部都留一个非常细小的条，能看到这有个东西，然后光标碰到上面之后它自动弹出来。」2026-09-07。

## Problem Statement

此前 C7 移除了顶部与拖动逻辑，只支持固定右侧完全隐藏式侧边栏（零残条）。用户希望：
1. 能够自由拖动面板；
2. 拖到屏幕顶部自动吸附贴到顶部，拖到侧边自动吸附贴到侧边栏；
3. 收起时无论在顶部还是侧边，都留有一个 5~6pt 的非常细小的微胶囊条（Sliver），清晰可见；
4. 光标移动触碰微细条时自动弹开展开，移开后自动收回。

## Solution

1. **贴边模式与状态持久化**：
   - `DockEdge`: `.top` / `.right`（默认 `.right`，记录于 `UserDefaults`）。
   - 记录用户拖动时的停靠坐标（顶部记录 X，右侧记录 Y）。
2. **自由拖动与智能吸附手感**：
   - 展开状态下，长按顶栏（或卡片）可拖动窗口。
   - 拖拽结束时（`dragEnded`）：比较窗口中心距屏幕可见顶部与右侧边缘的相对距离，最近者为吸附目标边缘，以物理弹簧曲线自动平滑归位贴边。
3. **微细条（Docked Sliver）视觉**：
   - `dockEdge == .top`：屏幕顶缘露出 6pt 悬浮微胶囊条（宽 140pt），带晶莹微反光与工作呼吸绿点。
   - `dockEdge == .right`：屏幕右缘露出 6pt 垂直微胶囊条（高 120pt），贴边平滑。
4. **光标触碰自动弹出**：
   - 触碰微细条区域或靠近边缘时立即触发 `.expanded`（顶部向下展开，右侧向左滑出）。
   - 移出后根据 `collapseDelay` 平滑收回到微细条。
