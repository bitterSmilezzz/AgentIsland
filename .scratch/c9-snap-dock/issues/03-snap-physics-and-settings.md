# 03 — 智能吸附计算、物理弹簧位移与设置联动

**What to build:**
- `dragEnded` 智能吸附判定：
  - 比较窗口中心到当前屏幕 `visibleFrame.maxX`（右缘）和 `visibleFrame.maxY`（顶缘）的物理距离。
  - 若 `distanceToRight < distanceToTop`，吸附到右侧（`dockEdge = .right`），计算并钳制 Y 坐标；
  - 否则吸附到顶部（`dockEdge = .top`），计算并钳制 X 坐标。
  - 使用 Apple 阻尼弹簧平滑滑动到位。
- 展开/收起方向适配：
  - 顶部展开：向下拉出；收起：向上收缩回顶缘微细条。
  - 右侧展开：向左滑出；收起：向右收缩回右缘微细条。
- 卡片圆角自适应：
  - 顶部贴边时：下方两角圆角；
  - 右侧贴边时：左方两角圆角。
- 设置窗口与菜单栏联动：
  - 设置界面「通用与外观」提供贴边位置选择器（顶部 / 右侧）与「重置位置」按钮。
  - 菜单栏 Popover 保持一致。
