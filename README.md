# AgentIsland

本机 AI 编码智能体的轻量工作台，监控运行状态、当前动作与 token 用量。

**main 使用 Rust/Tauri 开发。** Rust 负责监控、会话解析、配置与 CLI；静态 Web UI 提供灵动岛、贴边侧栏及工作台，macOS 使用系统窗口控制和材质。SwiftUI 与旧 WPF 实现保存在 [归档分支](https://github.com/bitterSmilezzz/AgentIsland/tree/codex/archive-swiftui)，归档规则见 [ADR 0016](docs/adr/0016-rust-only-main.md)。

> 本文档描述 **v0.0.306** 的行为；版本改动见 [CHANGELOG.md](CHANGELOG.md)。

## 功能

- **灵动岛**：小型贴边把手、实时智能体列表、当前动作、用量摘要；支持搜索、详情与用量分析，离开后自动收起。
- **侧边栏**：持续显示监控、用量、档位、待办、设置、远程通知和智能体管理；左右贴边与宽度可配置。
- **工作台**：概览显示实时监控、待办与常用入口，分组导航进入独立功能页，任务入口内切换任务看板与待办事项；切页保持导航与顶栏，采样不会重置正在输入的内容，当前窗口内切页与隐藏唤回保留编辑内容。
- **监控**：ChatGPT 桌面端与 Codex CLI 合并为一条“ChatGPT / Codex”，共用 Codex 会话及用量来源；Ego Lite 等供 Agent 使用的浏览器不列为内置 Agent。进程、文件与会话证据共同判定运行状态；会话源读不到、无本地明细和未接入明细源分别呈现，详情与 doctor 共用诊断口径。
- **桌面身份**：Trae CN 与 TraeWork 分别识别，TraeWork 兼容 TRAE SOLO CN 应用包；豆包工作独立识别 macOS 主进程。豆包工作与 TraeWork 提供进程和 CPU 活动，会话事件与 Token 明细尚无已验证本地来源。
- **用量**：读取本机 JSONL / SQLite 等记录，统计最近 24 小时与累计净消耗；缓存读取不重复计入，缓存创建按来源计入新鲜用量；费用估算用 `~` 标记。
- **本地预算**：用量分析可按工具设置滚动24小时 Token 上限，80%预警、100%超额，未知来源与实际零用量分别显示；逐项保存防止其他窗口覆盖，切页保留草稿。预算仅作本机提醒，不限制请求，也不代表服务商配额或接口账单。
- **会话入口**：待确认、已完成和运行异常分别给出具体动作。macOS Codex 可进入所观测状态的对应会话；其他已接入桌面工具的入口标为“打开工具”。提醒保留触发时目标，打开来源不会代替批准操作。
- **会话来源**：工作台集中当前语义来源与任务保存的历史，可按工具、当前观测、任务历史、本机目录及会话编号/任务名称筛选；来源变化会拒绝旧操作，历史使用对应运行保存的来源。精确会话与打开工具分别标注；来源与运行记录逐批查看，搜索覆盖已读取数据，记录可进入对应任务。可手动读取 Codex 默认普通/归档目录及 Claude Code 默认项目目录的未压缩主会话，核对真实编号与元数据身份，并在打开时复核文件和目录身份；目录记录不表示正在运行。子代理、自定义目录、压缩记录及其他工具完整历史仍未覆盖。
- **快捷导航**：工作台顶栏“前往”或 ⌘K 搜索功能页，方向键选择、回车打开、Escape 返回；切页保留未保存输入，确认操作期间保护当前预览。
- **模型与接口目录**：按模型、地址、协议和认证变量引用整理 Codex 配置与档位，支持本地查找、预览应用和定位编辑；配置来源不代表服务授权或运行中的模型。
- **提示词**：工作台内建本地提示词库，可新增、编辑与移除；保存后预览完整正文，再选择 Codex 或 Claude Code，确认应用到各自用户级指令。写入前备份并检查外部变化，支持预览还原。各工具备份隔离；Codex 非空用户覆盖文件使操作拒绝，Claude Code 仅支持默认用户目录。项目规则保留，须在新会话核对加载。
- **扩展配置**：工作台内建 Codex 用户级 MCP 管理，支持 HTTP 与本地进程配置的新增、编辑、启停和删除，写入前核对字段差异并备份。凭据只填写环境变量名；保留非目标配置，检查外部修改，可通过备份还原。含静态凭据或未支持形式的配置保留只读，服务器连接与客户端加载需在工具内确认；用户共享目录中的 Skills 可预览启停，写入前备份，重启 Codex 后核对加载；启停只改配置；macOS 支持从本地技能目录预览安装或更新，保留脚本/资源与旧包，安装记录可在重启后恢复，文件被后续修改时拒绝覆盖。恢复记录可逐项预览并移入废纸篓，保留包可手动取回，已安装技能与启停配置不变；默认展示最近 5 条，其余可展开。目录链接、特殊文件、已识别凭据及超限包拒绝安装；支持 YAML 多行说明、引号转义、注释及有界别名/合并键；元数据限 64 KiB，重复字段、无效类型和超限展开拒绝，标准技能包可选择 Codex 或 Claude Code 用户目录安装，并从另一工具手动预览同步；记录标明目标工具，恢复仅操作该目标。同步复制完整包，工具专属语法不转换，加载需在目标客户端核对；可按需编辑两工具用户级技能的 Markdown 正文，预览新旧文本后保存，元数据与资源保留；包内文件在编辑期间改变则拒绝旧草稿覆盖，保存版本可恢复。草稿仅留在当前窗口，编辑读取有效30分钟，正文与完整文件最多4 MiB。项目/插件目录与旧清单写入尚未接入。
- **模型与连接**：工作台按工具配置、模型目录、扩展、提示词和服务连接分区，支持方向键循环切换与 Home/End 定位，切换保留草稿；目录按接口和协议区分本机配置目标，可直接选择已保存档位，复用预览、备份与应用流程，不代表服务可用性或运行模型；服务连接可保存、编辑、停用和移除 New API、Magpie、CC Switch 的地址与凭据环境变量名，保存不会访问服务；可手动读取 New API 公开状态与 Magpie 服务身份，结果标明时间，鉴权/断线/不支持分别显示；状态可读不代表模型或用量权限，远端目录/用量与 CC Switch 接口尚未接入。侧栏保留 Codex 档位入口。Codex 配置展示目标，从可重现的当前配置保存档位、复用已保存接口、编辑模型并预览应用；检查外部改动，支持重新应用或保留当前配置。提供 Responses 协议模板；旧 Chat 档位可查看和删除，核对接口并改为 Responses 后才能保存或应用。支持白名单档位导入导出与备份关键字段对比，还原前保留当前文件。折叠清单可查看本机 Codex MCP 与 Codex、Claude Code、共享目录中的 Skills 配置状态。应用前自动备份，档位只保存环境变量名，密钥由用户通过环境变量提供。
- **配置备份保护**：写入前保存完整备份，同名冲突保留历史并停止操作；还原前也备份当前配置。含已识别私有字段或未支持形式的配置保持只读，凭据使用环境变量或钥匙串引用。
- **工作空间**：保存项目、常用工具、Codex 档位与窗口布局的本地组合；打开时逐项核对引用，进入对应项目、档位或规则预览。逐项应用后汇总本次结果，配置备份与窗口撤销保留具体恢复入口；组合变更需重新核对。失效引用说明原因，移除组合保留原模块数据；保存和打开不会自动执行工具、写配置或移动窗口。配置分项操作保存本地历史，重启后可定位恢复备份；未完成记录不会自动重试，恢复仍需预览确认。最近一次窗口撤销适用于当前应用运行期；组合关联的排列历史可在重启后定位，选择当前窗口并预览原位置再恢复。历史结果不表示运行会话或窗口当前状态。
- **本地任务**：在工作台按项目整理任务，查看未开始、执行中、需处理和已结束列表；记录人工关口、运行历史与产出引用，支持归档和恢复；Codex 的来源问题及完成结果、Claude 的问题及有明确正文的方案可按具体版本只读查看，内容按需读取、不复制到任务文件；运行历史可按保存的来源打开对应会话或工具，缺来源明确提示；可关联已观测到的文件或数据库会话并同步状态，数据库内不同会话及工作区分别识别，工具跳转按实际能力标注。灵动岛、侧栏和概览显示一条具体需处理事项与数量，可进入对应任务或来源工具。本地处理不会启动或批准来源工具操作。
- **用量趋势**：按实际时间显示小时记录，可切换 24 小时、7 天和 30 天；空缺不视为零消耗，24h 汇总与模型明细保持独立口径。读取失败保留上次内容，可重试。
- **用量来源**：工作台用量页可展开最近24小时的会话服务与请求模型，显示已核对和未核对的净消耗；缺少匹配身份的记录保留为未知。会话标识不代表请求接口、账户或服务商账单。
- **待办与报告**：本机待办列表；用量页按需展开 Markdown / CSV 报告，生成与复制反馈独立，失败保留已有正文；CLI 可导出文件。
- **窗口排列（macOS）**：工作台选择已识别工具窗口，在指定屏幕预览左右、主辅或网格排列；可保存和复用模板与工具偏好，复用时重新核对窗口和屏幕。辅助功能权限由用户显式开启，应用前复核，逐窗展示结果并保留最近一次撤销。同工具窗口可互换位置，必要时在屏幕工作区内临时错开，再完成排列或撤销；不能形成完整计划时会说明原因。排列历史保存原位置、目标和实际读回；重启后可逐窗选择当前工具窗口，预览历史原位置再恢复。历史详情按需展开，记录可单独删除；标题与原生句柄不保存。重叠身份不明确、全屏或状态不可读的窗口会说明限制；实际工具兼容性仍在验证。
- **MiniMax Code**：检测 MiniMax Code 桌面版与 `mcode` CLI，读取默认 `~/.minimax/v2/sqlite/runtime-state.sqlite` 的会话状态和独立用量账本；提供 24h、累计、模型拆分和小时趋势，不读取登录凭据。自定义数据目录与命名 profile 需另行配置档案。
- **通知**：确认、完成和成本事件提示；远程通知可选，默认关闭，支持飞书群机器人（可选签名）、微信与 QQ 的 PushPlus 推送、已有 QQ OneBot 11 群机器人、ntfy、HTTP 模板与 SMTP 465。选择渠道后填写必要信息，复杂模板与发送策略位于高级设置；页面提供手动发送测试和近期结果。

## 安装与使用

从 [Releases](https://github.com/bitterSmilezzz/AgentIsland/releases/latest) 下载发布包。macOS 包含 `AgentIsland.app` 和 Rust CLI `agentisland`；应用未公证，首次运行使用右键 → 打开。

macOS 默认作为菜单栏常驻应用启动，显示灵动岛贴条与菜单栏图标；手动打开工作台时显示 Dock 图标，关闭或收起工作台后隐藏 Dock 图标。托盘可打开工作台。灵动岛把手可通过悬停、点击或键盘 Enter / 空格展开，四个方向均可贴边；设置中的“收起时隐藏微细条”隐藏视觉元素并保留唤回热区。重复启动复用已有应用实例。

```sh
./agentisland --shell=workbench
./agentisland --shell=sidebar
./agentisland --expand
./agentisland --demo
./agentisland help
./agentisland status --json
./agentisland doctor
./agentisland report --format csv
```

`agentisland open workbench` 打开工作台，`agentisland open workbench-hide` 收起工作台。macOS 随包 CLI 优先打开对应应用；单独移动 CLI 且没有同目录应用时使用系统注册的应用。CLI 命令的参数与边界以 `agentisland help` 为准。清理命令会终止进程，请先查看检查结果并核实目标；单次采样的死锁判定为“本次未评估”，持续监控才积累足够观测证据。

## 构建与验证

macOS 需要 Rust stable、Command Line Tools、Python 3 和 cargo-tauri；前端不需要 Node/npm 构建。Rust 测试中的 JS 守护需要 Node.js。

```sh
scripts/install-git-hooks.sh
cargo test --locked --manifest-path app/src-tauri/Cargo.toml
scripts/build-app.sh
scripts/restart-app.sh
```

构建产物为 `dist/AgentIsland.app` 和 `dist/agentisland`，二者都使用 Rust；发布流程由 `scripts/release.sh <X.Y.Z> "<标题>"` 执行扫描、回归、打包、UI 冒烟、单实例检查、提交、tag 和 Release。版本校验覆盖 Cargo、锁文件、Tauri 配置、CHANGELOG 和本 README。

## 工程结构

- `app/src-tauri/src/`：Rust 监控、业务、Tauri 命令与 CLI。
- `app/src-tauri/tests/fixtures/`：会话与稳定契约夹具。
- `app/ui/`：三种窗口共用的静态界面与主题。
- `scripts/`：构建、验证、脱敏与发布。
- `docs/adr/` 与 `CONTEXT.md`：长期决策及领域口径。
- `docs/workbench/`：跨平台工作台计划与迁移取证记录。
- `site/`：对外功能主页。

## 当前限制

- macOS 是当前完整验证的交付平台；Windows 仍有 POSIX 适配工作，CI 的 Windows 检查作为可见的非阻塞结果。
- 用量覆盖取决于工具是否提供可读取的本机会话记录；云端用量和缓存读取消耗不能凭本地净消耗推导。
- 档位只修改本机 Codex 配置，不验证账号或模型可用性；目标接口须兼容客户端协议，新会话或重启后读取配置。原生 profile 覆盖暂不支持切换；原生登录及特殊认证配置不能保存为本应用档位。模型与接口字段的一致性检查不等于运行模型验证。
- 应用没有后台云端同步；远程通知须自行配置。Linux 未作完整交付验证。
