五种状态，五种颜色，五种语义

不是「进程在不在」的二值判断。working 要求进程在、且 60 秒内有文件写入或 CPU 越过阈值；只打开应用不动它、桌面抖动、浏览器缓存写入都不算任务完成。

  • working 运行中进程在，且有写入证据或持续算力消耗；旋转微弧跟着呼吸。
  • attention 等待确认识别结构化确认、权限申请与用户输入请求；多个 Agent 同时在等也不会漏报。
  • completed 已完成只在有写入证据时宣布完成，并给出这一轮的耗时与用量。
  • idle 待机进程在，但既不写入也不消耗算力——真的闲着。
  • offline 离线进程已退出。即使昨天有活动记录也不冒充「现在的状态」。

异常高负载会在五态之上再叠一层橙/红告警：Token 暴涨、长耗时死循环、孤儿后台、内存激增。

它是一条岛，不又一个窗口

顶栏按住可自由拖拽，松手按最近距离吸附到上、右、下、左任一边，并持久化该边锚点。收起态与屏幕物理边框之间用三次 Bézier 反向倒角平滑过渡，而不是悬空一块矩形。

  • 环形微仪表盘：5 态水位环 + 工作态旋转微弧，顶部并列活跃 Agent 迷你环，点击秒切
  • 悬停透视卡：实时命令、正在修改的文件、PID、24h / 累计 Token 与花费，带几何指向小尾巴
  • 卡内三级导航：主列表 → Agent 详情 → 模型会话列表
  • 键盘流：1–3 切视图、j/k 移动焦点、Enter 下钻、/ 搜索、Esc 逐级返回、? 速查
  • 全屏 Space 跟随、多屏跟随鼠标所在屏、外接屏拔出平滑重定位

正在做什么，花了多少，查得准不准

三块面板把「我离开这一会儿发生了什么」讲清楚：动作上下文、成本账、以及监控自身的可信度。

跨工具一本账

24h 与累计 Token、按模型拆分、花费，以及月末消耗与预算枯竭预测。预算与 24h 用量同为滚动 24 小时口径，趋势图的每根柱子对应一个日历天。

异常大的数值会被饱和到上限并说明，不会把报表算成 inf。

「真闲着」还是「没看到」

岛内与 doctor 共用同一份实现，把「会话源读不到 / 本地无明细 / 未接入明细源」分成三种不同结论——不会出现终端说不可信、岛上说正常。

孤儿判定要证据：ppid == 1 分不清遗孤与 launchd 托管的常驻服务，宁漏不错杀。

人不在 Mac 前也能收到

远程桌面连着 Mac 时，通知只画在 Mac 屏幕上——传的是像素不是事件。三个通道把提醒送出本机：ntfy 订阅、自定义 HTTP 模板（Server酱 / 企微 / 钉钉 / 飞书）、邮箱 SMTP。

默认只送「哪个 Agent + 什么状态」；命令内容、文件路径、消息原文必须显式勾选才会送出。

岛能做的，终端也能做

agentisland 随包附带（也装在 .app 的 Contents/Helpers/）。CI、脚本、SSH 里都能取到同一份状态：类 htop 的全屏看板、一次性自查、Markdown / CSV / JSON 运维报告、导出 Raycast 命令清单。

  • 「没取到」不印成 0：用量列是 —，JSON 里是 null；查了确实是零才写 0
  • 死锁判定是三态：卡死 / 不卡死 / 本轮判不出。一次性入口一律「本次未评估」，要结论得用持续观测的入口
  • 深链：agentisland://expand、agent?id=、analytics、toolbox、notify
  • 本地 Webhook：127.0.0.1:41999 的 POST /notify，只监听回环

隐私边界，以及现在还成立的限制

一个盯着你所有会话的工具，必须把「什么会离开这台机器」说清楚——包括它做不到的部分。

留在本机的

  • 凭据只进 macOS 钥匙串，由你自己录入；界面与日志只显示掩码，UserDefaults 里零密钥
  • 命令内容、文件路径、消息原文默认不外送，必须显式勾选「附带最后一条动作」
  • 「发送预览」显示实际会离开本机的原文
  • 深链与 /notify 产生的事件一律不外送——那是本机任意进程都能写的入口
  • 截图、构建产物、本地草稿一律不入库；提交前过一道棘轮式脱敏门禁

它确实做不到

  • Qoder 的 Token 消耗监控不了：会话库里四个 token 字段恒为 0，真值只有 credits。宁可显示 —，也不拿 credits 折算成一个看起来像真的数字
  • 邮箱只支持 465（隐式 TLS）：Network.framework 没有「在已建立的 TCP 上原地升级 TLS」的能力，25/587 会在配置层被拦住并说明原因
  • 本地 Webhook 无鉴权：只靠「仅监听回环」限制来源，岛内会把这类事件标为「外部投递」
  • 未公证（ad-hoc 签名）：首次打开需右键 → 打开

安装

从 Releases 下载最新的 AgentIsland-*.zip，解压后拖入「应用程序」或直接运行。

unzip AgentIsland-0.0.129.zip
mv AgentIsland.app /Applications
open AgentIsland.app        # 首次需右键 → 打开

从源码构建

无需 Xcode，SwiftPM + CommandLineTools 构建，手工组装 .app；测试是自己写的 runner，零依赖。

export SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk

swift build && swift build --build-tests
.build/debug/AgentIslandTestsRunner      # 自建测试套件
./scripts/build-app.sh                   # 打包：测试门禁 + 图标 + ad-hoc 签名
open dist/AgentIsland.app

跑起来之后

  • 光标碰到屏幕边缘那条 6pt 细线，岛就弹出来
  • 按 ? 看快捷键，按 1–3 在主列表 / 详情 / 用量之间切
  • 设置里五个分栏：通用与外观、Agent 监控、远程通知、引擎与性能、关于
  • 启停开关、熔断阈值、采样间隔、收起延迟、贴边位置与外观都实时生效，不需重启
