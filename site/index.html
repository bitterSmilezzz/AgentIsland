一眼分清 Agent 正在做什么

AgentIsland 综合进程、文件活动和会话事件判断状态。单纯打开应用不会被当成正在工作；缺少完成证据时，也不会直接报为已完成。

  • 运行中发现近期任务活动或持续算力使用。
  • 等待确认Agent 请求你确认操作、授权或补充输入。
  • 已完成检测到本轮完成迹象，并显示耗时与可读取的用量。
  • 待机进程仍在，但暂时没有检测到任务活动。
  • 离线Agent 进程已退出。

Token 用量突增、长时间高负载、异常后台进程或内存激增时，还会显示额外告警。

在屏幕边缘查看，需要时直达现场

展开卡片可查看 Agent 列表与详情，也能跳回对应的图形界面或终端。卡片可拖到屏幕四边，多屏和全屏空间也会跟随使用中的屏幕。

  • 状态环与活跃 Agent 指示，点击即可切换查看
  • 悬停查看当前命令、活动文件、进程与用量
  • 从 Agent 详情继续查看各模型会话和费用
  • 快捷键支持搜索、切换视图与返回；按 ? 查看完整列表
  • 可吸附到屏幕四边，并适配多屏与全屏空间

任务进展、用量和提醒，都有清楚去处

查看 Agent 最近在做什么、用量如何，以及当前监控数据是否完整。

查看 Token 与费用

按工具和模型查看用量、费用、近期趋势与预算进度，也可查看月末用量预测。

各工具可读取的数据不同；没有明细时会明确标出，不用估算值填补。

知道监控数据是否完整

工作台会说明会话来源是否可读、是否找到本地用量明细，以及哪些工具尚未接入明细。

也可运行 agentisland doctor 查看判断依据。

按需接收远程提醒

可通过 ntfy、自定义 HTTP 模板或邮箱，把完成、待确认和异常提醒发到其他设备。

远程通知默认关闭。命令、文件路径等活动详情只有在你明确启用后才会发送。

需要脚本或终端时，也能查看与管理

agentisland 命令行工具随应用提供，可在终端或脚本中查看状态、排查监控、汇总用量和生成报告。

  • 未读取到的用量会显示为「—」，不会混同为零
  • 一次性检查不会伪称已评估长时间运行或卡死状态
  • 支持从终端控制灵动岛，也提供本机 Webhook 供脚本投递事件

运行状态和 Token 明细的覆盖范围不同，具体取决于工具提供的本地数据。AgentIsland 只读解析所需字段，不展示对话正文或修改会话数据，也不需要辅助功能或完全磁盘访问权限。

数据留在本机，是否外发由你决定

AgentIsland 在本机只读查看进程和会话数据。远程通知默认关闭；开启后也可预览实际发送内容。

本机数据与通知

  • 会话文件以只读方式解析，不显示确认问题或回答正文
  • 远程通知默认关闭；凭据保存在 macOS 钥匙串
  • 命令和文件路径默认不外发，需在设置中主动选择附带活动详情
  • 发送预览可检查将要离开本机的内容
  • 由深链或本地 Webhook 触发的事件不会转发到远程通知

已知限制

  • Qoder 暂无 Token 明细：不会把 credits 换算成估算用量
  • 邮箱通知仅支持端口 465
  • 本地 Webhook 没有鉴权，仅监听本机回环地址
  • 应用未公证：首次打开时需在 Finder 中右键选择「打开」

下载并开始使用

从 Releases 下载最新压缩包，解压后将 AgentIsland.app 拖到「应用程序」。首次打开时，在 Finder 中右键应用并选择「打开」。
